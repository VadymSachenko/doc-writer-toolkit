Цей глосарій є авторитетним джерелом термінів для україномовних сторінок. Як читати таблицю —
`${CLAUDE_PLUGIN_ROOT}/context/doc-rules/glossary-format.md`. Два рядки нижче — зразки: замініть їх
термінами свого продукту.

## Терміни

| Термін | Рендер | Код-сутність | Визначення |
|---|---|---|---|
| `active` | `code` | `active` | Статус облікового запису — активний. UI-мітка: **Активний**. |
| Обліковий запис | `текст` | | Набір даних користувача, з яким він входить у застосунок. Не використовуйте: акаунт, профіль (як синонім). |
