# URLs and web addresses

- Prefer meaningful linked text over displaying a raw URL.
- Use *URL* for a web resource locator and *URI* when the broader identifier concept is
  technically necessary.
- For complete displayed URLs, use lowercase where the address permits it.
- Do not add sentence punctuation to a URL when it could be mistaken for part of the
  address.
- Never hyphenate a URL. If a break is necessary, break before a slash or another
  natural delimiter without inserting a character.
- Use secure `https` links when available.
- Remove unnecessary protocol, `www`, tracking parameters, and trailing slash only when
  doing so does not change or break the destination.
- Verify that link text identifies the destination and that the destination works for
  the intended locale and audience.
