# Type, layout, and titles

- Use semantic styles instead of manual font changes.
- Use sentence-style capitalization by default for titles, headings, labels, and UI.
- Prefer bold to italics for cited titles because bold is easier to read.
- Preserve official title capitalization for books, white papers, reports, games,
  events, and webinars.
- Use italics sparingly for emphasis; do not rely on type style alone to communicate
  warnings, state, or meaning.
- Left-align running text in left-to-right languages. Do not justify text or center long
  passages.
- Preserve comfortable line spacing and white space. Do not compress lines to fit more
  content into a page or viewport.
- Keep the number of typefaces, sizes, weights, and colors small and consistent.
- Do not underline ordinary emphasis; reserve underlining primarily for links.
- Never use all caps for ordinary emphasis or long labels.
