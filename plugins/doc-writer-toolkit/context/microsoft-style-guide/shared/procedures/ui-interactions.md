# Describing interactions with the UI

Prefer verbs that work with keyboard, mouse, touch, voice, and assistive technology.

## Verb choices

| Verb | Use for |
|---|---|
| **open** | Apps, programs, panes, File Explorer, files, folders, and shortcut menus. Do not use for commands or ordinary menus. |
| **close** | Apps, panes, dialogs, files, folders, notifications, and tabs. |
| **leave** | Departing a webpage or site. |
| **go to** | A menu, tab, named UI location, webpage, or website. |
| **select** | A specific control, checkbox, value, link, menu item, gallery item, key, or shortcut. |
| **choose** | A preference or desired outcome; also use before a UI label beginning with *Select* to avoid repetition. |
| **select and hold** | Pressing and holding an element. Add *(or right-click)* when relevant to non-touch instructions. |
| **clear** | Removing a selection from a checkbox. |
| **switch**, **turn on**, **turn off** | Changing a toggle, mode, or setting. |
| **enter** | Typing or otherwise supplying a value. |
| **move**, **drag** | Repositioning an object. Use *move through* for navigation through screens or pages. |
| **zoom in**, **zoom out** | Changing magnification. |

## Rules

- Avoid *click* and *swipe* in input-neutral instructions.
- Match UI labels exactly, including meaningful capitalization and punctuation.
- Do not describe a control type unless it adds necessary clarity.
- Use *pane*, not *blade*, for the UI region; open, close, or work **in** a pane.
- Do not call a dialog, pane, or other specific region a window.
- Use *checkbox* as one word and use *select* or *clear* for its state.
- Include the noun after an icon label when needed: **Search** button, not merely
  **Search**, if the label could be read as an action.
