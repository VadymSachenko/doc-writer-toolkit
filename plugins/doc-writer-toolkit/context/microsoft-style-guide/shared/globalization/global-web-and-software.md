# Global-ready web and software

- Use standards-based, progressively enhanced markup and simple layouts.
- Test likely browsers, devices, font substitutions, zoom levels, and input methods.
- Externalize all localizable text, including text produced by scripts.
- Allow text expansion and support right-to-left and vertical writing systems.
- Avoid layouts that depend on fixed string length, order, or direction.
- Keep downloads efficient and make essential text available before large media.
- Confirm that products, formats, downloads, claims, and examples are available and
  legal in each target market.
- Prefer globally available destinations. If a link or reference is locale-specific,
  say so and provide an alternative when possible.
- Monitor the locale of subscription audiences and localize recurring communications
  when required.
