# Lists

## Selection and structure

- Use at least two items. Prefer no more than seven when practical.
- Keep items short enough that readers can see several at once.
- Use bullets when order does not matter.
- Use numbers for a sequence, ranking, or referenced callouts.
- Give neighboring items parallel grammatical structures.
- Introduce the purpose with a heading, complete sentence, or fragment ending in a colon.
- Do not add punctuation after a heading that serves as the introduction.
- For localization, avoid making list items complete an unfinished introductory phrase.

## Term lists

For a compact term-and-definition list:

- Use bullets unless order matters.
- Put the term in bold sentence case. If it is a link, use link formatting only.
- Put a plain-text period between the term and definition.
- Start each definition with a capital letter and end it with a period.

**Recommended**

- **Draft.** Work that has not been submitted for review.
- **Approved.** Work accepted for publication.

## Punctuation

- Start items consistently with capitals or lowercase text.
- Do not end items with commas, semicolons, *and*, or *or*.
- Use periods for complete sentences and items that complete the introduction.
- Omit periods when every item is three words or fewer, a UI label, heading, string,
  filename, or similar fragment.
- In UI lists, omit punctuation from fragments and apply any necessary punctuation
  consistently across the screen.
