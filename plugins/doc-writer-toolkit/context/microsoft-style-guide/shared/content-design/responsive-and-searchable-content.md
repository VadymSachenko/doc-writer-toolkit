# Scannable, responsive, and searchable content

## Scanning

- Put the central message and action in the first visible section.
- Use short headings, sentences, paragraphs, and sections.
- Keep paragraphs focused; three to seven visual lines is a useful target.
- Use consistent syntax and formatting to create predictable landmarks.
- Give long documents internal navigation and meaningful section links.

## Responsive content

- Assume a narrow viewport and enlarged text.
- Keep headings short enough to avoid awkward wrapping.
- Crop images to relevant information and provide alt text.
- Simplify charts, axis labels, and legends.
- Minimize table columns and cell length.
- Verify that content still makes sense when right-hand content flows below left-hand
  content or when visual columns become a single sequence.
- Do not insert manual line breaks to force a desktop layout.

## Search

- Research the words readers use, not only internal product vocabulary.
- Put natural keywords early in titles, headings, summaries, introductions, link text,
  descriptions, and relevant alt text.
- Repeat terms only where natural; do not stuff keywords.
- Use concise, destination-specific links and link to supporting detail instead of
  repeating it.
- Describe non-text media nearby so it can be found through text search.
- Prefer durable, reader-centered writing over short-lived search tricks.
