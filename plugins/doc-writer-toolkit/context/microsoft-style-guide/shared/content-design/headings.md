# Headings

## Rules

- Use headings to express a real hierarchy and provide scanning landmarks.
- Make each heading specific to the content that follows.
- Front-load the reader's goal or the most meaningful keyword.
- Keep headings short, but do not sacrifice precision.
- Use parallel grammatical forms for headings at the same level.
- Prefer a noun phrase for a concept and an action-oriented phrase for a task.
- Use sentence-style capitalization.
- Do not end a heading with a period or colon. Use a question mark only when the
  heading is genuinely a question; use an exclamation point rarely.
- Avoid two headings in succession. Fix the hierarchy instead of adding filler text.
- Create a lower heading level only when the parent contains at least two distinct
  subordinate topics.
- Do not skip heading levels or simulate a heading with bold text.
- Avoid ampersands, plus signs, and avoidable hyphens in headings.
- Do not insert manual blank lines to control heading spacing.
- For run-in headings, use a semantic style and a phrase that introduces the paragraph.
