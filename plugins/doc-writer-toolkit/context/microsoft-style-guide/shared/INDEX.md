# Shared-rule index

Load only the folder that matches the task.

| Topic | Folder |
|---|---|
| Voice and tone | `voice/` |
| Accessibility | `accessibility/` |
| Inclusive content | `inclusive-content/` |
| Planning, headings, lists, tables, search | `content-design/` |
| Procedures and UI interactions | `procedures/` |
| Text, UI, title, code, and URL formatting | `formatting/` |
| Developer and reference content | `developer-content/` |
| Bots and virtual agents | `conversational-content/` |
| Global-ready content | `globalization/` |

These files transfer principles across languages. Language-specific mechanics still
come from `../en-us/` or `../uk-ua/`.
