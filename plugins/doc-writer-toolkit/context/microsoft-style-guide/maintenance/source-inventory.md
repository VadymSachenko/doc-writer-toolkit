# Source inventory

Snapshot date: 2026-07-16.

## English guide

- Canonical source: `https://learn.microsoft.com/en-us/style-guide/`
- Discovery baseline: archived `MicrosoftDocs/microsoft-style-guide` repository,
  commit `c6945c32294e845a84b192a094fb1b7c2c452a6a`.
- Inventoried baseline pages: 948.
- Live-only terminology pages added after the baseline: 1 (`URI`).
- Current live pages were used to refresh changed guidance through July 2026,
  including plugin, pane/blade, timeout, real time, sync, anti-malware, allow/block
  list, white paper, opt in/out, following, and sorry.

The archived repository is a discovery checklist, not the authority for changed live
rules. `source-map.json` records the page-to-file mapping.

## Ukrainian guide

- Official source: `https://aka.ms/ukrainian-styleguide`
- Edition observed: PDF created 2025-09-04.
- Length: 158 pages.
- All sections 1–5.7 are represented in `uk-ua/`, with the long orthography overview
  routed to the chief UA grammar corpus instead of duplicated.

## Deliberate exclusion

Microsoft Learn contributor guidance is outside this library’s scope.

Raw repositories, webpages, and PDFs are temporary extraction inputs and are not
retained in the final library.
