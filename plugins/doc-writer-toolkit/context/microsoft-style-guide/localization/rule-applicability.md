# Cross-language applicability matrix

| Rule family | Ukrainian applicability | Instruction |
|---|---|---|
| Outcome-first, concise, helpful voice | Transfer intent | Re-express naturally in Ukrainian. |
| Accessibility and bias-free principles | Transfer intent | Use Ukrainian person-first and gender-neutral strategies. |
| Content hierarchy, focused headings, usable procedures | Transfer intent | Apply structure; localize wording and punctuation. |
| Product facts, code, identifiers, placeholders | Preserve semantics | Do not change technical behavior or syntax. |
| English capitalization and title case | Not transferable | Apply Ukrainian capitalization and approved product spelling. |
| English punctuation, serial comma, apostrophe, quotation style | Not transferable | Use chief UA grammar plus the UI/documentation overlay. |
| English contractions and article choice | Not applicable | Recreate natural tone with Ukrainian syntax. |
| English pronoun and possessive frequency | Not transferable | Omit or restructure where natural; use **ви/свій** deliberately. |
| English number spelling | Conditional | Use Ukrainian number rules; prefer digits in UI and with variables. |
| English A–Z usage term | Source-only by default | Use it to understand intent; verify a Ukrainian approved term. |
| UI action semantics | Transfer action, localize verb | Map the control to **натисніть/виберіть/установіть/перейдіть**. |
| Microsoft Ukrainian localization choice | Ukrainian target only | Apply unless chief grammar or current approved terminology supersedes it. |
