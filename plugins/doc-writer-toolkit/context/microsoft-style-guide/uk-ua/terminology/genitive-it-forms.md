# Родовий відмінок поширених ІТ-термінів

для типового ІТ-значення. Спершу перевірте головний корпус через
`../grammar-authority.md`; якщо сучасна нормативна форма відрізняється, головний
корпус має вищий пріоритет. У дужках указано значення, яке змінює закінчення.
