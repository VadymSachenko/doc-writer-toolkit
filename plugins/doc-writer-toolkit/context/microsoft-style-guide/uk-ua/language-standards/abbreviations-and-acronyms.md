# Українські скорочення й акроніми

- Не створюйте довільних скорочень. Використовуйте усталені форми: **стор.**,
  **рис.**, **табл.**, **див.**, **год.**, **хв.**, **с**, **міс.**, **тиж.**,
  **тис.**, **млн**, **млрд**.
- Пишіть **тощо**, а не *і т. д.*
- Скорочуйте перекладений термін, якщо джерело теж використовує скорочення або
  коротка форма усталена.
- Не перекладайте англійську абревіатуру довільно. Усталені відповідники:
  **PC → ПК**, **OS → ОС**, **RAM → ОЗП**, **ROM → ПЗП**, **IR → ІЧ**.
- Невідому або неперекладену абревіатуру залишайте без змін і за першої згадки
  пояснюйте повною назвою чи дескриптором.
- Не додавайте українських відмінкових закінчень до латинської абревіатури.
  Відмінок передавайте дескриптором; рід визначайте за головним словом перекладу.
- У заголовку не вводьте незнайому абревіатуру без розшифрування в найближчому
  тексті. У довгому матеріалі періодично повторюйте повну назву.
