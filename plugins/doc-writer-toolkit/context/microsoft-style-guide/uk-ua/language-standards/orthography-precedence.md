# Межа правопису й локалізаційних правил

Microsoft Ukrainian Localization Style Guide містить огляд Правопису 2019 року.
Цей огляд не дублюється тут і не є головним мовним джерелом.

1. Для орфографії, відмінювання, милозвучності, синтаксису та пунктуації спочатку
   використовуйте `../grammar-authority.md`.
2. Цей корпус застосовуйте як локалізаційний шар: назви продуктів, компоненти UI,
   повідомлення, запити Copilot, клавіші, формати й усталені ІТ-відповідники.
3. Якщо PDF Microsoft і головний корпус суперечать одне одному в мовному питанні,
   перемагає головний корпус.
4. Не переносіть проєктно-специфічні терміни з `00-cheatsheet.md` у загальний текст.

Source: Microsoft Ukrainian Localization Style Guide, section 4.1.
