# Стилістичні граматичні рішення для локалізації

Це локалізаційні рішення. Загальну правильність перевіряйте через
`../grammar-authority.md`.

## Іменники й дієслова

- Назви процесів на **-ння** використовуйте для процесу, а не автоматично для
  результату. Коли можливо, замінюйте віддієслівний іменник дієсловом.
- Усталені назви: **вибір, підготовка, активація, друк, інсталяція, натискання,
  імпорт, експорт, синхронізація, перевірка, обробка, збір, публікація**.
- Для завершених дій зважайте на форму: **відкриття, закриття, злиття**.
- Не використовуйте закінчення **-ові** для неістот, якщо нормативна форма має
  **-у/-ю** або **-і**.
- У Microsoft-інтерфейсі метафоричні *майстер, агент, клієнт, браузер* можуть
  відмінюватися як неістоти відповідно до затвердженого терміна.

## Дієслівний вид і стан

- Обирайте доконаний вид для разової завершуваної дії, недоконаний — для
  повторюваної або тривалої.
- Тривалу операцію передавайте зворотним дієсловом, конструкцією **триває** або
  назвою процесу: **Сторінка завантажується**, **Триває завантаження сторінки**,
  **Завантаження сторінки…** Не поєднуйте **триває** з трьома крапками.
- Форма на **-но/-то** доречна, коли виконавця не названо: **Файл видалено**.
  Якщо виконавець є, зробіть його підметом: **Адміністратор видалив файл**.
- У теперішньому часі часто опускайте **є**: **Delve — це вебпрограма**;
  **Це новий центр**.

## Займенники та короткі форми

- Не дублюйте англійські присвійні займенники. Опускайте їх або використовуйте
  **свій**, якщо належність очевидна.
- Загальну інструкцію формулюйте наказово або безособово: **Введіть текст**,
  **Потрібно видалити файл**.
- У UI використовуйте короткі питання: **Продовжити?**, **Зберегти зміни?**
- Англійську форму *file(s)* передавайте природною множиною, без дужок і скісної
  риски: **Виберіть файли**.

## Рід і число

- Не копіюйте англійську однину в складених назвах, якщо йдеться про клас:
  *template wizard* → **майстер шаблонів**.
- Для підстановних значень перебудовуйте фразу так, щоб вона не залежала від роду
  або числівникового закінчення.
