# Пунктуація в українській локалізації

Загальну пунктуацію визначає `../grammar-authority.md`. Нижче — рішення, важливі
саме для локалізації та UI.

- **За замовчуванням** не відокремлюйте комою.
- **Наприклад** і **зокрема** відокремлюйте як вставні слова; після них немає
  окремої коми, якщо вони вводять компонент уже відокремленої пояснювальної
  конструкції.
- Після **Увага**, **Попередження**, **Обережно** ставте знак оклику. Пишіть
  **Порада.**, **Примітка.**, **Приклад.**
- Використовуйте дефіс усередині слова без пробілів. Для реченнєвого тире й
  математичного мінуса використовуйте коротке тире **–**; у діапазоні — без
  пробілів: **15–30**, у відніманні — з пробілами: **3 – 1 = 2**, перед від’ємним
  числом — без пробілу: **–1**.
- Звичайне речення завершуйте крапкою. Не додавайте крапку до заголовка, назви
  стовпця, підпису або іншого короткого ярлика, якщо формат не вимагає її.
- У програмі та на вебсторінці використовуйте прямі подвійні лапки. У документації
  та довідці — кутові **«…»**; вкладені лапки — прямі: **«кнопка "Готово"»**.
  Крапку ставте після закривальних лапок.
- Не використовуйте одинарні лапки замість подвійних.
- У дужках немає внутрішніх пробілів. Розділовий знак усього речення ставте після
  закривальної дужки.
- Уникайте скісної риски в прозі; замініть її на **або**, **чи**, **і**, **та**,
  **й**. У UI вона допустима за жорсткого обмеження довжини.
- Використовуйте символ трикрапки **…**, а не три крапки, якщо платформа
  підтримує його. Зберігайте трикрапку в локалізованій команді, якщо вона означає
  подальший діалог.
- Для нерозривних пар — назва продукту, число й одиниця, ініціали — використовуйте
  нерозривний пробіл, якщо середовище його підтримує.
- У звичайному тексті **&** передавайте сполучником; зберігайте лише в коді,
  заповнювачі, комбінації клавіш або офіційній назві.

## Списки

- Після незавершеної ввідної фрази ставте двокрапку; фрагменти починайте з малої
  літери, розділяйте крапкою з комою, останній завершуйте крапкою.
- Якщо елементи — повні речення або абзаци, починайте їх із великої літери й
  завершуйте належним знаком. Завершена ввідна фраза може закінчуватися крапкою.
