# Повідомлення, помилки й тривалі операції

- Пишіть коротко, однозначно й доброзичливо. Не перекладайте англійську формулу
  буквально; однаковий зміст передавайте однаковою українською формою.
- Не додавайте знак оклику лише тому, що він є в англійському повідомленні.
- Скорочуйте питання до дії: **Справді видалити файл?**, **Зберегти зміни?**
- *Please* переважно не перекладайте: **Зачекайте…**, **Виберіть програму**.
- *Welcome to* передавайте **Вас вітає…**, **Ласкаво просимо до…** або лише
  назвою продукту, якщо рядок складений і відмінювання небезпечне.

## Стандартні моделі

| Англійський сигнал | Рекомендована українська модель |
|---|---|
| An error occurred while… | **Сталася помилка під час…** |
| An error was detected | **Виявлено помилку** |
| Cannot / Failed to / Unable to | **Не вдалося…** |
| Cannot як об’єктивна заборона | **Не можна…** |
| Out of memory / not enough memory | **Бракує пам’яті** |
| Insufficient disk space | **Недостатньо місця на диску** |
| In progress | **Триває…** |
| Searching / Downloading | **Пошук… / Завантаження…** |
| Invalid | **неприпустимий**; для недійсного підпису/сертифіката — **недійсний** |
| Make sure | **Переконайтеся** |
| Restart | **Перезапустіть** |
| Try | **Спробуйте** |
| Congratulations! | часто опустіть і повідомте результат |

## Тривалі операції

Використайте одну природну форму: **Документ друкується**, **Завантаження
сторінки**, **Триває перетворення файла**. Не пишіть одночасно **Триває…** і
трикрапку.

## Заповнювачі

З’ясуйте, що підставляється, не змінюйте маркер і перебудуйте речення так, щоб
відмінок, рід і число залишалися правильними. Див.
`../locale-formats/numbers-and-placeholders.md`.
