# Клавіші, сполучення й рядок стану

## Назви клавіш

- Видимі на клавіатурі назви залишайте латиницею з відповідним регістром:
  **Alt, Backspace, Ctrl, Delete, Enter, Esc, Shift**.
- Перекладайте невидимі або описові назви: **стрілка вгору/вниз/вліво/вправо**,
  **клавіша Windows**, **клавіша контекстного меню**. **ПРОБІЛ** пишіть великими
  літерами.
- Перед назвою клавіші пишіть дескриптор: **натисніть клавішу Enter**;
  для комбінації — **натисніть клавіші Ctrl+S**.
- Не розрізняйте основну й цифрову клавіатуру без потреби. Якщо це важливо,
  поясніть: **клавіша Ins на цифровій клавіатурі**; за браку місця — **дод.**

## Комбінації та послідовності

- Одночасне натискання: `Key1+Key2`, без пробілів.
- Якщо назва однієї клавіші складається з кількох слів або є клавішею символу,
  пробіли допомагають розрізнити частини: **Ctrl + стрілка вниз**, `Ctrl + "-"`.
- Послідовне натискання позначайте комою: **послідовно натисніть Alt, F**.
- Зберігайте стандартні сполучення, якщо продукт не визначає інакше: **F1** для
  довідки, **Ctrl+C/V/X/Z**, **Alt+F4**, **Ctrl+P**, **Ctrl+F**.

## Клавіші доступу

- За можливості призначайте кириличну літеру або цифру, щоб не перемикати
  розкладку. Починайте з першої вільної літери зліва.
- Не дублюйте клавішу доступу. Якщо всі придатні символи зайняті, для другорядного
  елемента краще не призначати її.
- Розрізняйте: **access key** — клавіша доступу з Alt; **key tip** — підказка
  клавіші на стрічці; **shortcut key** — сполучення для прямої команди.

## Повідомлення рядка стану

- Для меню й команд переважно використовуйте назву дії: **Створення нового
  документа**, **Копіювання вибраних елементів**.
- Якщо іменникова форма незручна, використайте коротке дієслівне речення.
- Стандартизуйте синонімічні англійські повідомлення: *Cannot/Could not/Unable to
  find the file* → **Не вдалося знайти файл**.
- Для числових заповнювачів див. `../locale-formats/numbers-and-placeholders.md`.
