# Інклюзивна й доступна українська мова

- Описуйте людей через релевантну для теми ознаку, а не зводьте людину до неї.
- Пишіть **людина з інвалідністю**, а не використовуйте назву стану як іменник.
  Не протиставляйте таких людей «нормальним» або «здоровим».
- Не припускайте гендер, вік, родинний стан, походження чи можливості людини.
- Якщо гендер відомий і релевантний, використовуйте належну назву особи. Якщо ні,
  перебудуйте речення: друга особа, множина, безособова конструкція, **людина**
  або **особа**.
- Для реальної людини поважайте вказане нею ім’я та займенники.
- Уникайте стереотипів, образливої лексики, сленгу, профанації та метафор, що
  романтизують насильство чи хворобу.
- Не описуйте лише одну сенсорну або моторну дію, якщо вона не обов’язкова.
  В інструкціях віддавайте перевагу нейтральним дієсловам **виберіть**,
  **відкрийте**, **відтворіть**.
- Робіть речення й абзаци короткими; за можливості одна основна дія на речення.
  Слова **та**, **плюс**, **приблизно** краще за неоднозначні символи в прозі.

## Межа з правилами граматики

Рекомендація PDF про узагальнений чоловічий рід не скасовує сучасних правил
української мови. Якщо вона конфліктує з головним корпусом UA grammar, діє
`../grammar-authority.md`.
