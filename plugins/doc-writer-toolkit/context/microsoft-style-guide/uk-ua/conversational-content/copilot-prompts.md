# Готові запити Copilot українською

- Зберігайте функцію запиту: він має точно задавати дію й не змінювати очікуваний
  результат Copilot.
- Пишіть конкретно, стисло, природно й розмовно; починайте з дії або прямого
  запитання. Уникайте жаргону, нечітких слів і машинного тону.
- Для цього типу контенту допустиме затверджене неформальне звертання; не
  переносьте його автоматично на решту українського UI.
- Будьте ввічливі й професійні. Лапками позначайте текст, який треба створити,
  змінити або замінити, якщо це допомагає моделі визначити межі.
- Перекладайте видимий текст усередині маркера сутності, але не змінюйте назву
  атрибута або синтаксис тегу:
  `<entity type='file'>файлу</entity>`.
- Розмістіть маркер сутності там, де він граматично природний українською.
- Текст-підказку всередині `<placeholder>…</placeholder>` за можливості ставте в
  кінці речення, щоб читач міг замінити його без переміщення курсора.
- Подібні запити перекладайте однаково; перевіряйте пунктуацію, регістр і граматику
  після підстановки реального значення.

**Рекомендовано:** Назви ключові положення, наведені у `[файлі]`.  
**Не рекомендовано:** Перелічи ключові положення від `[файл]`.
