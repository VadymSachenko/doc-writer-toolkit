# Продукти, функції, торговельні марки й файли

- Не перекладайте назву продукту, функції або торговельної марки без підтвердженої
  локалізованої форми. Перевіряйте чинну базу термінів і правила бренду.
- Назви з **Microsoft** і зареєстровані марки зазвичай залишаються без перекладу.
  Слово *for* у складеній назві передавайте як **для**, якщо затверджена назва це
  передбачає.
- Локалізовані назви продуктів пишіть із великої літери. Їх можна відмінювати без
  дескриптора або подавати з дескриптором у лапках: **відкрийте Пошту**;
  **відкрийте програму «Пошта»**.
- Якщо локалізована назва поєднує українську й англійську частини, використайте
  дескриптор і лапки: **обліковий запис «OneDrive для бізнесу»**.
- **Microsoft** залишайте латиницею в назвах продуктів і сполуках *продукти
  Microsoft*. Коли йдеться про компанію як суб’єкта дії, використовуйте затверджену
  форму **корпорація Майкрософт**.
- Торговельну марку не локалізуйте, якщо немає правової вимоги й затвердженої
  локалізованої форми.

## Файли та версії

- У прикладах перекладайте змістовну частину імені файла, якщо немає вимоги
  зберегти оригінал: **Рішення.xlsx**.
- В імені файла відокремлюйте розширення крапкою. У прозі назву типу пишіть без
  початкової крапки й великими літерами: **DOCX-файл**, **файл типу DOCX**.
  У списку типів файлів зберігайте технічну форму `.docx`.
- Номер версії з крапкою не локалізуйте: **.NET Framework 4.8**.
- **Trial** → **ознайомлювальна версія**; **Preview** → **підготовча версія**, якщо
  контекст відповідає визначенню.
- У правовому рядку зберігайте ©; слово *Copyright* зазвичай опускайте. Точну
  юридичну формулу беріть із чинної термінологічної бази, не з цього знімка.
