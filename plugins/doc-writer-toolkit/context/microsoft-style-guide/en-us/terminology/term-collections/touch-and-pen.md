# Touch and pen interaction terms

- Use *select* in input-neutral procedures and gesture terms only in touch-specific guidance.
- Use *tap*, not *tap on*; hyphenate *double-tap*.
- Use *tap and hold* for sustained contact required by the product.
- Use *pan* for controlled multidirectional movement through content.
- Use *flick* for a quick movement through items and *swipe* for the product's defined
  short directional gesture.
- Use *pinch* and *stretch* only for the documented zoom gestures.
- Describe the number of fingers or pen action when it changes the result.
- Provide keyboard or other supported alternatives for essential gestures.
