# Security terms

- Use *attacker* or a precise role instead of *hacker* when describing malicious activity.
- Distinguish authentication, authorization, credentials, permissions, and access rights.
- Distinguish threat, vulnerability, exploit, incident, breach, malware, and virus.
- Write *anti-malware* with a hyphen; preserve official product names.
- Use *encrypt* and *decrypt* for reversible cryptographic operations; do not use them as
  vague synonyms for encoding, hashing, or password protection.
- Prefer *allow list* and *block list* over *whitelist* and *blacklist*.
- Use *sign in* and *sign out* as verbs; *sign-in* and *sign-out* as modifiers or nouns
  only where established.
- Do not promise absolute security. State the threat, control, limitation, and remaining risk.
