# Units of measure

- Use numerals with measurements, including values below 10.
- Use an established unit name or symbol consistently within a comparable set.
- Do not add periods or plural endings to unit symbols.
- Put a space between the number and symbol unless the standard, UI, or syntax specifies otherwise.
- Preserve case because it can change the unit's meaning.
- Define specialized or uncommon units for the intended audience.
- Localize decimal separators, grouping, unit preference, and spacing where required.
- Do not convert a value when exact source fidelity is required without recording the original.
