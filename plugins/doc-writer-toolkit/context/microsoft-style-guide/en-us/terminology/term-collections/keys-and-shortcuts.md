# Keys and keyboard shortcuts

- Use the key's displayed or official name and preserve its capitalization.
- Bold key names and shortcuts in instructions.
- Join simultaneously selected keys with `+` and no spaces: **Ctrl+Shift+S**.
- Separate keys selected in sequence with commas: **Alt, F, O**.
- Add *key* only when the name could be mistaken for ordinary text or an action.
- Use *keyboard shortcut* for a key or combination that invokes a command.
- Do not combine a mouse action with a key as if it were a shortcut; describe both actions.
- Document keyboard access for important actions even when the UI visually exposes it.
