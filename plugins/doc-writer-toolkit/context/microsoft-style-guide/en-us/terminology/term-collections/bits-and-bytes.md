# Bits and bytes

- Write *bit* and *byte* in lowercase in prose.
- Distinguish lowercase `b` for bits from uppercase `B` for bytes.
- Use established unit forms consistently: `kb`, `MB`, `GB`, and `TB` as defined by
  the product or measurement convention.
- Use IEC binary unit names and symbols when binary quantities must be explicit:
  kibibyte (`KiB`), mebibyte (`MiB`), gibibyte (`GiB`), and tebibyte (`TiB`).
- Put a space between a number and a unit symbol unless the product UI or syntax differs.
- Do not add a period or plural `s` to a unit symbol.
- State whether a transfer rate is in bits or bytes per second.
