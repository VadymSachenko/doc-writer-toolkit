# Mouse interaction terms

- Use input-neutral *select* in general procedures.
- Use *click*, *double-click*, and *right-click* only in mouse-specific instructions.
- Write *click*, not *click on*. Use *double-click* with a hyphen.
- Use *point to* for moving the pointer to an item without selecting it; *hover over* is
  acceptable where that wording is established.
- Use *drag* for holding a mouse button while moving an item.
- Use *scroll* for moving content vertically or horizontally with a mouse or scroll control.
- The plural of the device is *mice*; use *mouse pointers*, not *mice pointers*.
