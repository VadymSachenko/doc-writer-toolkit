# AI and bot terms

- Write *artificial intelligence (AI)* at first use unless the audience knows *AI*.
- Do not describe a system as intelligent without explaining the actual capability.
- Use *machine learning* for systems that learn patterns from data; do not use it as a
  synonym for all AI.
- Use *model* with enough context to identify its function or type.
- Use *bot* for an automated program. Use *chatbot* for a conversational bot and
  *virtual agent* for a bot that provides information or performs tasks.
- Do not imply that a bot or AI system is human, conscious, infallible, or independently responsible.
- Describe generated, recommended, predicted, or automated behavior precisely.
- Use *prompt* for input that directs a generative AI system; distinguish the prompt
  from the model's output.
