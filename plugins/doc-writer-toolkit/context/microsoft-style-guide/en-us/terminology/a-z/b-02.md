# Microsoft terms: B (2)

Load this file only when checking one of the indexed terms below.

<a id="black-hat-hacker"></a>
## black hat hacker

- Follow the referenced topic collection for this term.
- Related guidance: Security term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/black-hat-hacker)

<a id="blacklist"></a>
## blacklist

- Avoid blacklist. Use block list for a list of prohibited or blocked items.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/blacklist)

<a id="blade"></a>
## blade

- Avoid blade for a UI region. Use pane, and describe content as being in a pane.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/blade)

<a id="blank"></a>
## blank

- Avoid this term as a verb to mean removing the contents of a cell in a table or sheet.
- Prefer clear instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/blank)

<a id="blog-blogger-blogroll-weblog"></a>
## blog, blogger, blogroll, weblog

- Prefer blog as a noun or verb.
- Avoid weblog.
- Prefer blogger to refer to a person who writes or publishes entries for a blog.
- Prefer blogroll to refer to a list of links to other online content, particularly blogs, that's provided on a blog page.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/blog-blogger-blogroll-weblog)

<a id="blu-ray-disc"></a>
## Blu-ray Disc

- Prefer this spelling and capitalization when talking about the disc.
- After the first mention, it's OK to abbreviate to BD (no hyphen).
- When referring to the technology (not a specific disc), it's OK to use Blue-ray [X].
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/blu-ray-disc)

<a id="blue-screen-bluescreen"></a>
## blue screen, bluescreen

- Avoid blue screen or bluescreen, either as a noun or as a verb, to refer to an operating system that's not responding.
- As a verb, use stop. As a noun, use stop error.
- Acceptable: blue screen (two words) to refer to the screen display itself.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/blue-screen-bluescreen)

<a id="bluetooth"></a>
## Bluetooth

- Bluetooth is a proper noun and a registered trademark.
- Write with capitalization.
- Don’t include the registered trademark symbol (®).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/bluetooth)

<a id="board"></a>
## board

- Avoid to describe hardware that provides a connection between a peripheral device and a computer.
- Prefer card instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/board)

<a id="bold"></a>
## bold

- Prefer only as an adjective, not as a noun or verb.
- Avoid bolded, boldface, or boldfaced.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/bold)

<a id="bookmark"></a>
## bookmark

- One word.
- Prefer favorite, not bookmark, to refer to a saved site or webpage.
- Related guidance: favorite.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/bookmark)

<a id="boolean"></a>
## Boolean

- Write with capitalization.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/boolean)

<a id="boot"></a>
## boot

- Avoid this term as a verb.
- Prefer turn on to refer to turning on power to a device.
- In content for a technical audience, it's OK to use boot as an adjective, as in boot sector and boot sequence—but use startup instead if possible.
- If the UI or API uses boot in a label or element name, use boot to refer to the label or element name, but use start or startup to refer to the action or…
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/boot)

<a id="bottom-left-bottom-right"></a>
## bottom left, bottom right

- Avoid except in discussions of the BottomLeft and BottomRight properties.
- Prefer lower left and lower right instead.
- Hyphenate lower left and lower right as adjectives.
- Related guidance: lower left, lower-left, lower right, lower-right.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/bottom-left-bottom-right)

<a id="bounding-outline"></a>
## bounding outline

- Prefer to describe the visible element, usually a dotted rectangle, that surrounds a set of selected elements.
- If necessary, use dotted rectangle or dotted box to describe the bounding outline in content for a general audience, and then use bounding outline in subsequent references.
- Avoid marquee as a synonym.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/bounding-outline)

<a id="box"></a>
## box

- Most of the time, avoid talking about UI elements.
- When you need to refer to dialog box elements by name, use box instead of field to refer to any box except a check box or a list box.
- For a check box, use the complete term, check box.
- For an element that displays a list, such as a drop-down list box, use list instead of box for clarity.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/box)

<a id="broadcast"></a>
## broadcast

- OK to use as an adjective, a noun, or a verb.
- Prefer broadcast, not broadcasted, as the past-tense form of the verb.
- Prefer webcast to refer to a broadcast delivered on the web.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/broadcast)
