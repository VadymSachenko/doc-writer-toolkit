<a id="data-datum"></a>
## data, datum

- Prefer data as both a singular and plural noun.
- Avoid datum.
- Always use data with a singular verb, even if you're talking about more than one data set.
- Avoid the data are.
- Write in lowercase data unless it's at the beginning of a sentence or phrase.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/data-datum)

<a id="decrement"></a>
## decrement

- Prefer only in content for a technical audience.
- As a verb, use only to refer to decreasing an integer count by one.
- Avoid this term as a synonym for decrease.
- Acceptable: decrement as an adjective when discussing decrement operators and values.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/decrement)

<a id="deinstall"></a>
## deinstall

- Avoid except to reference the term when it appears in the UI or an API.
- Avoid deinstall to refer to the related action.
- Prefer remove instead.
- Example The DeInstall method removes the specified network component from the operating system.
- Related guidance: uninstall.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/deinstall)

<a id="delete"></a>
## delete

- Prefer this term as a verb to describe the results of using the Delete or Cut command, such as moving files to the Recycle Bin in Windows, moving items to the Deleted folder in…
- Prefer delete to describe these actions even if the customer uses a different method, such as by dragging a file to the Recycle Bin or using the Cut command.
- Prefer delete to refer to actions that result from pressing the Delete or Backspace key on the computer, such as deleting selected text.
- Avoid delete as a synonym for remove.
- Avoid cut or erase as a synonym for delete.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/delete)

## demilitarized zone (DMZ)

<a id="desktop"></a>
## desktop

- Prefer to refer to the work area on the Windows screen.
- Describe the desktop as client area only in content for a technical audience and only if necessary.
- Acceptable: desktop when it's necessary to distinguish the core version of an app from its variations.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/desktop)

<a id="destination"></a>
## destination

- Prefer a more precise term, such as website or folder, to describe an end point, such as the location reached when a customer clicks a hyperlink, the folder to which a file is copied…
- Prefer destination as a modifier only if necessary for clarity.
- Avoid target as a synonym.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/destination)
