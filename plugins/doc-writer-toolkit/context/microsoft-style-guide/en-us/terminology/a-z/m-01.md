## machine learning

- In general discussions, use lowercase.
- Prefer title-style capitalization to refer to named services, such as Machine Learning API and Machine Learning Studio.

<a id="marquee"></a>
## marquee

- Acceptable: marquee to refer to the scrolling text feature on webpages.
- Avoid to refer to the feature that draws a dotted line around a selection on the screen.
- Prefer bounding outline instead.
- Related guidance: bounding outline, dotted rectangle.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/marquee)

<a id="master-slave-master-subordinate"></a>
## master/slave, master/subordinate

- Avoid master/slave. In content for a technical audience, it's OK to substitute subordinate for slave.
- Prefer master/subordinate as an adjective.
- Describe arrangements in which one device controls another as a master/subordinate arrangement, or refer to the controlling device as the master server and the controlled device as the subordinate server.
- When you need to clarify the concept, it's OK to reference the use of slave as an adjective by saying also known as the slave server. It's OK to use master server and slave…
- Avoid using slave as an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/master-slave-master-subordinate)

<a id="maximize-button-maximize"></a>
## Maximize button, maximize

- Prefer the Maximize button to refer to the button, not just Maximize. Maximize as part of the Maximize button is always bold.
- Avoid Maximize box or Maximize icon.
- Acceptable: maximize as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/maximize-button-maximize)

<a id="medium-media"></a>
## medium, media

- Prefer medium, not media, as a singular subject.
- Ensure that the verb agrees with the subject (that is, the medium is and the media are).
- Prefer media to describe:
- Materials or substances, such as fiber optic cable or wire, through which data is transmitted. - Materials on which data is recorded or stored, such as magnetic disks, CDs, or tapes. - The mass-communications…
- Avoid media as a shortened form of multimedia.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/medium-media)
