# Microsoft terms: G (2)

Load this file only when checking one of the indexed terms below.

<a id="grow"></a>
## grow

- Avoid this term as a verb meaning to increase the size of something.
- Prefer a more specific verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/grow)
