# Microsoft terms: O (1)

Load this file only when checking one of the indexed terms below.

<a id="object"></a>
## object

- Avoid object as a synonym for item or thing.
- Instead, refer to a specific object.
- For example, in object-oriented programming, an object is an instance of a class that contains both methods and data and is treated as one entity.
- Similarly, in COM-based technologies, an object is a combination of code and data that implements one or more interfaces.
- In assembly language, object refers to the object module, which contains data that has been translated into machine code.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/object)

<a id="obsolete"></a>
## obsolete

- Avoid this term as a verb.
- Prefer a phrase such as make obsolete instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/obsolete)

<a id="of"></a>
## of

- Avoid of after another preposition in phrases such as off of or outside of.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/of)

- Follow the referenced topic collection for this term.
- Related guidance: Cloud-computing term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/off-premises-on-premises)

<a id="offline"></a>
## offline

- One word.
- Prefer only in the sense of not being connected to or part of a system or network.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/offline)

<a id="ok-okay"></a>
## OK, okay

- Prefer OK instead of okay or all right. Never use alright.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/ok-okay)

<a id="on"></a>
## on

- Prefer on as a preposition with:
- Menus - Tabs - Taskbar, toolbar, ruler, and desktop - Disks, in the sense of a program being on a disk - Networks - Hardware platforms - The web
- In COM programming, an interface is implemented on an object.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/on)

<a id="on-the-fly"></a>
## on the fly

- OK to use in content for a technical audience to refer to something that's not created until it's needed.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/on-the-fly)

<a id="on-screen"></a>
## on-screen

- Write with a hyphen as an adjective or adverb.
- Instead of using as an adverb, try to rewrite by using a phrase such as on the screen.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/on-screen)

## on-screen keyboard

- Follow the referenced topic collection for this term.

<a id="onboarding"></a>
## onboarding

- Avoid this term when you mean the process of introducing employees to a new role or organization.
- Prefer orientation instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/onboarding)

<a id="once"></a>
## once

- Avoid this term as a synonym for after.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/once)

<a id="online"></a>
## online

- One word, both as an adjective and adverb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/online)

<a id="online-services"></a>
## online services

- Avoid.
- If you need to refer generally to apps and services that you access online, mention the services by name or use services.
- Avoid online services to refer to protocols and data formats, such as XML, SOAP, and WSDL, that provide the means for integrating web-based apps.
- Prefer web services instead.
- Related guidance: web services.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/online-services)

<a id="onto"></a>
## onto

- Prefer one word (onto) to indicate moving something to a position on top of something else, as in drag the icon onto the desktop.
- Related guidance: sign in, sign out.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/onto)

<a id="opcode"></a>
## opcode

- Acceptable: opcode to refer to a programming term, such as the opcode parameter.
- Avoid opcode as a shortened form of operation code.
- Prefer operation code instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/opcode)

<a id="open"></a>
## open

- Prefer open, not opened, to describe the open state: an open folder.
- Prefer open, not start or launch, to describe opening a program or app.
- Avoid open to describe selecting a command, a menu, an option, or other similar element.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/open)

<a id="open-source-open-source"></a>
## open source, open-source

- Write in lowercase unless you're talking about the Open Source Initiative.
- Hyphenate open-source as an adjective preceding a noun, as in open-source software. Don't use open-sourced as an adjective .
- Don't hyphenate in other instances, such as Open source is a development model in which ....
- Avoid OSS as an abbreviation for open-source software.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/open-source)

<a id="operating-environment-operating-system"></a>
## operating environment, operating system

- OK to use in content for a technical audience, but avoid in content for a general audience.
- Prefer operating environment or environment to describe both hardware and the operating system software.
- Prefer operating system to describe only the software.
- Prefer graphical environment to describe the graphical user interface (GUI) of an operating system.
- Prefer on, under, or with as prepositions with operating system.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/operating-environment-operating-system)

<a id="opt-in-opt-out"></a>
## opt in, opt out

- Write opt in and opt out as verbs. Write opt-in and opt-out as nouns or adjectives. State what the person accepts or declines.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/opt-in-opt-out)
