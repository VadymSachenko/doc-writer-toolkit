# Microsoft terms: M (2)

Load this file only when checking one of the indexed terms below.

<a id="memory"></a>
## memory

- Always refer to a specific kind of memory, such as random-access memory ( RAM) , read-only memory (ROM), or hard drive space.
- Write in full RAM and ROM on the first mention unless you're positive that your audience is familiar with the term.
- In the noun forms that refer to memory measurements, use of in a prepositional phrase, as in 512 MB of RAM.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/memory)

<a id="memory-resident"></a>
## memory-resident

- Write with a hyphen.
- Prefer memory-resident program, not TSR, in content for a general audience.
- In content for a technical audience, it's OK to use TSR as an abbreviation for terminate-and-stay-resident.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/memory-resident)

<a id="menu-item"></a>
## menu item

- In general, avoid talking about the UI.
- Instead, talk about what the customer needs to do.
- If you must refer to commands on menus in content for a general audience, call them commands, not menu items.
- In content for developers, it's OK to use menu items in the context of UI development.
- Related guidance: Describing interactions with UI, Formatting text in instructions.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/menu-item)

<a id="message"></a>
## message

- Avoid message as a verb.
- Prefer send, receive, email, text, or send an IM instead.
- Prefer email, message, or email message to refer to an item sent or received using email.
- Prefer text or text message to refer to an item sent or received using SMS.
- To refer to an item sent or received using instant messaging, spell out instant message on the first mention if your audience might not be familiar with the abbreviation.
- Related guidance: email.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/message)

<a id="micro"></a>
## micro-

- In general, don't hyphenate words beginning with micro-, such as microprocessor and microsecond, unless it's necessary to avoid confusion.
- When in doubt, check The American Heritage Dictionary.

- Related guidance: Hyphens.

## Microsoft

- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/microsoft)

<a id="microsoft-account"></a>
## Microsoft account

- Don't capitalize account.
- Prefer Microsoft account to refer to the sign-in credentials (email address and password) that give someone access to Microsoft services, such as Skype, Xbox Live, and Outlook.com, and to products, such as Xbox consoles.
- Avoid Microsoft account to refer to corporate domain accounts, which are used to connect to corporate resources and services.
- Microsoft account was formerly known as Windows Live ID.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/microsoft-account)

<a id="microsoft-software-license-terms"></a>
## Microsoft Software License Terms

- When referring to the license agreement, use Microsoft Software License Terms, not End-User License Agreement or EULA.
- On the first mention, use the full name.
- On subsequent mentions, it's OK to shorten to license terms.
- Avoid licensing terms.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/software-license-terms)

<a id="microsoft-store"></a>
## Microsoft Store

- Prefer the full name Microsoft Store. Note the capitalization.
- In general, don’t include the (the Microsoft Store) unless it's necessary to fix awkward wording.
- Avoid it in marketing content. Exceptions In the UI, it’s OK to omit Microsoft when space is limited, and it’s OK to include the (the Microsoft Store, the Store) when it reads better.
- Avoid Windows Store or Xbox Store. Always use the singular Microsoft Store. Don’t use Microsoft Stores.
- Describe a brick-and-mortar store as a location.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/microsoft-store)

<a id="minimize-button-minimize"></a>
## Minimize button, minimize

- Prefer the Minimize button to refer to the button, not just Minimize. Minimize as part of the Minimize button is always bold.
- Avoid Minimize box or Minimize icon.
- Acceptable: minimize as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/minimize-button-minimize)

<a id="minus-sign"></a>
## minus sign (–)

- Prefer an en dash for a minus sign.
- Exception In an example in which the customer must type a hyphen to represent a minus sign, use a hyphen in the example and clarify which key should be selected.
- Related guidance: Keys and keyboard shortcuts term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/minus-sign)

## mission critical, mission-critical

- Two words.
- Hyphenate as an adjective.
- Prefer business-critical or simply critical instead if you can.
- When necessary, it's OK to use this term in a technical context to describe an application or business process.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/mission-critical)
