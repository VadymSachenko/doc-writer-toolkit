# Microsoft terms: B (1)

Load this file only when checking one of the indexed terms below.

<a id="back-end-back-end"></a>
## back end, back-end

- Avoid if you can substitute a more specific term, such as server, operating system, database, or network.
- Two words as a noun.
- Hyphenate as an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/back-end)

<a id="back-up-backup"></a>
## back up, backup

- Two words as a verb, one word as an adjective or a noun.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/back-up-backup)

<a id="backbone"></a>
## backbone

- Avoid in content for a general audience.
- You don't need to define backbone in content for a technical audience.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/backbone)

<a id="backlight"></a>
## backlight

- One word.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/backlight)

<a id="backspace"></a>
## backspace

- One word.
- OK to use as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/backspace)

<a id="backtab"></a>
## backtab

- Avoid.
- Instead, instruct the customer to use Shift+Tab.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/backtab)

<a id="badge"></a>
## badge

- A star, medal, or other virtual recognition that indicates an achievement in a game or other program.
- Prefer title-style capitalization for a badge name.
- Write in lowercase the word badge.
- Related guidance: achievement.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/badge)

<a id="baseline"></a>
## baseline

- Prefer baseline (one word) to refer to an established standard, as in baseline data.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/baseline)

<a id="beep"></a>
## beep

- Prefer instead of alarm or tone to refer to a beeping sound.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/beep)

<a id="below"></a>
## below

- Avoid this term when you mean later.
- Avoid this term as an adjective preceding a noun (the below section) or following a noun (the code below).
- Prefer a hyperlink, or use later or the following.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/below)

<a id="bi"></a>
## bi-

- In general, don't hyphenate words beginning with bi-, such as bidirectional, bimodal, and bimonthly, unless it's necessary to avoid confusion.
- When in doubt, check The American Heritage Dictionary.
- To learn more about hyphenation,
- Related guidance: Hyphens.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/bi)

## big data

<a id="big-endian-little-endian"></a>
## big-endian, little-endian

- Acceptable: big-endian and little-endian in content for a technical audience. Big-endian refers to the method of physically storing numbers so that the most significant byte is placed first. Little-endian is the opposite.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/big-endian-little-endian)

<a id="bio"></a>
## bio

- OK to use as an abbreviation for biography.
- Global tip In many languages, the full term is translated because an abbreviation isn't available.
- So you'll still need to allow ample space for expansion in localized text.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/b/bio)
