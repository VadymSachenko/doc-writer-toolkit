# Microsoft terms: Z (1)

Load this file only when checking one of the indexed terms below.

<a id="z"></a>
## z-

- Hyphenate all words referring to entities that begin with z used as a separate letter, such as z-axis, z-coordinate, z-order, and z-test.
- Avoid italic formatting for the z in these words unless the entire word is italic.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/z/z)

<a id="z-axis"></a>
## z-axis

- Write in lowercase.
- Hyphenate.
- In 3D charts, the z-axis shows depth and generally represents values.
- On the first mention, refer to the z-axis as the value (z) axis, where both the x-axis and y-axis are category axes.
- On subsequent mentions, use z-axis.
- Related guidance: value axis.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/z/z-axis)

<a id="zero-zeros"></a>
## zero, zeros

- Prefer zeros, not zeroes, as the plural of zero.
- When a measurement includes 0, use the plural form of the spelled-out unit of measure.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/z/zero-zeros)

<a id="zip-code"></a>
## ZIP Code

- Acceptable: ZIP Code in content that's intended for a US audience only.
- Otherwise, use postal code.
- Write with capitals as shown.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/z/zip-code)

<a id="zoom-in-zoom-out"></a>
## zoom in, zoom out

- Prefer zoom in and zoom out as generic verbs in instructions for all input methods.
- Avoid dezoom or unzoom.
- Related guidance: Touch and pen interaction term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/z/zoom-in-zoom-out)
