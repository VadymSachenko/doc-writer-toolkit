# Microsoft terms: U (1)

Load this file only when checking one of the indexed terms below.

<a id="uk"></a>
## UK

- Avoid using as an abbreviation for United Kingdom unless space is limited.
- Avoid this term as a synonym for Great Britain (GB) or England.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/uk)

<a id="ultrabook"></a>
## Ultrabook

- Prefer only to differentiate the Intel device from other types of thin and light laptops.
- Related guidance: Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/ultrabook)

<a id="un"></a>
## un-

- In general, don’t hyphenate words beginning with un-, such as undo and unread, unless it’s necessary to avoid confusion, as in un-ionized, or unless un- is followed by a proper noun, as in un-American.…
- To learn more about hyphenation,
- Related guidance: Hyphens.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/un)

<a id="unavailable"></a>
## unavailable

- Most of the time, talk about the actions that customers should take rather than describing UI.
- When you must discuss UI, use not available or isn’t available instead of unavailable, disabled, or grayed to describe commands and options that are in an unusable state.
- Prefer appears dimmed if you must describe their appearance.
- Acceptable: unavailable to describe an outage or a service that isn’t offered to certain customers.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/unavailable)

<a id="uncheck-unmark-unselect"></a>
## uncheck, unmark, unselect

- Avoid to refer to clearing a check box.
- Prefer clear instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/uncheck-unmark-unselect)

<a id="undelete"></a>
## undelete

- Avoid.
- Related guidance: restore.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/undelete)

<a id="underline-vs-underscore"></a>
## underline vs. underscore

- Prefer underline to describe text formatting that puts a line under the characters.
- Prefer underscore to refer to the underscore character ( \_ ).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/underline-vs-underscore)

<a id="undo"></a>
## undo

- OK to use as a verb to describe the action associated with the Undo command.
- Avoid this term as a noun.
- For example, don't say, After an undo, you can redo ....
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/undo)

<a id="uninstall"></a>
## uninstall

- Prefer uninstall as a verb to describe removing apps, programs, and hardware drivers from a device.
- Avoid uninstall as a noun.
- Related guidance: remove.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/uninstall)

<a id="unregister"></a>
## unregister

- Avoid in content for a general audience.
- Acceptable: unregister in content for developers.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/unregister)

<a id="unwanted-software"></a>
## unwanted software

- Follow the referenced topic collection for this term.
- Related guidance: Security term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/unwanted-software)

<a id="upgrade"></a>
## upgrade

- Prefer this term as a verb to describe replacing an installed version of a product with a newer version of the same product.
- Prefer this term as a noun to describe the process of upgrading software.
- Avoid upgrade as a synonym for update, service pack, or any other release that occurs between product versions.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/upgrade)

<a id="upload"></a>
## upload

- Prefer this term as a verb to describe transferring files from a local device to a website, server, or share.
- When you use upload as a verb, describe what the customer is transferring and where the customer is transferring it to. In grammatical terms, use both a subject (the thing to be uploaded) and…
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/upload)

<a id="upnp"></a>
## UPnP

- Don't spell out as Universal Plug and Play.
- Avoid this term as a synonym for Plug and Play or PnP.
- Prefer UPnP as an adjective followed by certified, if appropriate, and a specific term, such as device, architecture, or standards.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/upnp)

<a id="upper-left-upper-right"></a>
## upper left, upper right

- Hyphenate as adjectives.
- Prefer instead of top left and top right.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/upper-left-upper-right)

<a id="uppercase"></a>
## uppercase

- Most of the time, use capital letters instead of uppercase. It's OK to use uppercase when comparing with lowercase or to follow the UI.
- One word.
- Avoid uppercase as a verb.
- Avoid uppercased.
- When using uppercase and lowercase together, don't use a suspended hyphen (as in upper- and lowercase).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/uppercase)

<a id="upsize"></a>
## upsize

- Avoid . Use scale up instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/upsize)

<a id="upward"></a>
## upward

- Prefer instead of upwards.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/upward)

<a id="uri"></a>
## URI

- Use URI when the resource identifier can be a URL, URN, or another identifier. Use URL only when the identifier is specifically a web address.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/uri)

<a id="url"></a>
## URL

- In content for a general audience, use address rather than URL.
- In content for a technical audience, don't spell out URL on the first mention.
- If you have a reason to spell out URL, use uniform resource locator.
- Prefer a, not an, as an article preceding URL.
- Prefer of (not for) to describe the relationship of the word URL to a resource.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/u/url)
