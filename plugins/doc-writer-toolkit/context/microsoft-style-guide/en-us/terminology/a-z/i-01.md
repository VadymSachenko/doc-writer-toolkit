# Microsoft terms: I (1)

Load this file only when checking one of the indexed terms below.

<a id="i-e"></a>
## i.e.

- Avoid.
- Prefer that is instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/ie)

<a id="icon"></a>
## icon

- Prefer only to describe a graphic representation of an object that a customer can select and open, such as a drive, folder, document, or app.
- Avoid icon to describe graphical dialog box options or options that appear on ribbons, toolbars, toolboxes, or other areas of a window.
- For options that have graphics rather than text labels, use the most descriptive term available, such as button, box, or check box.
- To refer to the graphic itself, if there's no other identifying label, use symbol, as in warning symbol.
- When referring to an icon, use bold formatting for the icon name.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/icon)

<a id="iconize"></a>
## iconize

- Avoid.
- Prefer shrink to an icon or minimize instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/iconize)

<a id="if-vs-whether-vs-when"></a>
## if vs. whether vs. when

- Prefer if to express a condition, use whether to express uncertainty, and use when for situations that require preparation or to denote the passage of time.
- In informal writing for the web, it's OK to use if to express uncertainty.
- Avoid whether or not to express uncertainty.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/if-vs-whether-vs-when)

<a id="illegal"></a>
## illegal

- Avoid this term when you mean invalid or not valid.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/illegal)

<a id="image-map"></a>
## image map

- Two words unless you're referring to a programming map such as the elements of the ImageMap class.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/image-map)

<a id="imbed"></a>
## imbed

- Avoid.
- Prefer embed instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/imbed)

<a id="impact"></a>
## impact

- Prefer only as a noun.
- As a verb, use affect or another synonym.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/impact)

<a id="inactive-inactive-state"></a>
## inactive, inactive state

- Avoid in content for a general audience.
- Describe what the customer needs to do in simpler terms.
- In content for a technical audience, use instead of not current to refer to windows, apps, documents, files, devices, or portions of the screen that are available but not currently in use.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/inactive-inactive-state)

<a id="inbound"></a>
## inbound

- Avoid to describe email being delivered.
- Prefer incoming instead.
- Acceptable: inbound and outbound to describe marketing tactics.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/inbound)

<a id="incoming-outgoing"></a>
## incoming, outgoing

- Prefer to refer to email messages that are being downloaded or sent.
- Avoid inbound and outbound.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/incoming-outgoing)

<a id="increment"></a>
## increment

- In content for developers and IT pros, use increment as a verb only to mean increase by one or by a specified interval.
- As a noun, use increment to refer to the specified interval.
- In other content, it's OK to use increment as long as the meaning is clear.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/increment)

<a id="indent-outdent"></a>
## indent, outdent

- Prefer indent to refer to a single instance of indentation.
- For example, use hanging indent, nested indent, negative indent, or positive indent.
- Prefer indentation to refer to the general concept.
- Avoid outdent.
- Avoid indenting or outdenting into the margin.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/indent-outdent)

<a id="index-indexes-indices"></a>
## index, indexes, indices

- Prefer indexes as the plural form of index. Use indices only in the context of mathematical expressions.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/index-indexes-indices)

<a id="info"></a>
## info

- Acceptable: info as an abbreviation for information in content with an informal tone.
- Global tip The abbreviated form isn't available in all languages, so allow enough space for the full translated term in localized content.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/info)

<a id="infrastructure-as-a-service-iaas"></a>
## infrastructure as a service (IaaS)

- Follow the referenced topic collection for this term.
- Related guidance: Cloud-computing term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/infrastructure-as-a-service)

<a id="initialize"></a>
## initialize

- Avoid this term when you mean start a program or app or turn on a device.
- Acceptable: initialize to refer to preparing a disk or device for use or setting a variable to an initial value.
- Related guidance: start, restart, turn on, turn off.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/initialize)

<a id="initiate"></a>
## initiate

- Avoid this term when you mean start a program or app.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/initiate)

<a id="inline"></a>
## inline

- One word.
- Don't hyphenate.
- Prefer inline styles to describe styles embedded in tags using the STYLE parameter, which override styles in cascading style sheets.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/inline)

<a id="input"></a>
## input

- Avoid this term as a verb.
- Prefer enter or another appropriate verb instead.
- In content for a general audience, don't use as a noun to mean data or values entered into an app.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/input)
