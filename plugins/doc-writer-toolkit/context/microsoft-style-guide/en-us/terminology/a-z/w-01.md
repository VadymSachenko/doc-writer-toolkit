# Microsoft terms: W (1)

Load this file only when checking one of the indexed terms below.

<a id="w3c"></a>
## W3C

- Don't spell out.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/w3c)

<a id="want"></a>
## want

- Prefer instead of wish or desire when the customer has a choice of actions.
- Avoid when you mean need, which indicates a requirement or obligation.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/want)

<a id="we"></a>
## we

- In general, don't use.
- Focus on the customer, and avoid making Microsoft the subject.
- Acceptable: phrasing like we recommend if it helps you avoid awkward phrasing like it's recommended, but write around it if you can.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/we)

<a id="wearable-wearable-device"></a>
## wearable, wearable device

- Follow the referenced topic collection for this term.
- Related guidance: Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/wearable-wearable-device)

<a id="web-services"></a>
## web services

- Prefer web services to refer to protocols and data formats, like XML, SOAP, and WSDL, that provide the means for integrating web-based apps.
- Avoid web service or web services to refer generally to apps and services that you access online.
- Instead, mention the service by name or use service or services instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/web-services)

<a id="web-world-wide-web-www"></a>
## web, World Wide Web, WWW

- Write in lowercase web as a modifier except to match UI or in feature names that include web.
- Avoid the phrase World Wide Web. Use the web instead.
- Write in lowercase www in URLs and internet addresses.
- Prefer on to refer to material existing on the web.
- Prefer to or on to refer to the action of creating and publishing something to the web or on the web.
- Related guidance: URLs and web addresses.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/web-world-wide-web-www)

<a id="where"></a>
## where

- Prefer to introduce a list, as in code or formulas, to define the meaning of elements such as variables or symbols.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/where)

<a id="while"></a>
## while

- Prefer only to refer to something occurring in time.
- Avoid this term as a synonym for although, whereas, on the contrary, or in spite of.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/while)

<a id="white-hat-hacker"></a>
## white hat hacker

- Follow the referenced topic collection for this term.
- Related guidance: Security term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/white-hat-hacker)

<a id="white-paper"></a>
## white paper

- Write white paper as two words. Use it for an authoritative report or technical paper.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/white-paper)

<a id="white-space"></a>
## white space

- Two words.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/white-space)

<a id="whitelist"></a>
## whitelist

- Avoid whitelist. Use allow list for a list of permitted items.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/whitelist)

<a id="who-vs-that"></a>
## who vs. that

- Prefer who instead of that to introduce clauses referring to people.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/who-vs-that)

<a id="wi-fi"></a>
## Wi-Fi

- Try to use a general phrase instead, such as wireless network, or refer to the specific technology that you're describing, such as wireless LAN.
- Wi-Fi is a proper noun and a registered trademark.
- Write with capitals and hyphenate when referring specifically to Wi-Fi technologies.
- Avoid WiFi, wifi, or Wifi.
- Don’t include the registered trademark symbol (®).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/wi-fi)

<a id="wildcard-character"></a>
## wildcard character

- Prefer wildcard character, not just wildcard, to describe a character used to represent one or many characters, such as the asterisk (\) or question mark (?).
- Wildcard is one word.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/wildcard-character)

<a id="window"></a>
## window

- Avoid this term as a verb.
- Related guidance: Describing interactions with UI, Formatting text in instructions.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/window)

<a id="windows-7-windows-8-windows-10"></a>
## Windows 7, Windows 8, Windows 10

- Always use the entire name.
- Don't precede the name with Microsoft.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/windows-7-windows-8-windows-10)

<a id="windows-explorer"></a>
## Windows Explorer

- Avoid.
- Related guidance: File Explorer.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/windows-explorer)

<a id="windows-windows-based"></a>
## Windows, Windows-based

- Prefer Windows as a modifier for aspects or elements of the Windows operating system.
- Avoid Windows-based.
- Acceptable: Windows user sparingly to avoid awkward constructions, but try to avoid user in general.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/windows-windows-based)

## wireframe
