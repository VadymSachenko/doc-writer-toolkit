# Microsoft terms: L (2)

Load this file only when checking one of the indexed terms below.

<a id="link"></a>
## link

- Follow the referenced topic collection for this term.
- Related guidance: hyperlink.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/link)

<a id="list-box"></a>
## list box

- Two words.
- In general, avoid talking about UI.
- Instead, talk about what the customer needs to do.
- When you need to help a customer interact with UI, refer to a list box by its label and the word list, not list box.
- For the Mac, use pop-up list to refer to unnamed list boxes.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/list-box)

<a id="load"></a>
## load

- Avoid this term as a synonym for start, install, run, set up, or download.
- In content for a technical audience, use load only to describe dynamically calling graphics, documents, or installed programs or data, such as drivers, DLLs, scripts, registry entries, and profiles, into RAM or a program's…
- Prefer unload or remove to refer to removing these items from memory.
- For games, use load to refer to continuing gameplay at the last place that a game was saved. Load game and Load saved game are typical button labels for game UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/load)

<a id="lock-up"></a>
## lock up

- Avoid to describe a hardware failure or a program or an operating system that has stopped responding.
- Prefer fail instead for hardware, and stop responding for programs or the operating system.
- Related guidance: fail, stop, stop responding.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/lock-up)

<a id="log-on-log-off"></a>
## log on, log off

- Avoid log in, login, log into, log on, logon, log onto, log off, log out, logout, or a similar term unless it appears in the UI (and you're writing instructions).
- Prefer sign in or sign out instead.
- Related guidance: sign in, sign out, connect.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/log-on-log-off)

<a id="low-resolution"></a>
## low-resolution

- Write with a hyphen.
- Avoid abbreviating as lo-res.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/low-resolution)

<a id="lower"></a>
## lower

- Avoid to indicate product version numbers.
- Prefer earlier instead.
- Related guidance: earlier.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/lower)

<a id="lower-left-lower-left-lower-right-lower-right"></a>
## lower left, lower-left, lower right, lower-right

- Hyphenate as adjectives.
- Prefer instead of bottom left and bottom right.
- Accessibility note Don't use directional terms (left, right, up, down) as the only clue to location.
- Individuals with cognitive impairments might have difficulty interpreting them, as might people who are blind and use screen-reading software.
- Acceptable: a directional term if another indication of location, such as in the Save As dialog box, on the Standard toolbar, or in the title bar, is also included.
- Related guidance: a change in the interface as.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/lower-left-lower-right)

<a id="lowercase"></a>
## lowercase

- One word.
- Avoid lowercased.
- Avoid this term as a verb.
- When using lowercase and uppercase together, don't use a suspended hyphen (as in upper- and lowercase).
- Write in full both words instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/l/lowercase)
