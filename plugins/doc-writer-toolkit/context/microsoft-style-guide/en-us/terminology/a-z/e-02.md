# Microsoft terms: E (2)

Load this file only when checking one of the indexed terms below.

- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/endpoint)

<a id="ensure-insure-assure"></a>
## ensure, insure, assure

- Ensure, insure, and assure are interchangeable in many situations.
- To improve worldwide readability, Microsoft style makes these distinctions:
- Prefer ensure to mean to make sure or to guarantee. - Use insure to mean to provide insurance. - Use assure to mean to state positively or to make confident.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/ensure-insure-assure)

<a id="enterprise"></a>
## enterprise

- Acceptable: enterprise for an IT pro or developer audience to mean a large company or corporation.
- Prefer this term as an adjective if possible, as in enterprise computing or enterprise deployment, rather than as a noun to mean corporation.
- Avoid in content for a general audience.
- Related guidance: company vs. organization.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/enterprise)

<a id="entry-field"></a>
## entry field

- Avoid to refer to a text-entry field.
- Describe the box by its label.
- If you must use a descriptor, use box.
- Acceptable: entry field in a database context.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/entry-field)

<a id="environment-variable"></a>
## environment variable

- Prefer instead of environment setting or environment string.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/environment-variable)

<a id="erase"></a>
## erase

- Avoid this term as a synonym for delete unless the app requires it, as in Paint.
- Related guidance: delete.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/erase)

<a id="et-al"></a>
## et al.

- Avoid except in a citation that includes three or more authors.
- Prefer and others instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/et-al)

<a id="etc"></a>
## etc.

- Avoid.
- Instead be specific.
- When space is limited, use such as or like followed by an example or two.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/etc)

<a id="euro"></a>
## euro

- Write in lowercase.
- Plural: euros
- Symbol: €
- In US content, place the euro symbol in front of the amount.
- Different locales might place the euro symbol elsewhere, as appropriate.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/euro)

<a id="executable-exe"></a>
## executable, .exe

- Prefer executable and .exe as adjectives, not nouns.
- Prefer an, not a, as the article preceding .exe: an .exe file.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/executable-exe)

<a id="execute"></a>
## execute

- Avoid except to follow the UI.
- Prefer run instead.
- Even if the UI includes execute, the action is run.
- Always use run in the context of macros and queries.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/execute)

<a id="exit"></a>
## exit

- Avoid to describe closing an app or program.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/exit)

<a id="expand-collapse"></a>
## expand, collapse

- Prefer to describe a customer action that displays more or fewer subentries in a folder or outline.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/expand-collapse)

<a id="expose"></a>
## expose

- Avoid in content about UI.
- Prefer make available, display, or a similar term.
- Acceptable: expose in content about object-oriented programming technologies, such as the Component Object Model (COM), to describe making an object's services available to clients.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/expose)

<a id="extend"></a>
## extend

- Prefer extend instead of grow to refer to extending a selection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/e/extend)

## extension, file name extension
