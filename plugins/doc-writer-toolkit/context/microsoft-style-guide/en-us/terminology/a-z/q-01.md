# Microsoft terms: Q (1)

Load this file only when checking one of the indexed terms below.

<a id="quality-high-quality"></a>
## quality, high-quality

- Avoid quality by itself as an adjective.
- Always use high-quality.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/q/quality-high-quality)

<a id="quit"></a>
## quit

- Avoid quit to refer to any of the following:
- Closing an app or a program.
- Prefer close instead. - Closing a document or window.
- Prefer close instead. - The action a program takes to close itself when it has encountered a problem and can't continue.
- Prefer close instead. - Ending a session on a computer or network.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/q/quit)
