# Microsoft terms: W (2)

Load this file only when checking one of the indexed terms below.

<a id="wireless"></a>
## wireless

- Avoid talking about wireless technology to general users except in the context of connecting to a network.
- Even in that context, whenever you can, discuss connecting to the internet without referring to the technology.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/wireless)

<a id="wizard"></a>
## wizard

- In general, don't use the term wizard unless it appears in the UI.
- Instead, talk about what the customer needs to do to accomplish the task.
- Acceptable: wizard in content for a technical audience that discusses how to develop wizards.
- Prefer lowercase for the generic term wizard.
- Write with capitals wizard if it's part of a feature name that appears in the UI. (This is uncommon.)
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/wizard)

<a id="word-processing-word-processing"></a>
## word processing, word-processing

- Prefer word processor or word processing as a noun.
- Hyphenate word-processing as an adjective.
- Avoid word process or word processing as a verb.
- Prefer write, format, or another term instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/word-processing)

<a id="wordwrap-wordwrapping"></a>
## wordwrap, wordwrapping

- Avoid.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/wordwrap-wordwrapping)

<a id="work-area-workspace"></a>
## work area, workspace

- Work area is two words. Workspace is one word.
- In general, don't discuss UI.
- Instead, talk about what the customer wants to do.
- If it's necessary to describe UI, use workspace to refer to the area within a window where the customer interacts with the UI.
- Prefer work area only when the term has a specific meaning in a particular product.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/work-area-workspace)

<a id="work-style"></a>
## work style

- Two words.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/work-style)

<a id="workgroup"></a>
## workgroup

- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/workgroup)

<a id="working-memory"></a>
## working memory

- Avoid.
- Prefer available memory instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/working-memory)

<a id="workstation"></a>
## workstation

- One word.
- Avoid except in discussions of clients and servers.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/workstation)

<a id="worldwide-vs-international"></a>
## worldwide vs. international

- Prefer worldwide to describe something that encompasses all regions or involves the entire world.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/worldwide-vs-international)

<a id="write-only"></a>
## write-only

- Write with a hyphen.
- Related guidance: read/write, read/write permission.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/write-only)

<a id="write-protect-write-protected"></a>
## write-protect, write-protected

- Write with a hyphen.
- Prefer write-protect as a verb.
- Prefer instead of lock to refer to the action of protecting disks from being overwritten.
- Prefer write-protected as an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/w/write-protect-write-protected)
