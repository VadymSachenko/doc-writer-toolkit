## tool

- Add-in, add-on app, application applet Control Panel
- Related guidance: add-in, add-on.

## top-level folder

- In content for a general audience, use instead of root directory to refer to the directory or folder from which all other directories or folders branch.
- In content for developers, use root directory.

<a id="turn-on-turn-off"></a>
## turn on, turn off

- Prefer instead of power on/power off, start/stop, or switch on/switch off to mean turning the device on and off.
- Avoid to refer to selecting or clearing check boxes in instructions.
- Prefer select and clear instead.
- Acceptable: turn on/turn off to refer to webpage options and toggles.
- Prefer turned on and turned off instead of enabled and disabled to refer to commands and features that can be hidden or deactivated.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/turn-on-turn-off)
