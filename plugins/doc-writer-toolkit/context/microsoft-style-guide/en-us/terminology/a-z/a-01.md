# Microsoft terms: A (1)

Load this file only when checking one of the indexed terms below.

<a id="abort-abortion"></a>
## abort, abortion

- Avoid abortion as a computing term. Use cancel, stop, or another description of the action.
- Avoid abort in general-audience content. Retain it only when a technical audience needs an exact API or system term.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/abort-abortion)

<a id="above"></a>
## above

- Avoid this term when you mean earlier.
- Avoid this term as an adjective preceding a noun (the above section) or following a noun (the code above).
- Prefer a hyperlink, or use previous, preceding, or earlier.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/above)

<a id="access"></a>
## access

- This term is acceptable as a verb to mean obtain access to.
- Avoid access to mean start, create, or open. Use a more specific verb or phrase instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/access)

<a id="accessible"></a>
## accessible

- Reserve accessible and accessibility to refer to things that are easy to use for everyone, including people with disabilities.
- Avoid accessible as a synonym for simple.
- Prefer easy to learn, easy to use, or intuitive. But don't assume that what's easy for you is easy for customers.
- A better choice is to refer to the specific characteristics that make something easy to use, such as a familiar UI or simplified navigation.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/accessible)

<a id="achievement"></a>
## achievement

- Refers to an accomplishment that's formally recognized by a game, site, or app.
- Achievements are sometimes represented by a virtual badge, star, medal, or other reward.
- Prefer title-style capitalization for the achievement name.
- Write in lowercase the word achievement when it follows the achievement name.
- For Microsoft games, use achievement only if the achievement is awarded in a player’s Xbox Live profile.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/achievement)

<a id="active-player-active-user"></a>
## active player, active user

- Prefer active player, not active user, to refer to a person who's currently being tracked or recognized by a motion sensor or camera.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/active-player-active-user)

<a id="add"></a>
## add

- Prefer this term as a verb to describe installing add-ins and add-ons.
- Prefer remove to describe removing them.
- Avoid add to refer to installing apps and programs.
- Prefer install instead.
- Related guidance: install.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/add)

<a id="add-in-add-on"></a>
## add-in, add-on

- Prefer add-in to refer to software that adds functionality to a larger program, such as the Skype Meeting Add-in for Microsoft Outlook. Add-in can also refer to a driver or to a customer-written program…
- Prefer add-on to refer to a hardware device, such as an external drive, that's attached to the device.
- In content for a general audience, use add-in and add-on primarily as modifiers.
- For example, add-in program or add-on drive.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/add-in-add-on)

<a id="adjacent-selection"></a>
## adjacent selection

- Avoid if you can use multiple selection instead.
- Acceptable: adjacent selection if you must emphasize that the selected items are adjacent to one another.
- Avoid contiguous selection.
- Related guidance: multiple selection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/adjacent-selection)

<a id="administer"></a>
## administer

- Prefer instead of administrate.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/administer)

<a id="administrator-admin"></a>
## administrator, admin

- Prefer administrator, admin, or system administrator unless you need to specify a particular kind of administrator, such as a network administrator or a database administrator.
- Don't capitalize administrator or admin except when referring to the Administrator account type.
- Write with capitals Administrators only when referring to the Administrators group in Windows security.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/administrator-admin)

<a id="against"></a>
## against

- Avoid to refer to running or building a program on a particular platform or operating system.
- Prefer on instead.
- Acceptable: against in content for a technical audience to discuss evaluating a value against an expression or running a query against a database.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/against)

<a id="alarm"></a>
## alarm

- Avoid this term as a general reference to a sound intended to get the customer's attention.
- Prefer beep or a more specific description of the sound instead.
- Acceptable: alarm in a specific description, such as the low-battery alarm.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/alarm)

<a id="alert"></a>
## alert

- For technical audiences, it's OK to use alert to refer to automated messages from apps, products, services, and websites.
- For general users, don't use alert to refer to a system message.
- Prefer notification instead.
- Avoid alert as a synonym for reminder.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/alert)

<a id="alias"></a>
## alias

- Avoid this term when you mean an email address, account name, or distribution group name.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/alias)
