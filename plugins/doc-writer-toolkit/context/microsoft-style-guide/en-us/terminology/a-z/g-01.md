# Microsoft terms: G (1)

Load this file only when checking one of the indexed terms below.

<a id="gallery"></a>
## gallery

- Avoid this term when you mean a marketplace or store.
- Acceptable: gallery to refer to a collection of pictures, charts, graphics, templates, components, or other items that the customer can select from.
- Prefer the verb select for items in a gallery.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/gallery)

<a id="game-pad"></a>
## game pad

- Two words.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/game-pad)

<a id="garbage-collection-garbage-collector"></a>
## garbage collection, garbage collector

- OK to use in content for a technical audience to refer to the automatic recovery of heap memory or to the automatic deletion of objects that the runtime environment determines are no longer being…
- Prefer garbage collector to describe the component of a runtime environment that performs garbage collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/garbage-collection-garbage-collector)

<a id="general-data-protection-regulation-gdpr"></a>
## General Data Protection Regulation (GDPR)

- Write with capitals and spell out on the first mention.
- Include the when used as a noun.
- When General Data Protection Regulation or GDPR is used as an adjective, include the if the syntax of the sentence requires it.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/general-data-protection-regulation-gdpr)

## general protection fault, GP fault

<a id="global"></a>
## global

- In content for a technical audience, use global to refer to:
- Memory that's accessible to more than one process. - A variable whose value can be accessed and modified by any statement in a program.
- This is called a global variable. - Similar elements that pertain to an entire program.
- Avoid global in content for a general audience, especially in describing the process of replacing one text string with another throughout a document.
- Instead, describe the action or use all instances or all occurrences.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/global)

## glyph

- Avoid to refer generically to a graphic or pictorial image on a button, on an icon, or in a message box.
- Prefer symbol instead.
- Acceptable: glyph in a technical discussion of fonts and characters.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/glyph)

<a id="graphic-graphics-graphical"></a>
## graphic, graphics, graphical

- As a noun, use graphic to refer to a picture, display, chart, or other visual representation.
- Prefer graphics to refer in general to pictures, displays, charts, and other visual representations using computers.
- For example, graphics software.
- Most of the time, use graphical as an adjective.
- Prefer graphic as an adjective only to mean vivid or realistic or in the phrase graphic arts.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/graphic-graphics-graphical)

## graphics adapter

<a id="gray-grayed-out"></a>
## gray, grayed out

- Most of the time, talk about the actions that customers should take.
- Avoid gray or grayed out to describe commands or options that are in an unusable state—use not available or isn’t available instead.
- Prefer appears dimmed if you must describe their appearance.
- Prefer shaded to describe the appearance of check boxes that represent a mixture of settings.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/gray-grayed-out)

## greater, better

- Avoid greater or better to mean or later when identifying multiple versions of programs or apps.
- Related guidance: later.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/greater-better)

<a id="group-box"></a>
## group box

- Two words.
- Most of the time, avoid talking about specific UI elements.
- Instead, talk about what the customer needs to do.
- When you need to refer to a group box for a general audience, don't include the words group box.
- Just refer to the name of the group box.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/g/group-box)
