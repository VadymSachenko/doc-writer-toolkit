# Microsoft terms: O (2)

Load this file only when checking one of the indexed terms below.

<a id="option-option-button"></a>
## option, option button

- In general, avoid talking about the UI.
- Instead, talk about what the customer needs to do.
- Describe an option by its UI label only.
- If you must provide a descriptor, use option.
- Prefer the exact label text, including its capitalization, but don't capitalize the word option.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/option-button)

<a id="org-organization"></a>
## org, organization

- Prefer the term that makes the most sense for your audience.
- In content for a business or technical audience, it's OK to use org as an abbreviation for organization. Don't use a period after the abbreviation.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/org-organization)

<a id="output"></a>
## output

- Avoid this term as a verb.
- Instead, use a verb that describes the kind of output, such as write to, display on, or print to.
- Avoid using as a noun or an adjective in content for a general audience.
- Prefer a more specific term instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/output)

<a id="outside"></a>
## outside

- Prefer instead of outside of.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/outside)

<a id="over"></a>
## over

- Prefer over to refer to a position or location above something.
- For quantities, use more than.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/over)

<a id="overwrite"></a>
## overwrite

- Prefer only to describe replacing existing data with new data.
- Prefer replace to describe replacing an existing file with a new one that has the same name.
- Avoid overwrite as a synonym for type over.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/o/overwrite)
