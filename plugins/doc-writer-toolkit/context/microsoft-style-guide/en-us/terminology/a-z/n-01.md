# Microsoft terms: N (1)

Load this file only when checking one of the indexed terms below.

<a id="net"></a>
## .NET

- Note capitalization.
- Always begin with a period (.).
- Don't spell out as dot NET.
- Prefer Microsoft .NET on the first mention.
- After that, it's OK to use .NET.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/net)

<a id="n"></a>
## n

- Prefer a lowercase n in italic type to refer to a generic use of a number—when the value of a number is arbitrary or immaterial.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/n)

## namespace

- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/namespace)

## nanosecond

<a id="native-language"></a>
## native language

- Avoid to refer to a computer system's machine language.
- Prefer machine language or host language instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/native-language)

<a id="natural-user-interface-nui"></a>
## natural user interface, NUI

- Avoid natural user interface in content for a general audience.
- Avoid abbreviating as NUI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/natural-user-interface-nui)

<a id="navigate"></a>
## navigate

- Avoid to describe going from place to place on the internet or an intranet.
- Prefer browse instead.
- To describe going directly to a webpage or website, whether by entering a URL or selecting a hyperlink, use go to.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/navigate)

<a id="need"></a>
## need

- Prefer need to discuss a requirement or obligation; use want when the customer has a choice of actions.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/need)

<a id="network"></a>
## network

- Don't shorten to net.
- Avoid network as a verb to describe the action of connecting a computer to a network.
- A computer is on, not in, a network, and computers on a network are linked or connected, not networked.
- Prefer network as a verb and the noun networking only to describe making personal and business connections.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/network)

<a id="network-administrator"></a>
## network administrator

- Prefer only to specifically refer to the administrator of networks.
- In general, use administrator or system administrator unless you must specify a particular kind.
- Related guidance: administrator, admin.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/network-administrator)

<a id="non"></a>
## non-

- Don't hyphenate words beginning with non-, such as nonnumeric and nonzero, unless a hyphen is necessary to avoid confusion, as in non-native, or non- is followed by a proper noun, as in non-English. When…
- Avoid non- to negate an entire phrase.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/non)

<a id="nonadjacent-selection"></a>
## nonadjacent selection

- Avoid in content for a general audience to describe multiple selected items that don't touch.
- Prefer multiple selection or list the specific items instead.
- Prefer in content for a technical audience only if the term appears in the UI or API.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/nonadjacent-selection)

<a id="noncontiguous-selection"></a>
## noncontiguous selection

- Avoid in content for a general audience to refer to selecting multiple items that don't touch.
- Prefer multiple selection instead, or describe the specific noncontiguous items.
- Prefer in content for a technical audience only if the term appears in the UI or API.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/noncontiguous-selection)

<a id="nonprintable-nonprinting"></a>
## nonprintable, nonprinting

- Prefer nonprintable to refer to an area of a page that can't be printed on.
- Prefer nonprinting to refer to characters and other data that can't or won't be printed.
- Avoid unprintable.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/nonprintable-nonprinting)

<a id="normal-normally"></a>
## normal, normally

- Avoid normal to mean customary, usual, typical, or a similar term.
- Avoid normally to mean often, usually, ordinarily, typically, generally, or a similar term.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/normal-normally)

<a id="notification"></a>
## notification

- Prefer instead of notice to describe information displayed to a customer about communications, contacts, a service problem, or other item.
- Avoid pop-up, toast, or banner for this purpose.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/notification)
