# Microsoft terms: V (1)

Load this file only when checking one of the indexed terms below.

<a id="value-axis"></a>
## value axis

- Write in lowercase.
- Don't hyphenate.
- Usually refers to the vertical axis in 2D charts and graphs, which shows the values being measured or compared.
- Describe it as the value (y) axis on the first mention.
- On subsequent mentions, use y-axis.
- Related guidance: category axis, z-axis.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/v/value-axis)

<a id="versus-vs"></a>
## versus, vs.

- In headings, use the abbreviation vs., all lowercase.
- In text, spell out as versus.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/v/versus-vs)

<a id="video-call-videoconference"></a>
## video call, videoconference

- Prefer video call, not videoconference, when you need to be specific.
- Otherwise, it's OK to use call or meeting.
- In a verb phrase, follow the UI or use start a video call, join a video call, participate in a video call, or end a video call.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/v/video-call-videoconference)

<a id="virtual"></a>
## virtual

- Prefer only to refer specifically to a device or service that appears to be something it's not or that doesn't physically exist.
- For example, a virtual machine isn't an actual computer; it's something that emulates one.
- Avoid in content for a general audience.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/v/virtual)

<a id="virtualize"></a>
## virtualize

- Avoid in content for a general audience.
- In content for a technical audience, it's OK to use virtualize sparingly to mean creating a virtual implementation.
- For example, it's OK to use virtualize storage to refer to creating virtual storage.
- Avoid this term as a synonym for simulate.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/v/virtualize)

<a id="voicemail"></a>
## voicemail

- One word.
- Avoid abbreviating as v-mail or vmail.
- Prefer to refer generically to a voicemail app, to refer collectively to messages, or to refer to an individual message.
- If necessary to distinguish these meanings, use voicemail message or message to refer to an individual voicemail.
- Avoid this term as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/v/voicemail)
