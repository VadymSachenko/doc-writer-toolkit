# Microsoft terms: I (2)

Load this file only when checking one of the indexed terms below.

<a id="input-output-i-o-input-output-control"></a>
## input/output, I/O, input/output control

- Avoid input/output in content for a general audience.
- If you must use it, spell out on the first mention, and then abbreviate as I/O.
- In content for a technical audience, you don't need to spell out on the first mention.
- Prefer input/output control only in content for a technical audience.
- Always spell out on the first mention.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/input-output)

<a id="insecure"></a>
## insecure

- Avoid this term when you mean not secure.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/insecure)

<a id="inside"></a>
## inside

- Prefer instead of inside of.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/inside)

<a id="install"></a>
## install

- Prefer install to describe adding apps, hardware, and drivers to a device.
- Avoid download. Use uninstall to describe removing them.
- Avoid install as a noun.
- Prefer installation instead.
- Related guidance: add.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/install)

<a id="instant-message-im"></a>
## instant message, IM

- Write in full instant message or instant messaging on the first mention if your audience might not be familiar with the abbreviation.
- After that, it's OK to use IM as a noun or modifier .
- Avoid instant message or IM as a verb.
- Prefer send an instant message or send an IM instead.
- Exception In mobile UI content or to form a parallel construction with another one-word phrase, it's OK to use IM as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/instant-message-im)

<a id="instantiate"></a>
## instantiate

- Avoid.
- Prefer create an instance of (a class) instead.
- If you have a reason to use instantiate, its direct object must be the name of a class or a general reference to classes.
- You instantiate a class, not an object.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/instantiate)

<a id="insure-assure-ensure"></a>
## insure, assure, ensure

- Ensure , insure, and assure are interchangeable in many situations.
- To improve worldwide readability, Microsoft style makes these distinctions:
- Prefer ensure to mean to make sure or to guarantee. - Use insure to mean to provide insurance. - Use assure to mean to state positively or to make confident.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/insure-assure-ensure)

<a id="interface"></a>
## interface

- Prefer only as a noun, as in user interface and application programming interface.
- Prefer interface by itself only if the context is clear.
- For a general audience, it's OK to use UI or API after spelling out on the first mention.
- For a technical audience, it's not necessary to spell out those terms on the first mention.
- Avoid interface as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/interface)

<a id="internet-of-things-iot"></a>
## Internet of Things (IoT)

- Note the capitalization.
- Write in full on the first mention unless you're sure that your audience knows the term or IoT appears as part of a Microsoft product name.
- On subsequent mentions, use the abbreviation IoT.
- Include the with the spelled-out term but not the acronym.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/internet-of-things-iot)

<a id="internet-service-provider-isp"></a>
## internet service provider (ISP)

- Write in full on the first mention.
- Write in lowercase the spelled-out term.
- Prefer to refer to an organization that provides customers with internet access for activities such as web browsing, email, and newsgroups.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/internet-service-provider)

<a id="internet-intranet-extranet"></a>
## internet, intranet, extranet

- Prefer internet to refer to the worldwide collection of networks that use open protocols such as TCP/IP to communicate with one another.
- Don't capitalize.
- Prefer intranet to refer to a communications network based on web technology but that's available only to certain people, such as the employees of a company.
- Prefer extranet to refer to an extension of an intranet that uses internet protocols to give authorized outside users limited access to the intranet.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/internet-intranet-extranet)

<a id="invalid-not-valid"></a>
## invalid, not valid

- Both terms are OK to use, but try to use more specific terms instead.
- Global tip Use not valid instead of invalid if possible because machine translation might not translate i nvalid correctly.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/invalid-not-valid)

<a id="invoke"></a>
## invoke

- Avoid in content for a general audience.
- In content for a technical audience, it's OK to use invoke to refer to a function, process, or similar element.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/i/invoke)
