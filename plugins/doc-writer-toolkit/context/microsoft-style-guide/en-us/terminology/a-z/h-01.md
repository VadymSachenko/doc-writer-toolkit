<a id="half-inch"></a>
## half inch

- Hyphenate as an adjective.
- Prefer instead of half an inch or one-half inch.
- When space is limited or the measurement needs to be specific, use 0.5 in.
- Global tip Be careful when using abbreviations or acronyms that form English words.
- Machine translation might incorrectly translate the abbreviation in. as the word in.
- Related guidance: Units of measure term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/half-inch)

<a id="header"></a>
## header

- In content related to word-processing and publishing apps, use instead of running head when discussing page layout.
- Acceptable: running head for clarification or as a keyword.
- Avoid header as a synonym for heading.
- In technical content, it's OK to use header as a short form of file header, as in HTML header.
- Avoid header as a synonym for header file, which refers to the file at the beginning of a program that contains definitions of data types and variables used by the program's functions.
- Related guidance: footer.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/header)

<a id="help"></a>
## Help

- Most of the time, use just Help. Don't use online Help unless you need to describe the Help system.
- Write with capitals when referring to a Help system within a product.
- Acceptable: definition Help, context-sensitive Help, and online Help files to describe the Help system itself or to explain how to develop a Help system.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/help)

<a id="hexadecimal"></a>
## hexadecimal

- Avoid abbreviating as hex.
- Prefer h or 0x when abbreviating a number.
- Don't insert a space between the number and h, and use all uppercase for alphabetical characters displayed in hexadecimal numbers.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/hexadecimal)

<a id="hierarchical-menu"></a>
## hierarchical menu

- Avoid.
- Prefer submenu if you need to emphasize how the menu works as a feature.
- Better yet, avoid talking about UI.
- Instead, talk about what the customer wants to do.
- Acceptable: hierarchical menu when you need to explain types of menus to a technical audience.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/hierarchical-menu)
