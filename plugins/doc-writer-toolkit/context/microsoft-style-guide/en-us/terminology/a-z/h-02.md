# Microsoft terms: H (2)

Load this file only when checking one of the indexed terms below.

<a id="high-quality"></a>
## high-quality

- Avoid quality by itself as an adjective.
- Always use high-quality.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/high-quality)

<a id="high-resolution"></a>
## high-resolution

- Write with a hyphen.
- Avoid abbreviating as hi-res.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/high-resolution)

<a id="higher"></a>
## higher

- Avoid or higher to mean or later to refer to multiple versions of software.
- Acceptable: higher to refer to display resolution.
- Avoid higher to refer to processor speed.
- Prefer faster instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/higher)

<a id="hint"></a>
## hint

- Avoid hint as a heading for a type of note.
- Prefer tip instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/hint)

<a id="hit"></a>
## hit

- Avoid to refer to pressing a key.
- Prefer select instead.
- Prefer page view or page request, not hit, to refer to the number of times a complete webpage, with all its associated files, has been downloaded.
- Acceptable: hits to refer to the number of times a file that's part of a webpage has been retrieved.
- A single page view can result in many hits.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/hit)

<a id="home-directory"></a>
## home directory

- Avoid.
- In content for developers, use root directory to refer to the starting point in a hierarchical file structure.
- In Windows, the root directory is indicated by a backslash (\\).
- In all other content, use top-level folder.
- Related guidance: root directory.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/home-directory)

<a id="home-home-page"></a>
## home, home page

- Prefer home to refer to the main page of a website or the page a browser displays upon opening.
- Write with capitals Home only when it’s used as a UI label or in references to a UI label.
- Prefer home page, two words, in generic references if needed for clarity.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/home-home-page)

<a id="honeypot"></a>
## honeypot

- Avoid.
- In content that's specifically about network decoy technology, try to write around the reference.
- If you can't, define the term on the first mention.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/honeypot)

<a id="hot-link"></a>
## hot link

- Avoid to describe a connection that enables information in related databases or files to be updated when information in another database or file is changed.
- Avoid to refer to a hyperlink.
- Related guidance: hyperlink.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/hot-link)

<a id="hot-spot-hotspot"></a>
## hot spot, hotspot

- Avoid to refer to a hyperlink.
- In content for a technical audience, use two words to refer to the specific pixel on the pointer that defines the exact location to which a user is pointing.
- Prefer one word when referring to a site that offers internet access over a wireless LAN.
- Prefer one word when referring to programming elements, such as the elements of the HotSpot class, or to match UI.
- Related guidance: hyperlink.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/hot-spot-hotspot)

<a id="how-to-how-to"></a>
## how to, how-to

- Avoid how-to as a noun.
- Write with a hyphen as an adjective.
- Never capitalize the t in to.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/how-how-to)

<a id="html"></a>
## HTML

- Don't spell out.
- If you have a reason to spell out, use Hypertext Markup Language.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/html)

<a id="http-https"></a>
## HTTP, HTTPS

- Don’t spell out unless you're discussing protocols or URLs, and your audience might be unfamiliar with the abbreviation.
- When you have a reason to spell out, use Hypertext Transfer Protocol for HTTP and Hypertext Transfer Protocol Secure for HTTPS.
- Prefer all uppercase when referring to the HTTP or HTTPS protocol itself.
- In general, omit https:// and https:// from URLs.
- If for some reason you need to include https:// or https:// as part of a URL, use all lowercase.
- Related guidance: URLs and web addresses.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/http-https)

<a id="hyperlink"></a>
## hyperlink

- Prefer hyperlink or link to describe text or a graphic that readers can select to go to another document, to another place within the same document, or to a webpage.
- Prefer hyperlink to refer to a UI element labeled hyperlink.
- Avoid hot spot, hot link, or shortcut to refer to a link.
- Prefer go to to describe the process of going to another document, place, or webpage.
- Avoid click or click on.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/h/hyperlink)
