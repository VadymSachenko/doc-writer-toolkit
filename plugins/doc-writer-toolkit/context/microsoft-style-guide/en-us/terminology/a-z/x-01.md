# Microsoft terms: X (1)

Load this file only when checking one of the indexed terms below.

<a id="x"></a>
## x

- Prefer a lowercase x in italic type as a placeholder number or variable.
- Avoid x to refer to a generic, unspecified number.
- Prefer n instead.
- Avoid x in place of a multiplication sign.
- Related guidance: n, multiplication sign (×).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/x/x)

<a id="x-axis"></a>
## x-axis

- Write in lowercase.
- Hyphenate.
- On the first mention, use category (x) axis to refer to the horizontal axis in charts and graphs that shows the categories being compared.
- On subsequent mentions, use x-axis. It's OK to use horizontal (x) axis in content for a general audience.
- Avoid italic formatting for the x in x-axis unless the entire word is italic.
- Related guidance: value axis, category axis.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/x/x-axis)

<a id="x-coordinate"></a>
## x-coordinate

- Write in lowercase.
- Hyphenate.
- Avoid italic formatting for the x in x-coordinate unless the entire word is italic.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/x/x-coordinate)
