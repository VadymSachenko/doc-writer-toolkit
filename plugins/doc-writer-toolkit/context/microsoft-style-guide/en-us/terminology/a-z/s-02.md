# Microsoft terms: S (2)

Load this file only when checking one of the indexed terms below.

<a id="set-top-box"></a>
## set-top box

- Note hyphen.
- Avoid abbreviating.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/set-top-box)

<a id="setting-value"></a>
## setting, value

- Avoid generic nouns, such as setting or value, in content for a general audience.
- Prefer a specific noun, such as width, color, or font, instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/setting-value)

<a id="shaded"></a>
## shaded

- Most of the time, talk about the actions that customers should take.
- Avoid to describe commands or options that are in an unusable state—use not available or isn’t available instead.
- If you must describe their appearance, use appears dimmed.
- Acceptable: shaded to describe the appearance of check boxes that represent a mixture of settings.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/shaded)

<a id="shell"></a>
## shell

- OK to use as a noun in content for a technical audience.
- Avoid in content for a general audience.
- Avoid this term as a verb, such as shell or shell out.
- Prefer more precise terminology, such as create a new shell or return to the operating system.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/shell)

<a id="ship"></a>
## ship

- Avoid to refer to making products or services available to customers.
- Prefer release instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/ship)

<a id="shortcut-shortcut-menu"></a>
## shortcut, shortcut menu

- Shortcut is one word as an adjective or a noun.
- Avoid this term as a verb.
- Avoid this term as a synonym for hyperlink.
- Prefer shortcut menu only if it helps the customer locate the item in the UI.
- Most of the time, just describe what the customer needs to do.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/shortcut-shortcut-menu)

<a id="should-vs-must"></a>
## should vs. must

- Before using should or must, consider other ways to discuss recommendations or requirements, such as the imperative mood for required actions and a phrase such as we recommend for optional ones.
- Avoid Microsoft recommends or it is recommended.
- Be careful to make your tone helpful, not bossy. (For information about the imperative mood,
- Related guidance: Verbs.).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/should-vs-must)

<a id="shut-down-shutdown"></a>
## shut down, shutdown

- Two words as a verb, one word as a noun.
- Prefer shut down to describe exiting the operating system and turning off the device in a single action.
- Avoid shut down to describe turning off a device or as a synonym for close.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/shut-down-shutdown)

<a id="sign-in-sign-out"></a>
## sign in, sign out

- Prefer sign in to describe starting a session on a computer, a device, a network, an app, or anywhere a username and password are required.
- Prefer sign out to refer to ending a session.
- Avoid log in, login, log into, log on, logon, log onto, log off, log out, logout, sign into, signin, signoff, sign off, or sign on unless these terms appear in the UI (and you're…
- The verb form is two words, sign in or sign out. Avoid using as a noun or adjective (sign-in, sign-out).
- Instead, use a more descriptive or precise term.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/sign-in-sign-out)

<a id="simply"></a>
## simply

- Avoid this term when you mean that something is easy to do.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/simply)

<a id="single-sign-on-sso"></a>
## single sign-on (SSO)

- Write in full on the first mention, and lowercase the spelled-out term.
- Note hyphen.
- Related guidance: sign in, sign out.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/single-sign-on-sso)

<a id="site"></a>
## site

- Prefer to describe a collection of webpages that's part of a larger whole, such as the Microsoft website or the MSDN website.
- Prefer website instead of site if necessary for clarity.
- Information is on a site, but the address of a site is at www.example.com.
- Related guidance: page, URLs and web addresses.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/site)

<a id="site-map"></a>
## site map

- Two words.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/site-map)

<a id="size-resize"></a>
## size, resize

- Acceptable: size as a verb, as in size the window.
- Prefer resize to mean change the size of.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/size-resize)

<a id="sleep"></a>
## sleep

- Prefer to describe putting a device into a power-saving state without shutting it down.
- Related guidance: shut down, shutdown.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/sleep)

<a id="slider"></a>
## slider

- In general, avoid talking about UI elements.
- Most of the time, just describe what the customer needs to do.
- In content for a general audience, it's OK to use slider when you need to describe the UI element used to set a value on a continuous range of possible values, such as screen…
- In content for developers, it's OK to refer to a slider as a trackbar control.
- Don't refer to the scroll box or a progress indicator as a slider.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/slider)

<a id="slideshow"></a>
## slideshow

- One word unless you need to match the UI.
- Avoid carousel as a synonym.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/slideshow)

<a id="small-caps"></a>
## small caps

- Avoid small caps for key names or for AM and PM.
- Acceptable: the term small caps.
- If necessary for clarity, refer to them as small capitals on the first mention, followed by a phrase such as, "often referred to as small caps."
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/small-caps)

<a id="smart-card-smart-card"></a>
## smart card, Smart Card

- Two words.
- Prefer lowercase for generic references to smart cards or smart card technology.
- Write with capitals as part of proper nouns, such as Lenovo Integrated Smart Card Reader, but not in general references to smart card implementations.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/smart-card)

## smartphone
