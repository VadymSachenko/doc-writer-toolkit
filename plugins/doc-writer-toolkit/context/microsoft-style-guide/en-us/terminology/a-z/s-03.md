# Microsoft terms: S (3)

Load this file only when checking one of the indexed terms below.

## snap-in

- Prefer only to describe a program that runs in Microsoft Management Console.

<a id="sorry"></a>
## sorry

- Use sorry for sincere accountability when the product or service caused a meaningful problem. Do not add Hmm or Oops to routine errors.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/sorry)

<a id="spam"></a>
## spam

- Write in lowercase.
- Prefer spam only to refer to unsolicited commercial email.
- Avoid to refer generally to commercial email, such as bulk email sent to a customer list.
- Avoid to refer to an inappropriate posting to a large distribution list.
- Avoid spam as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/spam)

<a id="specification"></a>
## specification

- Always spell out.
- Avoid spec.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/specification)

<a id="spell-checker"></a>
## spell checker

- Prefer spell checker as a general term for a tool that checks spelling.
- To refer to a specific tool, use the name that appears in the UI.
- Prefer check spelling as a verb.
- Avoid spell check as a noun.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/spell-checker)

<a id="spin-box"></a>
## spin box

- Acceptable: spin box in content for a technical audience to describe a control that users can use to move, or spin, through a fixed set of values, such as dates.
- For a general audience, just discuss what the customer needs to do.
- If you need to refer to the control, refer to a spin box by its label.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/spin-box)

<a id="split-bar-split-box"></a>
## split bar, split box

- Acceptable: split bar and split box in content for all audiences.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/split-bar-split-box)

<a id="spoofing"></a>
## spoofing

- Acceptable: spoofing in content for all audiences if you're sure that your audience will understand the meaning.
- To avoid ambiguity, be specific about the kind of spoofing you're referring to, such as email spoofing or IP spoofing.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/spoofing)

<a id="spreadsheet-vs-workbook"></a>
## spreadsheet vs. workbook

- Prefer spreadsheet to refer to an accounting app, such as Microsoft Excel.
- Prefer workbook to refer to the file produced using a spreadsheet app.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/spreadsheet-vs-workbook)

<a id="sql-sql-server"></a>
## SQL, SQL Server

- When you're referring to a computer that's running Microsoft SQL Server, use a computer running SQL Server or a computer that's running SQL Server. (Note the capital S in Server.)
- Never refer to a computer that's running Microsoft SQL Server as any of the following:
- The SQL Server - a SQL Server - SQL Servers - SQL server
- When you're referring to Structured Query Language as SQL, use the indefinite article an: an SQL database.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/sql-sql-server)

<a id="start-button-start-menu"></a>
## Start button, Start menu

- Write with capitals references to the Start menu and the Start button on the Windows taskbar.
- Avoid bold formatting for Start unless you're referring to the menu or button in instructions.
- Don't refer to the Start button as the Windows Start button.
- Don't include the word button unless it's necessary for clarity.
- If you do, button is lowercase.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/start-button-start-menu)

<a id="start-page"></a>
## start page

- Avoid to refer to the main page of a website or the page a browser displays upon opening.
- Prefer home page instead.
- Related guidance: home, home page.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/start-page)

<a id="start-up-startup"></a>
## start up, startup

- Avoid start up as a verb.
- Prefer start instead.
- Note Use open, not start, to describe selecting a program or app from the Start menu to open it.
- Avoid on startup or similar noun phrases in content for a general audience.
- Acceptable: on startup in content for a technical audience.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/start-up-startup)

<a id="start-restart"></a>
## start, restart

- Avoid start to describe selecting a program or app to open it.
- Prefer open instead.
- Prefer restart to describe closing and reopening a program or app or turning a device off and then immediately back on.
- Related guidance: Describing interactions with UI, turn on, turn off.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/start-restart)

<a id="status-bar"></a>
## status bar

- Prefer instead of status line or message area to refer to the area at the bottom of a document window that shows the status of a document and other information, such as the meaning…
- Messages appear on, not in, the status bar.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/status-bar)
