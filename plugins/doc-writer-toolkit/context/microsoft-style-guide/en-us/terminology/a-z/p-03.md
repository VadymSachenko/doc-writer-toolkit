# Microsoft terms: P (3)

Load this file only when checking one of the indexed terms below.

<a id="power-down-power-up-power-off-power-on"></a>
## power down, power up, power off, power on

- Avoid.
- Prefer turn off and turn on instead.
- Avoid shut down to refer to turning off a device.
- Start, restart shut down, shutdown turn on, turn off
- Related guidance: start, restart.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/power-down-power-up-power-off-power-on)

<a id="power-user"></a>
## power user

- Avoid this term when you mean that someone must be an expert to use certain programs or features.
- Instead, identify the specific knowledge or skill that's required.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/power-user)

<a id="pre"></a>
## pre-

- In general, don’t hyphenate words beginning with pre-, such as preallocate and preempt, unless it’s necessary to avoid confusion, as in pre-engineered, or if pre- is followed by a proper noun, as in pre-C++.…
- To learn more about hyphenation,
- Related guidance: Hyphens.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/pre)

<a id="preceding"></a>
## preceding

- Acceptable: preceding, previous, or earlier to mean earlier in a piece of content, but use a hyperlink instead if you can.
- Avoid above.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/preceding)

<a id="press-press-and-hold"></a>
## press, press and hold

- Prefer only to describe pushing a physical button on hardware.
- Describing interactions with UI Touch and pen interaction term collection Keys and keyboard shortcuts term collection
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/press-and-hold)

<a id="preview"></a>
## preview

- Prerelease versions of software and services are typically identified as Product Name Preview (preferred) or Code Name Preview.
- In generic references, lowercase preview.
- Avoid using beta to refer to a prerelease product that's ready for unstructured testing by customers.
- Prefer preview instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/preview)

<a id="print-queue-printer-queue"></a>
## print queue, printer queue

- Avoid.
- Prefer list of documents instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/print-queue-printer-queue)

<a id="print-printout"></a>
## print, printout

- As a verb, use print instead of print out.
- Acceptable: printout as the result of a print job, if necessary, but try to be more specific.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/print-printout)

## profile

<a id="program-file"></a>
## program file

- Acceptable: program file as an alternative to executable file in content for a general audience.
- If possible, use the specific name of the file instead.
- Avoid app file or application file.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/program-file)

<a id="prompt"></a>
## prompt

- Prefer only to describe a signal, which might or might not be a message, that an app or the operating system is waiting for the customer to take some action.
- In general, restrict the use of prompt as a noun to the command prompt.
- Prefer this term as a verb to describe the act of requesting information or an action from the customer.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/prompt)

## property

<a id="pull-down-pull-down"></a>
## pull down, pull-down

- In general, avoid talking about UI.
- Instead, describe what the customer needs to do.
- Avoid pull down as a verb to describe how to use a menu or list.
- Avoid pull-down as an adjective to describe the appearance of a menu or list.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/pull-down)
