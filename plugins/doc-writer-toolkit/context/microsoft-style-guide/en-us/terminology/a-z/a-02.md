# Microsoft terms: A (2)

Load this file only when checking one of the indexed terms below.

<a id="allow-allows"></a>
## allow, allows

- Avoid allows (or enables or lets) to describe things that Microsoft or Microsoft apps make possible for the customer.
- Acceptable: allows to refer to features, such as security, that permit or deny some action or access.
- In content for technical audiences, write around the use of allow/allows by referring to customers in the third person, such as the customer can.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/allow-allows)

<a id="alphabetical"></a>
## alphabetical

- Prefer instead of alphabetic.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/alphabetical)

<a id="alphanumeric"></a>
## alphanumeric

- Prefer to refer to character sets that include only letters and numerals or to individual characters that can be only letters or numerals.
- Avoid alphanumerical.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/alphanumeric)

<a id="am-pm"></a>
## AM, PM

- Follow the referenced topic collection for this term.
- Related guidance: Date and time term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/am-pm)

<a id="ampersand"></a>
## ampersand (&)

- Avoid & in place of and in text or headings unless you're referring to the use of the symbol in UI.
- Acceptable: & in content for technical audiences that covers its use in HTML or programming languages.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/ampersand)

<a id="and-so-on"></a>
## and so on

- Avoid.
- Instead, be specific.
- When space is limited, use such as or like followed by an example or two.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/and-so-on)

<a id="and-or"></a>
## and/or

- Avoid unless it helps you avoid lengthy, complex wording.
- Most of the time, or can stand on its own.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/and-or)

<a id="anti-malware"></a>
## anti-malware

- Write anti-malware with a hyphen. Use it for software or measures that detect, block, or remove malware.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/antimalware)

<a id="antialiasing"></a>
## antialiasing

- Don't hyphenate.
- Don't capitalize antialiasing unless it begins a sentence or phrase.
- Don't capitalize aliasing in antialiasing.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/antialiasing)

<a id="antispyware"></a>
## antispyware

- Prefer only as an adjective.
- Don't hyphenate.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/antispyware)

<a id="antivirus"></a>
## antivirus

- Prefer only as an adjective.
- Don't hyphenate.
- Antivirus is often used interchangeably with antimalware to describe any program that removes malware.
- Prefer antivirus when you want to differentiate between antispyware and other antimalware programs.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/antivirus)

<a id="app-application"></a>
## app, application

- If possible, refer to a product by its descriptor, such as database management system or spreadsheet.
- Most of the time use app, not application, to describe desktop apps and cloud apps for tablets and mobile devices.
- Global tip The abbreviated form, app, isn't available in all languages, so allow enough space for the full translated term in localized content.
- For full-featured products, such as Office and Visual Studio, it's OK to use program instead of application.
- Acceptable: application in content for a technical audience, especially to refer to a set of software files that includes executable files and other components.
- Related guidance: add-in, add-on.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/app-application)

<a id="appendix-appendices"></a>
## appendix, appendices

- Prefer appendices as the plural form of appendix, not appendixes.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/appendix-appendices)

<a id="applet"></a>
## applet

- Prefer to refer to an HTML-based program that a browser downloads temporarily to a customer's hard drive. Applet is most often associated with Java.
- In general, when referring to a small program, use the name of the program or the most appropriate term, such as item, app, program, add-in, or applet.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/applet)

<a id="application-developer-app-developer"></a>
## application developer, app developer

- Avoid application developer, applications developer, or app developer.
- Prefer software developer, web developer, developer, or programmer instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/application-developer-app-developer)

<a id="application-file-app-file"></a>
## application file, app file

- Avoid.
- Prefer the specific name of the file if you can.
- Otherwise, use program file.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/application-file-app-file)

<a id="application-icon-app-icon"></a>
## application icon, app icon

- Avoid to refer to a program icon.
- Prefer the specific product name, such as the Word icon, instead.
- If you must use a general term, use app icon.
- Acceptable: application icon in content for developers when discussing programming elements such as the ApplicationIcon property.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/application-icon-app-icon)

<a id="application-window-app-window"></a>
## application window, app window

- Avoid to refer to a specific product window.
- Prefer the product name, such as the Word window, instead.
- Acceptable: application window in content for developers when discussing programming elements, such as the WindowSize event.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/application-window-app-window)

<a id="argument-vs-parameter"></a>
## argument vs. parameter

- These terms are often used interchangeably.
- Prefer argument in content for a general audience.
- Differentiate with parameter only if necessary.
- In content for a technical audience, use the same term consistently to refer to the same kind of element.
- When you need to differentiate between them:
- Related guidance: Reference documentation, Formatting developer text elements.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/argument-vs-parameter)

<a id="arrow"></a>
## arrow

- In content teaching basic skills, it's OK to use arrow to identify the arrow next to a list box label.
- Avoid up arrow or down arrow, which refer to the arrow keys on the keyboard.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/a/arrow)
