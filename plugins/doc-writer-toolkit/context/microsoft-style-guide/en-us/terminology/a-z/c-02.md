## check in

- OK to use as a verb phrase, as in check in code or check in changes.
- Avoid this term as a noun.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/check-in)

<a id="check-check-box-check-mark"></a>
## check, check box, check mark

- Prefer check or checked as an adjective related to check boxes.
- For example, a check mark or a checked command.
- Prefer check box, not box or checkbox, to refer to a check box in UI.
- Prefer select and clear with check boxes, not turn on and turn off, mark and unmark, check and uncheck, or select and deselect.
- Prefer check mark, not check, as a noun.
- Related guidance: Describing interactions with UI, Formatting text in instructions.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/check-check-box-check-mark)

<a id="click"></a>
## click

- Avoid this verb, which is specific to using a mouse.
- Instead, use verbs that work with multiple devices, such as select.
- Acceptable: click when you need to describe mouse actions specifically.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/click)

<a id="client"></a>
## client

- Avoid client to refer to a person.
- Prefer customer instead.
- Related guidance: Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/client)

<a id="client-side-client-side"></a>
## client side, client-side

- Avoid for a general audience.
- Prefer client instead.
- Acceptable: client side in writing for a technical audience when it refers specifically to the client part (side) of a program or protocol that acts on both a server computer and a client computer.
- Avoid using client-side as an adjective.
- If you must use it as an adjective, hyphenate it.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/client-side)

<a id="close-button"></a>
## Close button

- Write in full and capitalize the word Close.
- Acceptable: the Close button to eliminate ambiguity in content that teaches beginning skills, but for general audiences, just use Close.
- Prefer bold for Close when you're talking about the Close button.
- If you can, use an inline graphic of the button.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/close-button)

## co-
