# Microsoft terms: N (2)

Load this file only when checking one of the indexed terms below.

<a id="notification-area"></a>
## notification area

- Write in lowercase.
- Prefer only to describe the area on the right side of the taskbar where the clock and system notifications appear.
- Avoid the following terms as synonyms for notification area:
- System tray - systray - status area
- Avoid the word area by itself to refer to the notification area.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/notification-area)

<a id="null-null-null"></a>
## null, NULL, Null

- Prefer lowercase null to refer to a null value.
- Better yet, use null value to avoid confusion with the constant.
- Prefer NULL or Null (depending on the language) only to refer to the constant.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/null)

<a id="null-terminated-null-terminating"></a>
## null-terminated, null-terminating

- Prefer null-terminated as an adjective, as in null-terminated string.
- Avoid null-terminating, as in null-terminating character.
- Prefer terminating null character instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/null-terminated-null-terminating)

<a id="number-sign"></a>
## number sign (#)

- Always spell out number in number sign. Don't use pound sign.
- Avoid the \# symbol preceding a numeral.
- Write in full number instead.
- For example, use number 7, not \#7.
- When space is limited, as in tables, it's OK to abbreviate number as No.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/number-sign)

<a id="numeric"></a>
## numeric

- Prefer instead of numerical.
- For the keypad, use numeric keypad instead of numerical keypad or numeric keyboard.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/n/numeric)
