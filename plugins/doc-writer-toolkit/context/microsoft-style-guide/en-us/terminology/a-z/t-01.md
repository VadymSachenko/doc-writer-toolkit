# Microsoft terms: T (1)

Load this file only when checking one of the indexed terms below.

<a id="tab"></a>
## tab

- Avoid this term as a verb.
- As a noun, use only to refer to tabs on a ribbon, a webpage, in a dialog box, and so on.
- For other uses, clarify the meaning with a descriptor, such as the Tab key, a tab stop, or a tab mark on the ruler.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/tab)

<a id="table-of-contents"></a>
## table of contents

- Avoid Table of contents as the heading for the list of contents at the beginning of a document or file.
- Prefer just Contents instead.
- It's OK to refer generically to a table of contents.
- Avoid to describe on-screen navigation.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/table-of-contents)

<a id="terminate"></a>
## terminate

- Avoid this term as a synonym for close or exit.
- In content for a technical audience, it's OK to use terminate in phrases such as null-terminated string or terminate a process.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/terminate)

<a id="text-box"></a>
## text box

- Describe a box in which the user enters text only by its label.
- If you must use a descriptor, use box.
- Avoid field or entry field, except in content about database programs.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/text-box)

<a id="text-text-message"></a>
## text, text message

- Prefer this term as an adjective, a noun, or a verb in the context of SMS messages.
- Prefer text message and send or receive a text message, if necessary, to avoid ambiguity.
- Prefer text or text message rather than SMS (short message service) or MMS (multimedia messaging service) for the US audience.
- For markets where SMS may be the more common usage, localization teams will use the appropriate term.
- Global tip In some languages, text is translated differently as a noun and a verb.
- Related guidance: message.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/text-text-message)

<a id="thanks-thank-you"></a>
## thanks, thank you

- In general, use thanks not thank you. It's OK to use thank you in content that has a formal tone or is about a serious subject, such as cybersecurity or privacy.
- Avoid thanks unnecessarily.
- Prefer thanks as the closing in email, a letter, or a similar message.
- Otherwise, thank the customer only when they've been inconvenienced or they went out of their way to do something.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/thanks-thank-you)

<a id="that-vs-which"></a>
## that vs. which

- Prefer that at the beginning of a clause that’s necessary for the sentence to make sense.
- Don’t put a comma before that.
- Global tip Include that even if the sentence is clear without it.
- It helps to clarify the sentence structure.
- Prefer which at the beginning of a clause that adds supporting or parenthetical information.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/that-vs-which)

## tile, Live Tile

- Write in lowercase tile in general references to the shortcuts on the Start menu that customers can move around.
- These can be static, live, or content tiles.
- Write with capitals Live Tile to describe the feature and in marketing materials.

- Write with a hyphen as an adjective.

<a id="toast"></a>
## toast

- Avoid to refer to a notification triggered by an app or the operating system that's displayed in a pop-up notification.
- Prefer notification instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/toast)

<a id="toggle"></a>
## toggle

- Avoid this term as a verb.
- Instead, use switch, turn on, or turn off with the name of the toggle or command to describe what the customer must do.
- OK to use as a noun or an adjective, as in toggle key or toggle switch. A toggle turns a particular mode on or off.
- When you must refer to a toggle by name, use bold formatting for the name of the toggle.
- Prefer sentence-style capitalization unless you need to match the UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/toggle)

<a id="tone"></a>
## tone

- Avoid to refer to a beeping sound.
- Prefer beep instead.
- Acceptable: tone in other contexts dealing with sound, such as a dial tone or a tone coming from a speaker.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/t/tone)
