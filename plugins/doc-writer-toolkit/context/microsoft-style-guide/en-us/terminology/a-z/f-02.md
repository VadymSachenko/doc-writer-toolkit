# Microsoft terms: F (2)

Load this file only when checking one of the indexed terms below.

<a id="flush-flush-to"></a>
## flush, flush to

- In content for a general audience, don't use flush, flush to, flush left, or flush right to describe text alignment.
- Instead, use even, left-aligned, or right-aligned, as appropriate.
- In content for a technical audience, it's OK to use flush as a verb, for example, flush the buffer.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/flush-flush-to)

<a id="flyout"></a>
## flyout

- Avoid in content for a general audience.
- Instead, describe what the customer needs to do.
- Acceptable: flyout as an adjective in content for a technical audience if you need to describe a transient UI element that displays settings or information related to what the customer is doing.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/flyout)

<a id="folder-folder-icon"></a>
## folder, folder icon

- In general, try not to talk about UI.
- Instead, talk about what the customer should do.
- In content about Windows, use folder to refer to a container for files and other folders.
- Prefer directory only in content for developers when you need to refer to the structure of the file system or to match the API.
- For MS-DOS, use directory.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/folder-folder-icon)

<a id="following"></a>
## following

- Use following only when it clearly identifies content that comes next. Prefer a direct noun or these when the reference is already clear.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/following)

<a id="font-font-style"></a>
## font, font style

- Prefer font, not typeface, for the name of a typeface design such as Times New Roman or Segoe UI.
- Prefer font style, not type style, to refer to the formatting, such as bold, italic, or small caps, and font size, not type size, for the point size, such as 12 points or 14…
- When referring to bold formatting, use bold, not bolded, boldface, or boldfaced. When referring to italic formatting, use italic, not italics or italicized.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/font-font-style)

<a id="foo-foobar-fubar"></a>
## foo, foobar, fubar

- Avoid fubar.
- Avoid foo, foobar, or related words in content for a general audience.
- Acceptable: these words as placeholders or variable names in content for a technical audience, but if you can, use another placeholder instead, such as Example.exe.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/foo-foobar-fubar)

<a id="footer"></a>
## footer

- In content related to word-processing and publishing apps, use instead of bottom running head or running foot when discussing page layout.
- Acceptable: running foot as a synonym in keyword lists.
- Related guidance: header.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/footer)

<a id="foreground-program"></a>
## foreground program

- In content for a technical audience, use instead of foreground process.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/foreground-program)

<a id="format-formatted-formatting"></a>
## format, formatted, formatting

- Prefer format to refer to the overall layout or pattern of a document.
- Prefer formatting or formatted to refer to specific character formatting, paragraph formatting, and other types of formatting.
- Related guidance: font, font style.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/format-formatted-formatting)

<a id="fourth-generation-language"></a>
## fourth-generation language

- Write in full on the first mention.
- On subsequent mentions, it's OK to abbreviate as 4GL.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/fourth-generation-language)

<a id="frameset"></a>
## frameset

- Prefer only in content for developers.
- Prefer frames to refer to the independently scrollable regions on a webpage.
- Prefer frameset document to describe the HTML document that describes the frame layout in a frames page.
- Prefer frames page to describe the page itself, but don't use this term in content for a general audience.
- In general discussions, use frames.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/frameset)

<a id="freeze-frozen"></a>
## freeze, frozen

- Avoid freeze as a synonym for stop responding.
- Avoid frozen to describe the resulting state.
- Related guidance: stop, stop responding.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/freeze-frozen)

<a id="friendly-name"></a>
## friendly name

- Avoid.
- Prefer display name instead to refer to a person's name as it appears in an address or email list.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/friendly-name)

<a id="from-vs-on"></a>
## from vs. on

- Prefer from to indicate a specific place or time as a starting point.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/from-vs-on)

<a id="front-end-front-end"></a>
## front end, front-end

- In content for a general audience, don't use as a synonym for the desktop interface to a database or server.
- Instead, refer to the program by name, or use interface, program, app, or another specific and accurate term instead.
- Acceptable: these terms in content for a technical audience.
- Two words as a noun.
- Hyphenate as an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/front-end)

<a id="full-screen-full-screen"></a>
## full screen, full-screen

- Two words as a noun.
- Hyphenate as an adjective before a noun.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/full-screen)

<a id="function"></a>
## function

- Avoid this term when you mean application programming interface (API).
- Avoid API to mean function.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/function)
