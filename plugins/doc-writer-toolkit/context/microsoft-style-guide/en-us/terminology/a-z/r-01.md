# Microsoft terms: R (1)

Load this file only when checking one of the indexed terms below.

<a id="radio-button"></a>
## radio button

- Prefer radio button only in content for developers in which the API includes the term.
- In that case, use wording such as \ option button (also known as a radio button).
- In other content, refer to a radio button by its label.
- If you must provide a descriptor, use option.
- Write with capitals the label text as it appears in the UI, but don't capitalize the word option.
- Related guidance: option, option button.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/radio-button)

<a id="ragged-right"></a>
## ragged right

- Avoid.
- Prefer left-aligned to describe text with an uneven right edge.
- Related guidance: left align, left-aligned.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/ragged-right)

## RAM

<a id="range-selection"></a>
## range selection

- Avoid.
- In content for a general audience, use a phrase such as a range of cells or a range of dates to refer to a selection of adjoining cells, dates, or other items.
- Prefer the same type of phrasing in content for a technical audience, but if you're describing the feature, use adjacent selection.
- Prefer multiple selection to describe selecting more than one nonadjacent item.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/range-selection)

<a id="re"></a>
## re-

- In general, don’t hyphenate words beginning with re- unless it’s necessary to avoid confusion or re- is followed by a proper noun.
- When in doubt, refer to The American Heritage Dictionary.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/re)

<a id="read-only"></a>
## read-only

- Write with a hyphen.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/read-only)

<a id="read-write-read-write-permission"></a>
## read/write, read/write permission

- Prefer instead of read-write. Capitalize both read and write if the context requires read to be capitalized.
- Prefer read/write permission, not read/write access.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/read-write-read-write-permission)

<a id="real-time-real-time"></a>
## real time, real-time

- Write real time as a noun phrase. Hyphenate real-time before a noun as an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/real-time)

<a id="reboot"></a>
## reboot

- Avoid.
- Prefer restart instead, and be clear that restart in this context refers to the device, not to a program or an app.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/reboot)

<a id="recommend"></a>
## recommend

- Acceptable: we recommend to introduce a Microsoft recommendation.
- Avoid Microsoft recommends or it is recommended.
- Avoid recommend when something is required.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/recommend)

<a id="recycle-bin-recycle-bin"></a>
## Recycle Bin, recycle bin

- Write with capitals both words when referring to the Recycle Bin on the Windows desktop.
- Write in lowercase when referring to the recycle bin in OneDrive.
- In UI, it's OK to use Recycle bin for labels and headings.
- Always use the definite article the, as in the recycle bin.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/recycle-bin)

<a id="refresh"></a>
## refresh

- Prefer to describe updating a webpage.
- Avoid refresh to describe an image being restored on the screen or data being updated.
- Prefer redraw or update instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/refresh)

<a id="registry-registry-settings"></a>
## registry, registry settings

- Prefer lowercase for the word registry except when referring to a named system component, such as the Registry Editor.
- Prefer all uppercase letters for the first-level subtrees, separating words with underscore characters.
- Registry subtrees are usually bold.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/registry-registry-settings)

## reinitialize

<a id="rem-statement"></a>
## REM statement

- OK to use as an abbreviation for remark statement in Visual Basic and some other programs.
- Avoid generically to refer to a comment.
- Prefer comment instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/rem-statement)

<a id="remote"></a>
## remote

- Acceptable: remote as an adjective to describe a person or computer at another site.
- Avoid remote drive to describe a drive on a remote computer.
- Prefer network drive instead.
- Avoid remote as a verb.
- Avoid remote as a noun except to refer to a remote-control device.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/remote)

<a id="remove"></a>
## remove

- Avoid remove to mean delete.
- Prefer remove:
- To describe taking an item off a list in a dialog box that has Add and Remove buttons. - To describe taking a toolbar button off a toolbar or hiding displayed data, such as…
- Related guidance: uninstall, delete, load.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/remove)

<a id="replace"></a>
## replace

- Avoid replace as a noun.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/replace)

<a id="restart"></a>
## restart

- Prefer to describe closing and reopening a program or app or turning a device off and then immediately back on.
- Make it clear which of these you're talking about.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/restart)
