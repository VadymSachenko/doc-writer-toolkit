# Microsoft terms: S (1)

Load this file only when checking one of the indexed terms below.

<a id="s-es"></a>
## (s), (es)

- Don't add (s) or (es) to a singular noun to indicate that it can be singular or plural.
- Most of the time, use plural instead.
- If it's important to indicate both, use one or more.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/s-es)

<a id="sample-vs-preview"></a>
## sample vs. preview

- Prefer sample to describe a graphic representation of something that might show up on the screen.
- Prefer preview to describe a graphic representation of exactly what the customer will
- Related guidance: on the screen.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/sample-vs-preview)

<a id="save"></a>
## save

- Prefer this term as a verb to describe saving app installation files to a device and saving files to a local drive or share.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/save)

<a id="scan-line"></a>
## scan line

- Two words when referring to either the row of pixels read by a scanning device or one of the horizontal lines on a display.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/scan-line)

<a id="screen"></a>
## screen

- Prefer instead of screenful or full screen.
- Exception It's OK to say that a program or app is running in full-screen mode.
- Acceptable: screen in instructions to describe what customers
- Related guidance: on the screen or how they interact with it; Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/screen)

<a id="screen-resolution"></a>
## screen resolution

- For screen resolutions, use number × number instead of number by number. For example, use 640 × 480 instead of 640 by 480.
- Prefer the multiplication sign (×) instead of the letter x.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/screen-resolution)

<a id="screened-subnet"></a>
## screened subnet

- Avoid.
- Prefer perimeter network instead.
- On the first mention, it's OK to say:
- Perimeter network (also known as DMZ, demilitarized zone, and screened subnet)
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/screened-subnet)

<a id="screenshot"></a>
## screenshot

- One word.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/screenshot)

<a id="script-scriptlet"></a>
## script, scriptlet

- Avoid scriptlet.
- Most of the time, use script or a more specific term.
- Acceptable: scriptlet when necessary to refer to a specific component in COM, a section of embedded code, or a small script.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/script-scriptlet)

<a id="scroll"></a>
## scroll

- Avoid.
- Prefer a verb phrase such as move through instead, if the context is clear.
- Acceptable: scroll in content that teaches beginning skills to describe interacting with a document by using a mouse, keyboard, or other peripheral device.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/scroll)

<a id="scroll-bar-scroll-arrow-scroll-box"></a>
## scroll bar, scroll arrow, scroll box

- Most of the time, avoid talking about elements in UI.
- Instead, describe what the customer needs to do.
- Avoid arrow to refer to a scroll arrow.
- Avoid slider or slider box as a synonym for scroll box.
- Avoid gray or shaded area to refer to the scroll bar.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/scroll-bar-scroll-arrow-scroll-box)

<a id="search-box"></a>
## search box

- Don't capitalize unless you need to match the UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/search-box)

<a id="search-search-and-replace"></a>
## search, search and replace

- Avoid search and replace to describe finding and replacing things in a document or other location.
- Prefer find and replace instead.
- Prefer search and replace as verbs, not as nouns or adjectives.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/search-and-replace)

<a id="secondary-menu"></a>
## secondary menu

- Avoid in content for a general audience.
- If it's important to describe how the menu works, use submenu.
- In content for developers, use only in content about creating menus and only if you can't use submenu.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/secondary-menu)

<a id="select"></a>
## select

- Prefer select to refer to marking text, objects, cells, and other items that a customer will take action on, such as copying or moving.
- Describe the marked items as the selection or the selected text, objects, cells, and so on.
- Avoid highlight or pick as a synonym for select.
- For information about using select as a verb in instructions and procedures,
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/select)

<a id="service-level-agreement-sla"></a>
## service-level agreement (SLA)

- Write in full on the first mention.
- Prefer lowercase for the spelled-out term, and note the hyphen.
- Prefer an not a with the acronym.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/service-level-agreement-sla)

<a id="set-up-setup-setup"></a>
## set up, setup, Setup

- Prefer this term as a verb to describe the process of preparing hardware and installed apps for initial use.
- Two words as a verb, one word as an adjective and a noun.
- Don't hyphenate.
- Write with capitals Setup when it refers to the Setup program.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/set-up-setup)

<a id="set-specify"></a>
## set, specify

- Avoid generic terms such as set and specify to describe customer actions.
- Try to use more specific verbs.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/s/set-specify)
