# Microsoft terms: Y (1)

Load this file only when checking one of the indexed terms below.

<a id="y-axis"></a>
## y-axis

- Write in lowercase.
- Hyphenate.
- On the first mention, refer to the y-axis as the value (y) axis.
- On subsequent mentions, use y-axis.
- Acceptable: vertical (y) axis in content for a general audience.
- Related guidance: category axis, value axis.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/y/y-axis)

<a id="y-coordinate"></a>
## y-coordinate

- Write in lowercase.
- Hyphenate.
- Avoid italic formatting for the y in y-coordinate unless the entire word is italic.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/y/y-coordinate)
