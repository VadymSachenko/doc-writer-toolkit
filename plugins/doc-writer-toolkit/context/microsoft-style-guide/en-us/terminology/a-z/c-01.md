# Microsoft terms: C (1)

Load this file only when checking one of the indexed terms below.

<a id="core"></a>
## -core

- Hyphenate adjectives formed by adding -core in reference to types of processors.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/dash-core)

<a id="c-c-c"></a>
## C, C++, C#

- Acceptable: C, C++, and C\# as adjectives.
- Don't form hyphenated modifiers with them, such as C-based or C-callable.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/c-cplusplus-csharp)

<a id="cable"></a>
## cable

- Avoid this term as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cable)

<a id="cabling"></a>
## cabling

- Avoid this term as a synonym for cable or cables.
- In a discussion of network connections, it's OK to use cabling to refer to a combination of cables, connectors, and terminators.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cabling)

<a id="cache-vs-disk-cache"></a>
## cache vs. disk cache

- Differentiate between cache and disk cache.
- Prefer cache to refer to a special memory subsystem where data values are duplicated for quick access. - Use disk cache to refer to a portion of RAM that temporarily stores information read from…
- Avoid cache or file cache to refer to the location of internet files that are downloaded as you browse the web.
- Prefer Temporary Internet Files folder.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cache-vs-disk-cache)

<a id="calendar"></a>
## calendar

- Avoid this term as a verb.
- Prefer schedule, list, or another appropriate verb instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/calendar)

<a id="call-back-callback"></a>
## call back, callback

- Two words as a verb, one word as an adjective or a noun.
- In content for developers, don't use callback to mean callback function.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/call-back-callback)

<a id="call-out-callout"></a>
## call out, callout

- Two words as a verb, one word as an adjective or a noun.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/call-out-callout)

<a id="can-may"></a>
## can, may

- When you
- Related guidance: can in your writing, consider deleting it. Can implies ability but not action. Rewrite to describe the action if possible.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/can-may)

<a id="cancel-canceled-canceling-cancellation"></a>
## cancel, canceled, canceling, cancellation

- Prefer cancel the selection instead of deselect or unmark.
- Prefer clear to refer to check boxes.
- Prefer cancel to describe ending code requests and processes before they're complete.
- Spell canceled and canceling with one l, but spell cancellation with two l' s.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cancel-canceled-canceling-cancellation)

<a id="carry-out-vs-run"></a>
## carry out vs. run

- Prefer run, not carry out, to describe actions related to commands, macros, and programs.
- Related guidance: run vs. execute.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/carry-out-vs-run)

<a id="cascading-style-sheets-css"></a>
## Cascading Style Sheets (CSS)

- Write with capitals references to the technique for adding fonts, colors, and so on to web content.
- Write in full unless the abbreviation CSS is familiar to your audience.
- Write in lowercase references to style sheets created using the technique.
- Avoid CSS to refer to a specific cascading style sheet.
- Instead, use the CSS file, the cascading style sheet, or the style sheet.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cascading-style-sheets-css)

<a id="catalog"></a>
## catalog

- Prefer instead of catalogue.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/catalog)

<a id="category-axis"></a>
## category axis

- Write in lowercase.
- Don't hyphenate.
- Describe the category (x) axis on the first mention.
- On subsequent mentions, use x-axis.
- Acceptable: horizontal (x) axis in content for a general audience.
- Related guidance: [.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/category-axis)

<a id="cell-phone-cellular-phone"></a>
## cell phone, cellular phone

- Avoid.
- Related guidance: Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cell-phone-cellular-phone)

<a id="cellular"></a>
## cellular

- Avoid cellular phone or cell phone.
- Acceptable: cellular in the context of cellular data network or cellular data connection.
- Related guidance: Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cellular)

<a id="center-on"></a>
## center on

- Prefer instead of center around.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/center-on)

<a id="character-set"></a>
## character set

- Avoid this term as a synonym for code page.
- A character set appears on a code page.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/character-set)

<a id="chart"></a>
## chart

- Avoid this term as a verb when referring to entering data for a chart.
- Prefer plot instead.
- Prefer the noun chart instead of graph to refer to graphic representations of data.
- For example, use bar chart, pie chart, and scatter chart.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/chart)

<a id="chat"></a>
## chat

- Prefer this term as an adjective, a noun, or a verb in the context of internet or intranet chat.
- Prefer voice chat and video chat if necessary to avoid ambiguity.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/chat)
