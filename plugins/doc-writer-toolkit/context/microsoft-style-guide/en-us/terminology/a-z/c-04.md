# Microsoft terms: C (4)

Load this file only when checking one of the indexed terms below.

<a id="control-panel"></a>
## Control Panel

- Prefer Control Panel, not the Control Panel, to refer to the entire Windows Control Panel feature.
- Most of the time, refer to specific, named control panels.
- When you must discuss control panels generically, refer to an individual control panel as a control panel item (lowercase).
- When you must refer to the icons that represent control panels, use control panel icon (lowercase).
- Avoid applet, program, tool, or control panel to refer to either the icons or the items.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/control-panel)

<a id="control-menu-box"></a>
## control-menu box

- Avoid referring by name to this icon and the menu that it opens.
- If you must, refer to the \ icon or the \ shortcut menu.

<a id="corrupted"></a>
## corrupted

- Avoid.
- Try to use a more empathetic statement to describe a file or data that has been damaged.
- Better yet, offer help in fixing it if possible.
- Avoid corrupt.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/corrupted)

<a id="country-or-region"></a>
## country or region

- Prefer instead of country for list headings, descriptions, and other contexts that might include named dependencies or disputed territories.
- In general discussions, use just country. Don't use geography or geo as a synonym for country or country or region.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/country-or-region)

<a id="crash"></a>
## crash

- Avoid.
- Prefer fail for disks or other hardware, or stop responding for programs or the operating system.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/crash)

<a id="cut-cut-and-paste"></a>
## cut, cut-and-paste

- Avoid cut:
- As a verb, even to refer to an action involving the Cut command.
- Prefer delete instead. - As a verb to describe temporarily moving text to the clipboard.
- Prefer move or copy instead. - As an imperative verb in procedures involving the Cut or the Delete command.
- Prefer delete instead. - As a noun to refer to the action of the Delete command.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/cut-and-paste)
