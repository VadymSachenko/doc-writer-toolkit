<a id="more-than-vs-over"></a>
## more than vs. over

- Prefer more than to refer to quantifiable figures and amounts—things you can count.
- Prefer over:
- To refer to a position or location that's above something. - In a comparison in which more is already used.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/more-than-vs-over)

<a id="multi"></a>
## multi-

- In general, don't hyphenate words beginning with multi- unless it's necessary to avoid confusion or multi- is followed by a proper noun.
- Check The American Heritage Dictionary.
- If you don't find the word there or in the following list, use multiple before the word instead.
- Don't invent new words by combining words with multi-.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/multi)

<a id="multifactor-authentication"></a>
## multifactor authentication

- When describing an authentication that uses more than one factor, use the term multifactor authentication.
- Avoid multi-factor.
- Instead always use multifactor, without the hyphen.
- Avoid the abbreviated or acronym form of this term.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/multifactor-authentication)

<a id="multiple-selection"></a>
## multiple selection

- Prefer to refer to a selection that includes multiple items.
- Acceptable: adjacent selection if you must emphasize that the selected items are adjacent to one another.
- Avoid disjoint selection, nonadjacent selection, or noncontiguous selection, except in content for a technical audience, and only if the term appears in the UI or API.
- If you need to refer to nonadjacent selected items, use multiple selection or list the specific items.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/multiple-selection)

<a id="multiplication-sign"></a>
## multiplication sign (×)

- Prefer the multiplication sign (×), not the letter x, to indicate the mathematical operation.
- Prefer an asterisk (\) if you need to match the UI.
- Prefer × to mean by when you refer to screen resolution or dimensions.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/m/multiplication-sign)
