# Capitalization

- Default to sentence-style capitalization: capitalize the first word and proper nouns.
- Apply sentence case to headings, titles, table headers, UI text, labels, and list items.
- Preserve official spelling for products, services, organizations, APIs, and trademarks.
- Do not capitalize an ordinary feature, role, team, document type, or concept to signal importance.
- After a colon in an English title or heading, capitalize the first word. In ordinary
  body text, lowercase it unless it is a proper noun or begins a quotation.
- Do not use all caps for emphasis.
- Use title-style capitalization only for official titles that require it, including
  certain books, reports, games, events, and webinars.
