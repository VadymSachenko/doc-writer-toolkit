# Quotation marks, apostrophes, ellipses, and slashes

- Use apostrophes for possession and contractions, not ordinary plurals or decades.
- Prefer straight quotation marks in technical content and code-oriented contexts where
  smart marks could be copied or interpreted incorrectly.
- Use quotation marks for exact messages, strings, and short cited titles when the
  formatting rule calls for them. Do not add quotation marks to every UI label.
- In US English, periods and commas normally go inside closing quotation marks; keep
  literal code and strings exact.
- Use an ellipsis to show omitted quoted material or a deliberate trailing thought, not
  as generic decoration. Preserve a UI ellipsis only when quoting the UI exactly.
- Avoid a slash as a substitute for *and* or *or* in prose. Use it for established units,
  paths, fractions, alternatives in compact labels, and literal syntax.
- When instructing a reader to type a slash, name it and show the character.
