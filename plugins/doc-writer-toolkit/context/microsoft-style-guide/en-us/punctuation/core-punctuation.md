# Core punctuation

- Use one space after sentence-ending punctuation and colons.
- Use periods for complete sentences and procedural steps.
- Do not end titles, headings, subheadings, or UI titles with periods or colons.
- Use a question mark for a direct question, not an indirect question.
- Use exclamation points rarely and never to manufacture enthusiasm or intensify an error.
- Avoid semicolons. Prefer two sentences or a list when the relationship is complex.
- Put punctuation in the same type style as the surrounding sentence unless it is part
  of a formatted literal such as code or a UI string.
- Do not add sentence punctuation to literal input when the reader might type it.
