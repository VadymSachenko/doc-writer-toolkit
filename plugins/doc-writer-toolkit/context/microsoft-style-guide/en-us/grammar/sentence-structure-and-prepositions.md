# Sentence structure, modifiers, and prepositions

- Keep the subject, verb, object, and their modifiers close together.
- Place introductory modifiers next to the person or thing they modify.
- Rewrite a dangling modifier rather than expecting context to repair it.
- Avoid chains of more than two prepositional phrases.
- It is acceptable to end a sentence with a preposition when the alternative sounds
  unnatural or less clear.

## UI prepositions

| Use **on** | Use **in** |
|---|---|
| command bar, search bar, taskbar, toolbar | box, dialog, list |
| command line, menu, page | pane, search results |
| ribbon, tab | system tray, window |
