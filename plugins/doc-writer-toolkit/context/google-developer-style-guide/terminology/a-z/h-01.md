# H terminology — 1 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-hamburger"></a>
## `hamburger, hamburger menu`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer the aria-label for that particular icon. For example, menu Menu.

[Official entry](https://developers.google.com/style/word-list#hamburger)

<a id="term-hands-off"></a>
## `hands off, hands-off`

**Scope:** `do-not-use`  
**Rule:** Use a less figurative phrase, such as automated. If you're referring to a group that doesn't do anything during a process, write a description.

[Official entry](https://developers.google.com/style/word-list#hands-off)

<a id="term-hands-on"></a>
## `hands on, hands-on`

**Scope:** `do-not-use`  
**Rule:** Use a less figurative phrase, such as customizable, or write a description of the activity.

[Official entry](https://developers.google.com/style/word-list#hands-on)

<a id="term-hang"></a>
## `hang, hung`

**Scope:** `do-not-use`  
**Rule:** Do not use to refer to a computer or system that is not responding. Prefer stop responding or not responding.

[Official entry](https://developers.google.com/style/word-list#hang)

<a id="term-happiness"></a>
## `happiness and satisfaction`

**Scope:** `general`  
**Rule:** Use happiness For a customer's perception of a site's reliability. Use satisfaction For whether the site meets the customer's needs. Site reliability engineering (SRE) content generally refers to measuring customer happiness instead of customer satisfaction.

[Official entry](https://developers.google.com/style/word-list#happiness)

[Official entry](https://developers.google.com/style/word-list#hardcode)

<a id="term-he"></a>
## `he, him, his`

**Scope:** `use-with-caution`  
**Rule:** Do not use a gendered pronoun except for a specific individual of known gender. Use they and their for the general singular pronoun.

[Official entry](https://developers.google.com/style/word-list#he)

<a id="term-healthcare"></a>
## `healthcare`

**Scope:** `general`  
**Rule:** Use the heading form; do not use health care or health-care.

[Official entry](https://developers.google.com/style/word-list#healthcare)

<a id="term-health-check"></a>
## `health check`

**Scope:** `use-with-caution`  
**Rule:** Use with caution. When describing an action taken for a computer system, only use the term health check if this is the term that appears in the interface. Be certain to remove any ambiguity regarding whether the term refers to health in the medical sense. Use detailed, non-figurative language as much as possible, such as referring to a node being responsive instead of referring to a node being healthy.

[Official entry](https://developers.google.com/style/word-list#health-check)

## `healthy`

<a id="term-high-availability"></a>
## `high availability (noun), high-availability (adjective)`

**Scope:** `general`  
**Rule:** Spell as high availability when used as a noun and as high-availability when used as an adjective. Lowercase except when part of a product name, but Acceptable to abbreviate as HA after first use.

[Official entry](https://developers.google.com/style/word-list#high-availability)

<a id="term-hold-the-pointer-over"></a>
## `hold the pointer over`

**Scope:** `general`  
**Rule:** Only use this verb phrase in the following cases: When the user needs to hold their mouse over a UI element, but not click the UI element. This action involves waiting for the UI to react—for example, waiting for a tooltip to open or waiting for a submenu to open. When the duration of time is important. The phrase point to is more common.

[Official entry](https://developers.google.com/style/word-list#hold-the-pointer-over)

<a id="term-hot"></a>
## `hot`

**Scope:** `general`  
**Rule:** When possible, avoid jargon like hot failover, hot standby, and hot spare. If you use one of these phrases, define it on first use and use it consistently throughout the document. However, see hotspot.

[Official entry](https://developers.google.com/style/word-list#hot)

<a id="term-hotspot"></a>
## `hotspot`

**Scope:** `general`  
**Rule:** In databases, hotspots occur when a small number of nearby rows are accessed frequently in a short period of time, causing CPU spikes and affecting performance. Use hotspot and hotspots as nouns. Do not use verb and gerund forms such as hotspotting, because they translate less consistently. When you use hotspot, define it the first time that you use it on a page as you normally do with jargon.

[Official entry](https://developers.google.com/style/word-list#hotspot)
