# U terminology — 1 of 1

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-ui"></a>
## `UI`

**Scope:** `general`  
**Rule:** Do not use generically to refer to a page or dashboard. Use a more specific term like page or console. If a specific term is unavailable, use web interface.

[Official entry](https://developers.google.com/style/word-list#ui)

<a id="term-under"></a>
## `under`

**Scope:** `do-not-use`  
**Rule:** Do not use for a range of version numbers. Prefer earlier. Do not use to refer to a position in the UI.

[Official entry](https://developers.google.com/style/word-list#under)

## `Unicode`

[Official entry](https://developers.google.com/style/word-list#unicode)

## `Unix-like`

**Scope:** `general`  
**Rule:** Use the heading form; do not use Unixlike or Unix like.

[Official entry](https://developers.google.com/style/word-list#unix-like)

<a id="term-unix-epoch-time"></a>
## `Unix epoch time`

**Scope:** `general`  
**Rule:** Use instead of Unix time or epoch time to refer to a point in time represented as a number of seconds since the Unix epoch (00:00:00 UTC on January 1, 1970), ignoring leap seconds.

[Official entry](https://developers.google.com/style/word-list#unix-epoch-time)

<a id="term-user"></a>
## `user`

**Scope:** `general`  
**Rule:** Use the word user only to refer to the user of the software that your reader is developing. Otherwise, address the reader as you and assume that they will complete the tasks that you're documenting.

[Official entry](https://developers.google.com/style/word-list#user)

<a id="term-using"></a>
## `using`

**Scope:** `general`  
**Rule:** Where using might have more than one interpretation, use by using to help clarify the logic of the sentence.

[Official entry](https://developers.google.com/style/word-list#using)

<a id="term-utf"></a>
## `UTF`

**Scope:** `general`  
**Rule:** Include the hyphen in the names of Unicode encodings, such as UTF-8, UTF-16, and UTF-32.

[Official entry](https://developers.google.com/style/word-list#utf)

<a id="term-utilize"></a>
## `utilize, utilization`

**Scope:** `general`  
**Rule:** Use with caution. Do not use utilize when you mean use. Acceptable to use utilize or utilization For the quantity of a resource being used.

[Official entry](https://developers.google.com/style/word-list#utilize)
