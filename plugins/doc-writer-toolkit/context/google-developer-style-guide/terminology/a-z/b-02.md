# B terminology — 2 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-blue-green"></a>
## `blue-green`

**Scope:** `general`  
**Rule:** Use the heading form; do not use blue/green or blue green.

[Official entry](https://developers.google.com/style/word-list#blue-green)

<a id="term-boolean"></a>
## `boolean`

**Scope:** `general`  
**Rule:** In most contexts, boolean refers to a specific data type in a specific programming language. In such cases, use code font and the exact spelling and capitalization of the programming keyword. For the abstract data type, use lowercase. If you refer to Boolean mathematics or Boolean logic, use uppercase.

[Official entry](https://developers.google.com/style/word-list#boolean)

<a id="term-branding-information"></a>
## `branding information`

**Scope:** `general`  
**Rule:** In the Google Cloud console, the phrase branding information refers to the information that Google shows to users when the client asks them to authorize access: specifically, the project's name and logo, and the developer's Google Account. This information is set in the Consent screen page.

[Official entry](https://developers.google.com/style/word-list#branding-information)

<a id="term-break-glass"></a>
## `break-glass`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer a more precise term depending on context: To describe a general emergency or procedure that grants emergency access, use emergency access. To describe a fallback procedure, use manual fallback or preplanned procedure.

[Official entry](https://developers.google.com/style/word-list#break-glass)

<a id="term-button"></a>
## `button`

**Scope:** `general`  
**Rule:** In a UI, a link isn't the same as a button; Do not use the term button to refer to a link. Use button to refer to mechanical buttons (like the volume control buttons on the side of a phone) and capacitive touch buttons on a phone (like the Home button). You press mechanical buttons, and tap capacitive and on-screen buttons.

[Official entry](https://developers.google.com/style/word-list#button)
