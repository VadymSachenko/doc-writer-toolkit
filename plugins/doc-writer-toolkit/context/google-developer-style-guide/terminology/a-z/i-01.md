# I terminology — 1 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-iaas"></a>
## `IaaS`

**Scope:** `general`  
**Rule:** Write out on first mention: infrastructure as a service (IaaS).

[Official entry](https://developers.google.com/style/word-list#iaas)

<a id="term-iam"></a>
## `IAM`

**Scope:** `general`  
**Rule:** For the Google Cloud product, spell it out on first use: Identity and Access Management (IAM). For UI text, write this term the way it's written in the UI. For the general practice of identity and access management, spell it out in lowercase on first use and include a parenthetical comment:

[Official entry](https://developers.google.com/style/word-list#iam)

<a id="term-id"></a>
## `ID`

**Scope:** `general`  
**Rule:** Use the heading form; do not use Id or id, except in string literals or enums. In some contexts, it's best to spell out as identifier or identification.

[Official entry](https://developers.google.com/style/word-list#id)

<a id="term-ie"></a>
## `i.e.`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer phrases like that is. Many people confuse e.g. and i.e.

[Official entry](https://developers.google.com/style/word-list#ie)

<a id="term-if"></a>
## `if`

**Scope:** `general`  
**Rule:** Wondering whether to use if or whether? See whether. Although it is common in casual usage to omit the word then in if. then statements, you should include helper words like then in technical documentation.

[Official entry](https://developers.google.com/style/word-list#if)

<a id="term-image"></a>
## `image`

**Scope:** `general`  
**Rule:** Image by itself doesn't localize well because of its many meanings. Consider adding context—for example, disk image or container image.

[Official entry](https://developers.google.com/style/word-list#image)

<a id="term-impact"></a>
## `impact`

**Scope:** `use-with-caution`  
**Rule:** Use only as a noun. Instead of writing that something has an impact, use the word affect.

[Official entry](https://developers.google.com/style/word-list#impact)

<a id="term-index"></a>
## `index`

**Scope:** `general`  
**Rule:** Use the plural indexes unless there is a domain-specific reason (for example, a mathematical or financial context) to use indices.

[Official entry](https://developers.google.com/style/word-list#index)

<a id="term-ingest"></a>
## `ingest`

**Scope:** `general`  
**Rule:** Use import, load, or copy For simple movement of data. Use ingest only For such operations that also involve significant processing of the data.

[Official entry](https://developers.google.com/style/word-list#ingest)

<a id="term-ingress"></a>
## `ingress`

**Scope:** `general`  
**Rule:** For the networking term, use lowercase. For the GKE term or API, capitalize Ingress.

[Official entry](https://developers.google.com/style/word-list#ingress)

<a id="term-in-order-to"></a>
## `in order to`

**Scope:** `use-with-caution`  
**Rule:** Prefer **to**. Use **in order to** only when it prevents ambiguity or materially
improves readability.

[Official entry](https://developers.google.com/style/word-list#in-order-to)

<a id="term-inline"></a>
## `inline`

**Scope:** `general`  
**Rule:** One word as an adjective, inline, not in line or in-line.

[Official entry](https://developers.google.com/style/word-list#inline)

<a id="term-instance-group"></a>
## `instance group`

**Scope:** `general`  
**Rule:** Do not abbreviate to IG.

[Official entry](https://developers.google.com/style/word-list#instance-group)

<a id="term-intercluster"></a>
## `intercluster`

**Scope:** `general`  
**Rule:** Use unhyphenated intercluster, not inter-cluster.

[Official entry](https://developers.google.com/style/word-list#intercluster)

<a id="term-interconnect-attachment"></a>
## `interconnectAttachment`

**Scope:** `general`  
**Rule:** Use For the API. Otherwise, use VLAN attachment.

[Official entry](https://developers.google.com/style/word-list#interconnect-attachment)

<a id="term-interconnect-connection"></a>
## `Interconnect connection`

**Scope:** `general`  
**Rule:** Use **Interconnect connection** only with the official product name, such as
**Dedicated Interconnect connection** or **Partner Interconnect connection**. **Connection**
is acceptable later. Do not use standalone **Interconnect**, generic **cloud interconnect
connection**, or **cross-connect**.

[Official entry](https://developers.google.com/style/word-list#interconnect-connection)

<a id="term-interconnect-connection-location"></a>
## `Interconnect connection location`

**Scope:** `general`  
**Rule:** Only refer to an Interconnect connection location in context of a specific product, for example CDN Interconnect. Acceptable to also use colocation facility.

[Official entry](https://developers.google.com/style/word-list#interconnect-connection-location)

<a id="term-interconnect-type"></a>
## `interconnect type`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer connection type. Examples of connection types are a dedicated connection or a connection provided by a service provider.

[Official entry](https://developers.google.com/style/word-list#interconnect-type)

<a id="term-interface"></a>
## `interface`

**Scope:** `general`  
**Rule:** Acceptable as a noun. Do not use as a verb. Prefer interact, talk, speak, communicate, or other similar terms.

[Official entry](https://developers.google.com/style/word-list#interface)

<a id="term-internal-dns"></a>
## `internal DNS`

**Scope:** `general`  
**Rule:** Write internal all lowercase except at the beginning of a sentence, heading, or list item.

[Official entry](https://developers.google.com/style/word-list#internal-dns)
