# G terminology — 1 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-gigabytes-per-second"></a>
## `GBps`

**Scope:** `general`  
**Rule:** Use this abbreviation for **gigabytes per second**; do not use `GB/s`.

[Official entry](https://developers.google.com/style/word-list#gigabytes-per-second)

<a id="term-gbps"></a>
## `Gbps`

**Scope:** `general`  
**Rule:** Use this abbreviation for **gigabits per second**; do not use `Gb/s`.

[Official entry](https://developers.google.com/style/word-list#gbps)

<a id="term-gcloud"></a>
## `gcloud CLI`

**Scope:** `general, google-cloud-only`  
**Rule:** Use the full name Google Cloud CLI the first time that you mention the product on a page.

[Official entry](https://developers.google.com/style/word-list#gcloud)

<a id="term-gender"></a>
## `gender-neutral he, him, or his (or she or her)`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer the singular they (see Jane Austen and other famous authors violate what everyone learned in their English class). Do not use he/she or (s)he or other such punctuational approaches.

[Official entry](https://developers.google.com/style/word-list#gender)

<a id="term-generative-ai"></a>
## `generative AI`

**Scope:** `general`  
**Rule:** Spell out generative. Use sentence case. Do not use gen AI or Gen AI. Do not hyphenate generative AI as an adjective unless you must do so for clarity.

[Official entry](https://developers.google.com/style/word-list#generative-ai)

<a id="term-ghetto"></a>
## `ghetto`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer more precise terms like clumsy, workaround, or inelegant to refer to code that isn't in a production-ready state.

[Official entry](https://developers.google.com/style/word-list#ghetto)

<a id="term-gimp"></a>
## `gimp, gimpy`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer precise, non-figurative language to refer to a deficiency in a component. Acceptable in reference to companies, tools, software packages, and other entities that use the term in their names.

[Official entry](https://developers.google.com/style/word-list#gimp)

<a id="term-gke-node"></a>
## `GKE node`

**Scope:** `general`  
**Rule:** Use when first introducing GKE nodes on a given page. For subsequent mentions, you can use node. A GKE node is a worker machine that runs containerized applications and other workloads. The machine is a Compute Engine VM that GKE creates during cluster creation.

[Official entry](https://developers.google.com/style/word-list#gke-node)
