# W terminology — 1 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-wake-lock"></a>
## `wake lock (noun), wake-lock (adjective)`

**Scope:** `general`  
**Rule:** Spell as wake lock when used as a noun and as wake-lock when used as an adjective.

[Official entry](https://developers.google.com/style/word-list#wake-lock)

<a id="term-walkthrough"></a>
## `walkthrough`

**Scope:** `general`  
**Rule:** Use the heading form; do not use walk-through.

[Official entry](https://developers.google.com/style/word-list#walkthrough)

<a id="term-war-room"></a>
## `war room, warroom, war-room`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer a more precise term to describe the activity or team. Depending on context, possible alternatives include rapid response team, situation response team, situation room, incident-management team, or media monitoring room.

[Official entry](https://developers.google.com/style/word-list#war-room)

<a id="term-warm"></a>
## `warm`

**Scope:** `general`  
**Rule:** When possible, avoid jargon like warm failover, warm standby, and warm spare. If you use one of these phrases, define it on first use and use it consistently throughout the document.

[Official entry](https://developers.google.com/style/word-list#warm)

<a id="term-we"></a>
## `we`

**Scope:** `general`  
**Rule:** Do not use we (or other first-person plural pronouns such as our or us) to address the reader who is performing the tasks that you're documenting. Prefer you. Acceptable to use we to refer to the organization that's represented as the author of the document as long as the antecedent is clear.

[Official entry](https://developers.google.com/style/word-list#we)

<a id="term-whether"></a>
## `whether`

**Scope:** `general`  
**Rule:** To decide whether it's more appropriate to use if or whether, see Grammar Girl's discussion of if and whether. To decide whether you need to add or not when using whether, see the New York Times's blog post about whether (or not).

<a id="term-while"></a>
## `while`

**Scope:** `general`  
**Rule:** Do not use to indicate a contrast. Prefer a more precise term, such as although. Acceptable to refer to a period of time.

[Official entry](https://developers.google.com/style/word-list#while)

<a id="term-white-box"></a>
## `white-box`

**Scope:** `use-with-caution`  
**Rule:** Avoid using white-box, whitebox, or white box to describe monitoring and testing. Consider using a more precise term for clarity. For monitoring, use introspective monitoring. For testing, use clear-box testing.

[Official entry](https://developers.google.com/style/word-list#white-box)

## `whitepaper`
