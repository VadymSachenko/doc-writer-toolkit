# D terminology — 1 of 3

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-dash"></a>
## `dash`

**Scope:** `general`  
**Rule:** A dash (—) isn't the same character as a hyphen (-). The characters are used for different purposes. Therefore, do not use the word dash to refer to a hyphen.

[Official entry](https://developers.google.com/style/word-list#dash)

<a id="term-dashboard"></a>
## `dashboard`

**Scope:** `use-with-caution`  
**Rule:** Do not use to refer to the Google Cloud console. Use dashboard not Dashboard unless it's officially part of a product name.

[Official entry](https://developers.google.com/style/word-list#dashboard)

<a id="term-data"></a>
## `data`

**Scope:** `general`  
**Rule:** Use data as singular, not plural; the data is, not the data are. Use data as a mass noun, not a count noun; less data, not fewer data.

[Official entry](https://developers.google.com/style/word-list#data)

<a id="term-dataflow"></a>
## `data flow (noun); dataflow (noun)`

**Scope:** `general`  
**Rule:** If it's possible to replace with the phrase flow of data, then use two words: data flow. If that replacement doesn't work, such as For something like stream processing or reactive programming, then use one word: dataflow.

[Official entry](https://developers.google.com/style/word-list#dataflow)

<a id="term-denylisted"></a>
## `denylist (verb), denylisted, denylisting`

**Scope:** `do-not-use`  
**Rule:** Do not use **denylist** as a verb; rewrite the action precisely. **Denylist** is
acceptable as a noun.

[Official entry](https://developers.google.com/style/word-list#denylisted)

<a id="term-deprecate"></a>
## `deprecate`

**Scope:** `general`  
**Rule:** To deprecate an item is to recommend against the item's use, typically as a warning that the item will soon be unavailable or unsupported. Do not use deprecated to mean removed, deleted, shut down, or turned down.

[Official entry](https://developers.google.com/style/word-list#deprecate)
