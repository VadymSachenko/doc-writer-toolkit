# K terminology — 1 of 1

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-k8s"></a>
## `k8s`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer Kubernetes.

[Official entry](https://developers.google.com/style/word-list#k8s)

<a id="term-kilobytes-per-second"></a>
## `KBps`

**Scope:** `general`  
**Rule:** Use this abbreviation for **kilobytes per second**; do not use `KB/s`.

[Official entry](https://developers.google.com/style/word-list#kilobytes-per-second)

<a id="term-kbps"></a>
## `Kbps`

**Scope:** `general`  
**Rule:** Use this abbreviation for **kilobits per second**; do not use `Kb/s`.

[Official entry](https://developers.google.com/style/word-list#kbps)

<a id="term-kebab"></a>
## `kebab, kabob, kebab menu, kabob menu`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer the aria-label for that particular icon. For example, more_vert More.

[Official entry](https://developers.google.com/style/word-list#kebab)

<a id="term-kebab-case"></a>
## `kebab case, kabob case, kebab-case, kabob-case`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer dash-case.

[Official entry](https://developers.google.com/style/word-list#kebab-case)

<a id="term-key"></a>
## `key`

**Scope:** `general`  
**Rule:** Do not use as an adjective in the sense of crucial or important. If you use key as a noun, specify which kind of key you're referring to on first mention, because there are many kinds of keys in technical contexts.

[Official entry](https://developers.google.com/style/word-list#key)

<a id="term-key-pair"></a>
## `key pair`

**Scope:** `general`  
**Rule:** A pair of keys, such as a public key and a private key. Contrast with key-value pair, which refers to a pairing that specifies a value for a variable (as in configuration files).

[Official entry](https://developers.google.com/style/word-list#key-pair)

<a id="term-key-ring"></a>
## `key ring`

**Scope:** `general`  
**Rule:** Use instead of keyring (without the space) For a grouping of Cloud KMS keys.

[Official entry](https://developers.google.com/style/word-list#key-ring)

<a id="term-key-value"></a>
## `key-value pair`

**Scope:** `general`  
**Rule:** Use instead of key/value pair or key value pair.

[Official entry](https://developers.google.com/style/word-list#key-value)

<a id="term-kill"></a>
## `kill`

**Scope:** `use-with-caution`  
**Rule:** Avoid when possible. Prefer words like stop, exit, cancel, or end. For exceptions to this rule, see Documenting command-line syntax.

[Official entry](https://developers.google.com/style/word-list#kill)
