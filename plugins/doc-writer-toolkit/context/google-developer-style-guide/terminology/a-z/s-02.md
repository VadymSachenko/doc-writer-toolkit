# S terminology — 2 of 3

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-she"></a>
## `she, her, hers`

**Scope:** `use-with-caution`  
**Rule:** Do not use a gendered pronoun except for a specific individual of known gender. Use they and their for the general singular pronoun.

[Official entry](https://developers.google.com/style/word-list#she)

<a id="term-sherpa"></a>
## `sherpa`

**Scope:** `do-not-use`  
**Rule:** If possible, use a more precise term. For example, if you mean guide, use that term.

[Official entry](https://developers.google.com/style/word-list#sherpa)

<a id="term-shift-left"></a>
## `shift left`

**Scope:** `use-with-caution`  
**Rule:** In general, avoid using this term to mean moving something earlier in time. Prefer a less figurative phrase, such as shift earlier or move to an earlier phase. This figurative term relies on the non-universal assumption that the natural flow is from left to right. Acceptable to use shift left and shift right in the context of binary multiplication and division.

[Official entry](https://developers.google.com/style/word-list#shift-left)

<a id="term-should"></a>
## `should, should be`

**Scope:** `use-with-caution`  
**Rule:** Generally avoid. Because should is ambiguous by definition, it can be problematic. For more information and alternatives, see Word choice for recommendations and requirements. Replace it with a word matched to what's actually meant: must for a requirement, we recommend for a recommendation, can for an optional action, will for an expected outcome, might for a merely possible outcome, or state the actual current behavior directly instead of a hedge.

[Official entry](https://developers.google.com/style/word-list#should)

<a id="term-simple"></a>
## `simple, simply`

**Scope:** `use-with-caution`  
**Rule:** What might be simple for you might not be simple for others. Try eliminating this word from the sentence because usually the same meaning can be conveyed without it.

[Official entry](https://developers.google.com/style/word-list#simple)

<a id="term-since"></a>
## `since`

**Scope:** `general`  
**Rule:** If you mean because, then use because instead of since. Since is ambiguous; it can refer to the passage of time. Because refers to causation or the reason for something.

[Official entry](https://developers.google.com/style/word-list#since)

<a id="term-single-most"></a>
## `single most`

**Scope:** `general`  
**Rule:** Use the heading form; do not use singlemost.

[Official entry](https://developers.google.com/style/word-list#single-most)

<a id="term-single-pane-of-glass"></a>
## `single pane of glass`

**Scope:** `general`  
**Rule:** Avoid. This term is used to favorably compare a centralized control and monitoring interface against the alternative of several disparate interfaces. It can almost always be replaced by single interface or unified interface.

[Official entry](https://developers.google.com/style/word-list#single-pane-of-glass)

<a id="term-slave"></a>
## `slave`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer alternative terms appropriate to your domain, such as worker or replica. If the command or code that you're documenting uses the literal word slave, then use this word only in direct reference to the code item (formatted as code), make it clear what you're referring to, and use the new term thereafter.

[Official entry](https://developers.google.com/style/word-list#slave)

<a id="term-slice"></a>
## `slice and dice`

**Scope:** `do-not-use`  
**Rule:** Do not use the phrase slice and dice. Prefer specific terms appropriate to the task that you're describing. Some possible options include: segment data for analysis or break information into smaller parts.

[Official entry](https://developers.google.com/style/word-list#slice)

<a id="term-smartphone"></a>
## `smartphone, smart phone`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer mobile phone or phone. If you're talking about more than phones, then use mobile device. Acceptable to use phone (without mobile) when the context is clear.

[Official entry](https://developers.google.com/style/word-list#smartphone)

<a id="term-soon"></a>
## `soon`

**Scope:** `use-with-caution`  
**Rule:** Avoid in timeless documentation because this word can become outdated. The word can also prematurely disclose product or feature strategy or inappropriately imply that a product or feature might change.

[Official entry](https://developers.google.com/style/word-list#soon)

<a id="term-spin-up"></a>
## `spin up`

**Scope:** `use-with-caution`  
**Rule:** Avoid colloquial **spin up** unless referring to a hard disk. Prefer **create** or
**start** for a resource or process.

[Official entry](https://developers.google.com/style/word-list#spin-up)

## `SQL`

**Scope:** `general`

[Official entry](https://developers.google.com/style/word-list#sql)

<a id="term-ssh"></a>
## `ssh and SSH`

**Scope:** `general`  
**Rule:** Do not use ssh or SSH as a verb. SSH is a secure communications protocol; ssh is a utility.

[Official entry](https://developers.google.com/style/word-list#ssh)
