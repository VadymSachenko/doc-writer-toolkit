# C terminology — 3 of 3

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-cross-site-request-forgery"></a>
## `cross-site request forgery`

**Scope:** `general`  
**Rule:** Lowercase except at the beginning of a sentence, heading, or list item.

[Official entry](https://developers.google.com/style/word-list#cross-site-request-forgery)

<a id="term-curated-roles"></a>
## `curated roles`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer predefined roles.

[Official entry](https://developers.google.com/style/word-list#curated-roles)

<a id="term-currently"></a>
## `currently`

**Scope:** `use-with-caution`  
**Rule:** Avoid because this word is implied. The word can also prematurely disclose product or feature strategy or inappropriately imply that a product or feature might change.

[Official entry](https://developers.google.com/style/word-list#currently)

<a id="term-custom-mode-vpc-network"></a>
## `custom mode VPC network`

**Scope:** `general`  
**Rule:** Use the heading form; do not use custom mode network.

[Official entry](https://developers.google.com/style/word-list#custom-mode-vpc-network)

<a id="term-curl"></a>
## `curl`

**Scope:** `general`  
**Rule:** Use the heading form; do not use cURL. For information about when to use code format, see Items that are sometimes in code font.

[Official entry](https://developers.google.com/style/word-list#curl)

<a id="term-cyber-monday"></a>
## `Cyber Monday`

**Scope:** `general`  
**Rule:** Avoid unless explicitly referring to an event in the US. Prefer peak scale event.

[Official entry](https://developers.google.com/style/word-list#cyber-monday)
