# S terminology — 3 of 3

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-sshing"></a>
## `ssh'ing`

**Scope:** `do-not-use`  
**Rule:** Do not use.

[Official entry](https://developers.google.com/style/word-list#sshing)

<a id="term-startup"></a>
## `startup (noun or adjective), start up (verb)`

**Scope:** `general`  
**Rule:** Use this spelling and form unless a project-specific rule overrides it.

[Official entry](https://developers.google.com/style/word-list#startup)

<a id="term-static-external-ip-address"></a>
## `static external IP address`

**Scope:** `general`  
**Rule:** Do not use static IP address or external IP address to refer to static external IP addresses.

[Official entry](https://developers.google.com/style/word-list#static-external-ip-address)

<a id="term-status-bar"></a>
## `status bar`

**Scope:** `general`  
**Rule:** Use the heading form; do not use statusbar or status-bar. Lowercase except at the beginning of a sentence, heading, or list item.

[Official entry](https://developers.google.com/style/word-list#status-bar)

<a id="term-stonith"></a>
## `STONITH, STOMITH`

**Scope:** `use-with-caution`  
**Rule:** Avoid using graphic or metaphorical language. Instead, explain the relevant feature, such as fence failed nodes.

[Official entry](https://developers.google.com/style/word-list#stonith)

<a id="term-style-sheet"></a>
## `style sheet`

**Scope:** `general`  
**Rule:** Style sheet and stylesheet are both acceptable spellings. However, be consistent with your choice throughout a given document.

[Official entry](https://developers.google.com/style/word-list#style-sheet)

<a id="term-sub-command"></a>
## `sub-command`

**Scope:** `general`  
**Rule:** Use the heading form; do not use subcommand.

[Official entry](https://developers.google.com/style/word-list#sub-command)

<a id="term-subnet"></a>
## `subnet`

**Scope:** `general`  
**Rule:** **Subnet** is an acceptable short form of **subnetwork**. Choose one term and use
it consistently.

[Official entry](https://developers.google.com/style/word-list#subnet)

## `subtree`

[Official entry](https://developers.google.com/style/word-list#subtree)

<a id="term-subzone"></a>
## `subzone`

**Scope:** `general`  
**Rule:** Use the heading form; do not use sub-zone or sub zone.

[Official entry](https://developers.google.com/style/word-list#subzone)

<a id="term-such-as"></a>
## `such as`

**Scope:** `general`  
**Rule:** Use such as to introduce examples or draw comparisons. Note that such as, like, and include introduce non-exhaustive lists, so it's redundant to combine them with etc., so forth, or and more.

[Official entry](https://developers.google.com/style/word-list#such-as)

<a id="term-surface"></a>
## `surface`

**Scope:** `general`  
**Rule:** Avoid as a transitive verb; prefer a precise phrase such as **make people aware
of** or **expose**.

[Official entry](https://developers.google.com/style/word-list#surface)
