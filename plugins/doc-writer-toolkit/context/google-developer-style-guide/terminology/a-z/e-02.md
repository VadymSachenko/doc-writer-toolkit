# E terminology — 2 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-exploit"></a>
## `exploit`

**Scope:** `general`  
**Rule:** Do not use exploit to mean "use." Only use exploit in the negative sense, such as to describe exploiting a security vulnerability.

[Official entry](https://developers.google.com/style/word-list#exploit)

<a id="term-external-vpn-gateway"></a>
## `external VPN gateway`

**Scope:** `general`  
**Rule:** Write external and gateway all lowercase except at the beginning of a sentence, heading or list item.

[Official entry](https://developers.google.com/style/word-list#external-vpn-gateway)

<a id="term-extract"></a>
## `extract`

**Scope:** `general`  
**Rule:** Use instead of unarchive, uncompress, untar, or unzip.

[Official entry](https://developers.google.com/style/word-list#extract)
