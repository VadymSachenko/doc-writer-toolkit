# A terminology — 2 of 3

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-all-apps-screen"></a>
## `all apps screen`

**Scope:** `general, android-only`  
**Rule:** In Android documentation: Lowercase except at the beginning of a sentence, heading, or list item.

[Official entry](https://developers.google.com/style/word-list#all-apps-screen)

<a id="term-allowlist"></a>
## `allowlist (verb), allowlisted, allowlisting`

**Scope:** `do-not-use`  
**Rule:** Do not use **allowlist** as a verb; rewrite the action precisely. **Allowlist** is
acceptable as a noun.

[Official entry](https://developers.google.com/style/word-list#allowlist)

<a id="term-allows-you-to"></a>
## `allows you to`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer lets you.

[Official entry](https://developers.google.com/style/word-list#allows-you-to)

<a id="term-alpha"></a>
## `alpha`

**Scope:** `general`  
**Rule:** Lowercase except when part of a product name.

[Official entry](https://developers.google.com/style/word-list#alpha)

<a id="term-america"></a>
## `America, American`

**Scope:** `use-with-caution`  
**Rule:** Use only to refer to the Americas or the American continent. Do not use to refer to the United States. Prefer a more precise term like the US or the United States, and people in the US.

[Official entry](https://developers.google.com/style/word-list#america)

<a id="term-among"></a>
## `among`

**Scope:** `general`  
**Rule:** See between versus among.

[Official entry](https://developers.google.com/style/word-list#among)

<a id="term-am-pm"></a>
## `AM, PM`

**Scope:** `general`  
**Rule:** To be consistent with Material Design, use all caps, no periods, and a space before.

[Official entry](https://developers.google.com/style/word-list#am-pm)

<a id="term-and-or"></a>
## `and/or`

**Scope:** `use-with-caution`  
**Rule:** Do not use unless space is limited, such as in a table.

[Official entry](https://developers.google.com/style/word-list#and-or)

<a id="term-android"></a>
## `Android`

**Scope:** `general, android-only`  
**Rule:** For the operating system, capitalize Android.

[Official entry](https://developers.google.com/style/word-list#android)

<a id="term-android-powered"></a>
## `Android-powered device`

**Scope:** `general, android-only`  
**Rule:** Use the heading form; do not use Android device.

[Official entry](https://developers.google.com/style/word-list#android-powered)

<a id="term-and-so-on"></a>
## `and so on`

**Scope:** `use-with-caution`  
**Rule:** Avoid using and so on whenever possible.

[Official entry](https://developers.google.com/style/word-list#and-so-on)

<a id="term-anti"></a>
## `anti*`

**Scope:** `general`  
**Rule:** See guidance about hyphens with prefixes.

[Official entry](https://developers.google.com/style/word-list#anti)

<a id="term-anti-pattern"></a>
## `anti-pattern`

**Scope:** `use-with-caution`  
**Rule:** Avoid using anti-pattern, particularly as a standalone heading. Instead, consider using a more specific and broadly understood term.

[Official entry](https://developers.google.com/style/word-list#anti-pattern)

<a id="term-api"></a>
## `API`

**Scope:** `general`  
**Rule:** Use **API** for a web API or a language-specific API, not for an individual
method or class.

[Official entry](https://developers.google.com/style/word-list#api)

<a id="term-api-console"></a>
## `API Console, APIs console, developer console, dev console, or Google API Console`

**Scope:** `do-not-use`  
**Rule:** Do not use. Instead, refer to the Google APIs Explorer or to the Google Cloud console.

[Official entry](https://developers.google.com/style/word-list#api-console)

<a id="term-api-console-key"></a>
## `API Console key`

**Scope:** `general`  
**Rule:** In most contexts, use API key instead of API Console key. In Apps admin APIs, Acceptable to use API Console key to distinguish from other API keys.

[Official entry](https://developers.google.com/style/word-list#api-console-key)

<a id="term-api-key"></a>
## `API key`

**Scope:** `general`  
**Rule:** Use the heading form; do not use developer key or dev key.

[Official entry](https://developers.google.com/style/word-list#api-key)

<a id="term-apis-explorer"></a>
## `APIs Explorer`

**Scope:** `general`  
**Rule:** Use the heading form; do not use API explorer or other variants.

[Official entry](https://developers.google.com/style/word-list#apis-explorer)

<a id="term-app"></a>
## `app`

**Scope:** `general`  
**Rule:** In general, use app instead of application For programs for end users, especially in the context of mobile or web software. In some contexts, such as enterprise software, Acceptable to use application to convey a sense of greater complexity. Use application in standard phrases such as application programming interface.

[Official entry](https://developers.google.com/style/word-list#app)

## `app bar`

**Scope:** `general, android-only`  
**Rule:** In Android contexts, formerly action bar.

[Official entry](https://developers.google.com/style/word-list#app-bar)
