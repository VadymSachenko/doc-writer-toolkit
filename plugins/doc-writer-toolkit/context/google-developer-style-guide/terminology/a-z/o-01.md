# O terminology — 1 of 1

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-oauth-20"></a>
## `OAuth 2.0`

**Scope:** `general`  
**Rule:** Use the heading form; do not use OAuth 2, OAuth2, or Oauth.

[Official entry](https://developers.google.com/style/word-list#oauth-20)

<a id="term-off-the-shelf"></a>
## `off-the-shelf, commercial off-the-shelf (COTS)`

**Scope:** `do-not-use`  
**Rule:** Use more widely understood terms like ready-made, prebuilt, standard, or default.

[Official entry](https://developers.google.com/style/word-list#off-the-shelf)

<a id="term-old"></a>
## `old, older`

**Scope:** `use-with-caution`  
**Rule:** Do not use to refer to a previous version of a product. Prefer earlier. Make sure that you provide a version number by which to understand earlier. In Android documentation, use lower instead of earlier.

[Official entry](https://developers.google.com/style/word-list#old)

<a id="term-on-premises"></a>
## `on-premises`

**Scope:** `general`  
**Rule:** Use the heading form; do not use on prem, on premise, or on-premise. Hyphenate when used as any part of speech. Use to refer to a customer's resources that they manage in their own facilities. Do not use peer. It can be acceptable to use on-premises as a noun when it would be awkward to repeatedly write out a full phrase like an on-premises environment. However, it's preferable to use the more complete phrase whenever possible.

[Official entry](https://developers.google.com/style/word-list#on-premises)
