# A terminology — 3 of 3

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-as"></a>
## `as`

**Scope:** `general`  
**Rule:** If you mean because, then use because instead of as. As is ambiguous; it can refer to the passage of time. Because refers to causation or the reason for something.

[Official entry](https://developers.google.com/style/word-list#as)

<a id="term-as-of-this-writing"></a>
## `as of this writing`

**Scope:** `use-with-caution`  
**Rule:** Avoid because this phrase is implied. The phrase can also prematurely disclose product or feature strategy or inappropriately imply that a product or feature might change.

[Official entry](https://developers.google.com/style/word-list#as-of-this-writing)

<a id="term-authentication-and-authorization"></a>
## `authentication and authorization`

**Scope:** `general`  
**Rule:** In general, use the word authenticated only to refer to users, and use authorized only to refer to requests that are sent by a client app on behalf of an authenticated user. When you want to use a preposition with authenticate, use against.

[Official entry](https://developers.google.com/style/word-list#authentication-and-authorization)

<a id="term-authn-authz"></a>
