# N terminology — 1 of 1

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-na"></a>
## `N/A`

**Scope:** `general`  
**Rule:** Use the heading form; do not use NA. Spell out as not available or not applicable on first reference.

[Official entry](https://developers.google.com/style/word-list#na)

<a id="term-name-server"></a>
## `name server`

**Scope:** `general`  
**Rule:** Use the heading form; do not use nameserver.

[Official entry](https://developers.google.com/style/word-list#name-server)

<a id="term-namespace"></a>
## `namespace`

**Scope:** `general`  
**Rule:** Use the heading form; do not use name space.

[Official entry](https://developers.google.com/style/word-list#namespace)

<a id="term-native"></a>
## `native`

**Scope:** `use-with-caution`  
**Rule:** Avoid using native to refer to people. For software products, try to use a more precise term—for example, use built-in to describe a feature that's part of a product.

[Official entry](https://developers.google.com/style/word-list#native)

<a id="term-navigation-bar"></a>
## `navigation bar`

**Scope:** `general`  
**Rule:** Do not use to refer to a navigation menu.

[Official entry](https://developers.google.com/style/word-list#navigation-bar)

## `neither`

**Scope:** `general`  
**Rule:** Write neither A nor B, not neither A or B.

[Official entry](https://developers.google.com/style/word-list#neither)

<a id="term-network-ip-address"></a>
## `network IP address`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer internal IP address.

[Official entry](https://developers.google.com/style/word-list#network-ip-address)

<a id="term-new"></a>
## `new, newer`

**Scope:** `use-with-caution`  
**Rule:** Avoid in timeless documentation because this word can become outdated. If you must use new, give the reader a reference point—for example, a version number or release date. Do not use newer to refer to a specific version of a product. Prefer later.

[Official entry](https://developers.google.com/style/word-list#new)

<a id="term-ninja"></a>
## `ninja`

**Scope:** `do-not-use`  
**Rule:** Do not use to refer to a person. Prefer a term such as expert. Acceptable in reference to companies, tools, software packages, and other entities that use the term in their names.

[Official entry](https://developers.google.com/style/word-list#ninja)

[Official entry](https://developers.google.com/style/word-list#non)

<a id="term-nonce"></a>
## `nonce`

**Scope:** `use-with-caution`  
**Rule:** Use with caution: this term has a secondary slang meaning that can cause confusion for global readers. Always define the term on first use, and only use it in specific technical contexts such as authentication and blockchain. In end-user documentation and other contexts, use a more descriptive phrase, such as a number that will be used only once.

[Official entry](https://developers.google.com/style/word-list#nonce)

## `non-key`

[Official entry](https://developers.google.com/style/word-list#non-key)

<a id="term-noops"></a>
## `NoOps`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer fully managed. If you must include the term, define it at first use with language such as fully managed or no operations, but not non-operational. Do not use noops. For an instruction that does nothing, use no-op or the specific instruction name for your context.

[Official entry](https://developers.google.com/style/word-list#noops)

<a id="term-notification-drawer"></a>
## `notification drawer`

**Scope:** `general, android-only`  
**Rule:** In Android contexts, do not hyphenate. Lowercase except at the beginning of a sentence, heading, or list item.

[Official entry](https://developers.google.com/style/word-list#notification-drawer)

<a id="term-now"></a>
## `now`

**Scope:** `use-with-caution`  
**Rule:** Avoid when describing features of products or services because this word is implied. If the intent of the text is a comparison between past and present, you can use now—for example, "In versions of the tool earlier than 1.10, you could use only the default value, but now you can assign a custom value."

[Official entry](https://developers.google.com/style/word-list#now)

<a id="term-nuke"></a>
## `nuke`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer remove or attack. For example, a denial-of-service attack.

[Official entry](https://developers.google.com/style/word-list#nuke)
