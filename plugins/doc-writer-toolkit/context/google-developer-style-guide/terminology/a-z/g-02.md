# G terminology — 2 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-grandfathered"></a>
## `grandfathered`

**Scope:** `do-not-use`  
**Rule:** Do not use to refer to something that is allowed to violate a rule because it predates the rule. Prefer an adjective like legacy or exempt or a verb like made an exception.

[Official entry](https://developers.google.com/style/word-list#grandfathered)

<a id="term-gray-box"></a>
## `gray-box, grey-box`

**Scope:** `use-with-caution`  
**Rule:** Avoid using gray-box, graybox, or gray box to describe testing. To refer to testing that's a combination of clear and opaque testing methods, describe exactly what it's doing. If you need to refer to this type of testing after you describe it, consider using a more precise term for clarity, such as translucent-box testing.

[Official entry](https://developers.google.com/style/word-list#gray-box)

<a id="term-gypsy"></a>
## `gypsy`

**Scope:** `do-not-use`  
**Rule:** Do not use. To refer to the people, use Romani, Roma, or Traveller, as appropriate for the specific group you're referring to. In place of metaphorical uses of the term, use more precise phrases.

[Official entry](https://developers.google.com/style/word-list#gypsy)
