# M terminology — 1 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-male-adapter"></a>
## `male adapter`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer a genderless word like plug.

[Official entry](https://developers.google.com/style/word-list#male-adapter)

<a id="term-man-hours"></a>
## `man hours, manhours, man-hours`

**Scope:** `do-not-use`  
**Rule:** Avoid using gendered terms. Prefer terms like person hours.

[Official entry](https://developers.google.com/style/word-list#man-hours)

<a id="term-mitm"></a>
## `man-in-the-middle (MITM)`

**Scope:** `do-not-use`  
**Rule:** Avoid using gendered terms. Prefer terms like on-path attacker or person-in-the-middle (PITM).

[Official entry](https://developers.google.com/style/word-list#mitm)

<a id="term-markdown"></a>
## `Markdown`

**Scope:** `general`

[Official entry](https://developers.google.com/style/word-list#markdown)

<a id="term-master"></a>
## `master`

**Scope:** `do-not-use`  
**Rule:** Use with caution. Never use in conjunction with slave. Where possible, replace master with a specific term that is accurate for the context, such as primary, main, original, parent, initiator, driver, controller, manager, mixer, aggregator, publisher, leader, or active.

[Official entry](https://developers.google.com/style/word-list#master)

<a id="term-matrix"></a>
## `matrix`

**Scope:** `general`

[Official entry](https://developers.google.com/style/word-list#matrix)

<a id="term-may"></a>
## `may`

**Scope:** `general`  
**Rule:** In general, reserve for official policy or legal considerations. To convey possibility, use can or might instead. To convey permission, use can instead. For information about clarifying who's performing an action, see Active voice.

[Official entry](https://developers.google.com/style/word-list#may)

[Official entry](https://developers.google.com/style/word-list#megabytes-per-second)

<a id="term-media-type"></a>
## `media type`

**Scope:** `general`  
**Rule:** In general, use the term media type. In contexts where you need to refer to a content type—For example, if you mention the Content-Type HTTP header—it's okay to use content type instead, to avoid confusion. Do not use MIME type.

[Official entry](https://developers.google.com/style/word-list#media-type)
