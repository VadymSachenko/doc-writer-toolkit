# Reference-documentation verbs

## GDSG-REFVERB-001 — Describe what an element does

Start a method, function, or similar member’s main description with a present-tense,
third-person singular verb.

**Recommended:** Creates a session. Returns the session identifier.  
**Not recommended:** Create a session. Return the session identifier.

Use an imperative only when directly instructing the reader. Use consistent verbs for
similar operations: **creates**, **deletes**, **gets**, **lists**, **returns**, **sets**,
or a more exact domain verb. Do not add a vague lead-in such as “This method is used to.”
