# Images and media

## GDSG-IMAGE-001 — Use an image only when visual information matters

Use a screenshot for UI orientation or a diagram for a spatial or relational concept.
Do not use an image to present code, command output, a table, or prose that should be
searchable, selectable, responsive, and accessible.

## Make the image accessible and durable

- Provide concise alt text that communicates the image’s purpose in context.
- Use empty alt text for a purely decorative image.
- Explain a complex chart or diagram in nearby text; alt text alone is not enough.
- Introduce a meaningful image with a complete sentence.
- Do not rely on color, position, shape, or a visual gesture as the only instruction.
- Crop screenshots to relevant content and remove personal, secret, or rapidly changing
  data.
- Prefer vector assets for diagrams and high-resolution raster assets when vector is not
  suitable.
- Supply captions only when they add information not already conveyed by nearby text.

For audio or video, provide an accessible transcript or equivalent and captions where
speech conveys information.
