# Product names and trademarks

## Product and feature names

- Use the current official name and capitalization.
- Lowercase a generic feature name unless the official name or visible UI label is capped.
- Do not invent an abbreviation for a product name. Use an official short form only when
  the audience and context support it.
- Do not use a product name as a verb.
- Use an article only when normal grammar and the official naming pattern require it.
- Distinguish a product, service, tool, API, console, application, and command-line utility
  accurately. Use **service** for a collective offering only when that is its defined role.

## GDSG-TRADEMARK-001 — Use a trademark as a modifier

Follow the owner’s spelling, capitalization, attribution, and symbol requirements. Use a
trademark as an adjective modifying a generic noun; do not make it a verb, plural, or
possessive.

**Recommended:** two ExampleApp licenses; the ExampleApp interface  
**Not recommended:** two ExampleApps; ExampleApp’s interface

Include a trademark symbol or attribution statement only when the owner or project legal
guidance requires it. Do not add symbols inconsistently or imply endorsement.
