# Filenames and file types

## New web files

Unless the project has a stronger convention, use lowercase ASCII words separated by
hyphens. Make the name short, descriptive, and durable. Avoid spaces, underscores,
punctuation, and dates that will become stale.

**Recommended:** `configure-access.md`  
**Not recommended:** `Configure_Access_Final_2026.md`

## References in text

- Put an exact filename, extension, directory, or path in code font.
- Add the common noun **file**, **folder**, **directory**, or **path** when it improves
  grammar and accessibility.
- Name a file type with its conventional label: **PNG file**, not “`.png` file,” unless
  the literal extension is the topic.
- Preserve the exact case of a case-sensitive name.
- Do not pluralize or make a literal filename possessive; add and inflect a noun.
