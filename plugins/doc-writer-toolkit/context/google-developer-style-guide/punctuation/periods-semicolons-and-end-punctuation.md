# Periods, semicolons, and end punctuation

## Periods

- End complete sentences with a period, including complete-sentence list items.
- Use one space after a period.
- In US prose, put a period inside a closing quotation mark except when preserving a
  literal code string.
- For parentheses, put the period inside only when the entire sentence is parenthetical.
- Do not add periods to acronyms or initialisms.

Use an exclamation point only for a rare genuinely exclamatory statement. Do not use it
to add promotional energy to routine documentation, headings, notices, or instructions.

## Semicolons

Use semicolons sparingly. Prefer two sentences or a clearer list. A semicolon can join
closely related independent clauses or separate complex list items that already contain
commas. When a conjunctive adverb such as **however** joins independent clauses, a
semicolon can precede it and a comma follows it.
