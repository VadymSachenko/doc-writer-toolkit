# Mathematical notation and phone numbers

## Mathematical notation

- Use semantic, accessible notation rather than an image of an equation.
- Italicize variables; keep operators, function names, numbers, and units upright.
- Use proper entities or the publishing system’s math support for symbols, fractions,
  exponents, and subscripts.
- Use an accessible math-rendering tool for complex or multiline expressions and provide
  a textual explanation where readers need one.
- Define each variable and uncommon symbol near its first use.

## Phone numbers in examples

- Use reserved or clearly fictional numbers; never publish real personal contact data.
- Format North American, international, and extension forms consistently for the target
  audience.
- Use nonbreaking spaces and, where supported, nonbreaking hyphens to prevent awkward
  line breaks.
- Label an extension clearly instead of appending an unexplained digit sequence.
