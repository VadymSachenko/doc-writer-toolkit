# Tables

## GDSG-TABLE-001 — Use a table for comparison

Use a table when at least about three related items have multiple comparable properties.
Use a list when readers only need one property per item or a simple sequence.

## Construct an accessible table

- Introduce the table with a complete sentence.
- Add a concise caption when it helps identify the table independently.
- Use short, descriptive column and row headers and semantic header cells.
- Put one comparable type of information in each column.
- Keep cells concise; avoid multiple paragraphs, procedural steps, and nested tables.
- Avoid merged cells and tables used only for page layout.
- Ensure the table remains usable on a small screen and with assistive technology.
- Use sentence case and consistent punctuation in headers and cells.

If a table becomes too wide or requires extensive prose in cells, split it, convert it
to sections, or expose fewer comparison dimensions.
