This document summarizes guidelines on how to format text elements — bold, italic, underline, code font, capitalization, and quotation marks — to ensure readability and consistency.

For more details, see the [Text-formatting summary](https://developers.google.com/style/text-formatting) page in the Google developer documentation style guide.

## Bold

**Rule:** Use bold formatting for UI elements and at the beginning of notices.

- ✓ **Recommended:** Click **Save**.
- ✓ **Recommended:** **Note:** All VPC networks include firewall rules.

## Italic

**Rule:** Use italics when drawing attention to a specific word or phrase, such as when defining a term or using [<link to Words as words>].

**Rule:** Italicize titles of books, movies, web series, and other full-length works, unless they're part of a link.

**Rule:** Italicize mathematical variables and version variables.

- ✓ **Recommended:** *x + y = 3*
- ✓ **Recommended:** version 1.4.*x*

## Underline

**Rule:** Don't underline text.

## Code font

**Rule:** Apply code font to code in text, inline code, user input, filenames, class names, method names, HTTP status codes, console output, and placeholders.

**Rule:** Don't override or modify font styles inline.

- ✓ **Recommended:** Open the `settings.json` file.
- ⛔️ **Not recommended:** Open the **settings.json** file.

## Capitalization

**Rule:** Use sentence case — capitalize only the first word.

**Scope:** Sentence case applies to headings, titles, navigation, lists and their items, glossaries, index terms, labels, callouts, and other text in images and diagrams.

- ✓ **Recommended:** Create product plans
- ⛔️ **Not recommended:** Create Product Plans

**Rule:** Use all-capitals for placeholders.

- ✓ **Recommended:** *`PROJECT_ID`*
- ⛔️ **Not recommended:** *`project_id`*

## Quotation marks

**Rule:** For titles of shorter works — articles, episodes in a web series — put the title in quotation marks, unless it's part of a link.

- ✓ **Recommended:** See "Getting started with product plans" for an overview.

**Rule:** Put quotation marks and end punctuation outside of link text.

- ✓ **Recommended:** For more information, see [Product codes].
- ⛔️ **Not recommended:** For more information, see [Product codes.]
