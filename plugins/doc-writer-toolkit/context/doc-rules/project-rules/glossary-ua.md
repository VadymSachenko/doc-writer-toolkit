Цей глосарій є авторитетним джерелом термінів для україномовних документів UCPay. Оновлюйте його, коли новий документ вводить новий термін, якого тут ще немає.

| Термін | Визначення |
|---|---|
| **API-токен** | Унікальний рядок із 128 символів для автентифікації запитів до API UCPay. Не використовуйте: партнерський токен, ключ автентифікації. |
| **Архів** | Розділ кабінету партнера з завершеними транзакціями. Не використовуйте: завершені транзакції, закриті позиції, історія. |
| `cancelled` | Статус транзакції — скасована. **UK spelling** (не `canceled`). UI-мітка: Скасована. |
| **Вебхук** | HTTP-запит, який UCPay надсилає на URL партнера при настанні події (наприклад, зміні статусу транзакції). Не використовуйте: колбек, нотифікація, пуш. |
| **Вхідна транзакція** | Транзакція із зарахуванням коштів на рахунок партнера або кінцевого клієнта. Не використовуйте: поповнення, вхідна заявка. |
| **Вихідна транзакція** | Транзакція з виведенням коштів із рахунку. Не використовуйте: виплата (як синонім у публічних документах). |
| **Віджет** | Платіжний компонент UCPay, що встановлюється на стороні партнера. Не використовуйте: компонент. |
| **Диспут** | Оскарження транзакції кінцевим клієнтом. Не використовуйте: скарга, апеляція. |
| **Ендпоінт** | Конкретна адреса API-методу. Не використовуйте: кінцева точка. |
| `in queue` | Статус транзакції — в черзі очікування. UI-мітка: В черзі. |
| `in work` | Статус транзакції — у роботі. UI-мітка: В роботі. |
| **Кабінет партнера** | Вебінтерфейс UCPay для керування транзакціями, налаштуваннями та звітністю. Не використовуйте: дашборд, партнерський портал, кабінет клієнта. |
| **Кінцевий клієнт** | Фізична або юридична особа, яка здійснює платіж через продукт партнера. Не використовуйте: кінцевий користувач, клієнт (коли неоднозначно). |
| **Комісія** | Сума, що утримується UCPay за проведення транзакції. Не використовуйте: збір, плата. |
| **Моніторинг** | Розділ кабінету партнера з активними (незавершеними) транзакціями. Не використовуйте: активні транзакції, відкриті позиції. |
| `new` | Статус транзакції — нова. UI-мітка: Новий. |
| **Партнер** | Юридична особа, підключена до платформи UCPay для обробки платежів. Не використовуйте: провайдер, клієнт, мерчант. |
| **Переміщення** | Зміна відповідальної робочої групи для транзакції. Не використовуйте: перепризначення, переведення. |
| **Робоча група** | Підрозділ, відповідальний за опрацювання транзакцій у певний момент. Не використовуйте: команда, черга. |
| **Сума** | Заявлена сума транзакції на момент ініціювання. Не використовуйте: початкова сума, заявлена сума (як альтернатива терміна). |
| `success` | Статус транзакції — успішна. UI-мітка: Успіх. |
| **Токен вебхука** | Ключ для перевірки автентичності вхідних вебхук-запитів. Не використовуйте: колбек-токен, секрет вебхука. |
| **Транзакція** | Фінансова операція, ініційована через платіжний шлюз UCPay. Розм.: заявка. Не використовуйте: запит, аплікація, операція. |
| **UCP** | Скорочення від UniComPay. Вживайте після першої згадки «UniComPay (UCP)». |
| **UniComPay** | Офіційна назва платформи. Не використовуйте: Юнікомпей, UCP Pay, Unicompay. |
| **Фактична сума** | Остаточна сума, зафіксована після завершення транзакції. Не використовуйте: кінцева сума, підтверджена сума. |
