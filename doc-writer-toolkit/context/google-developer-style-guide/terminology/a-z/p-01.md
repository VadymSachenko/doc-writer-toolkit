# P terminology — 1 of 3

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-paas"></a>
## `PaaS`

**Scope:** `general`  
**Rule:** Write out on first mention: platform as a service (PaaS).

[Official entry](https://developers.google.com/style/word-list#paas)

<a id="term-page"></a>
## `page`

**Scope:** `general`  
**Rule:** Use page to refer to the following: A whole web page, which can include text, images, links, banners, navigational panes, and other features. A sub-page of a console in particular.

[Official entry](https://developers.google.com/style/word-list#page)

<a id="term-parameter"></a>
## `parameter`

**Scope:** `general`  
**Rule:** In our API documentation, parameter is usually short for query parameter; it's a NAME=VALUE pair that's appended to a URL in an HTTP GET request. In some contexts, however, the term can have other meanings.

[Official entry](https://developers.google.com/style/word-list#parameter)

<a id="term-parent-child"></a>
## `parent-child or parent/child`

**Scope:** `general`  
**Rule:** Use the heading form; do not use parent – child or parent—child.

[Official entry](https://developers.google.com/style/word-list#parent-child)

<a id="term-path"></a>
## `path`

**Scope:** `general`  
**Rule:** Avoid using filepath, file path, pathname, or path name if possible.

[Official entry](https://developers.google.com/style/word-list#path)

<a id="term-peer-gateway"></a>
## `peer gateway`

**Scope:** `general`  
**Rule:** Do not use on-premises gateway when you mean a peer gateway. A peer gateway can be an on-premises device or service or another cloud gateway.

[Official entry](https://developers.google.com/style/word-list#peer-gateway)

<a id="term-peer-network"></a>
## `peer network`

**Scope:** `general`  
**Rule:** Do not use on-premises network when you mean a peer network. A peer network can be an on-premises network or another cloud network.

[Official entry](https://developers.google.com/style/word-list#peer-network)

<a id="term-peering-zone"></a>
## `peering zone`

**Scope:** `general`  
**Rule:** Use the heading form; do not use peer zone.

[Official entry](https://developers.google.com/style/word-list#peering-zone)

<a id="term-per"></a>
## `per`

**Scope:** `general`  
**Rule:** To express a rate, use per instead of the division slash (/), unless space constraints require the use of the slash. Avoid per in contexts other than rate units.

[Official entry](https://developers.google.com/style/word-list#per)

<a id="term-performant"></a>
## `performant`

**Scope:** `use-with-caution`  
**Rule:** Avoid where possible. Prefer a more precise term.

[Official entry](https://developers.google.com/style/word-list#performant)

<a id="term-persist"></a>
## `persist`

**Scope:** `general`  
**Rule:** Do not use as a transitive verb. It's best to avoid using as a verb at all, especially in passive voice.

[Official entry](https://developers.google.com/style/word-list#persist)

<a id="term-persistent-disk"></a>
## `persistent disk`

**Scope:** `general`  
**Rule:** Use the heading form; do not use PD. Lowercase except at the start of a sentence.

[Official entry](https://developers.google.com/style/word-list#persistent-disk)

<a id="term-pii"></a>
## `personally identifiable information (PII)`

**Scope:** `general`  
**Rule:** Some government agencies use the less common term personally identifying information; use this alternate term only in contexts where you're referring to a document that uses this term.

[Official entry](https://developers.google.com/style/word-list#pii)

<a id="term-pets-versus-cattle"></a>
## `pets versus cattle, pets vs. cattle, pets v. cattle`

**Scope:** `do-not-use`  
**Rule:** Do not use. Prefer more precise terms like persistent versus dynamic or manually configured versus automated.

[Official entry](https://developers.google.com/style/word-list#pets-versus-cattle)

<a id="term-plain-text"></a>
## `plain text`

**Scope:** `general`  
**Rule:** In most contexts, use plain text, but use plaintext in a cryptography context.

[Official entry](https://developers.google.com/style/word-list#plain-text)

<a id="term-please"></a>
## `please`

**Scope:** `use-with-caution`  
**Rule:** Do not use please in the normal course of explaining how to use a product, even if you're explaining a difficult task. Do not use the phrase please note. Use please only when you're asking for permission or forgiveness—for example, when what you're asking for benefits you, inconveniences a reader, or suggests a potential issue with a product.

[Official entry](https://developers.google.com/style/word-list#please)

<a id="term-plugin"></a>
## `plugin (noun), plug-in (adjective), plug in (verb)`

**Scope:** `general`  
**Rule:** Use the noun form plugin For the software component. Use the adjective form plug-in For the action of installing a software component. Use the verb form plug in when you're describing the process of installing a software component.

[Official entry](https://developers.google.com/style/word-list#plugin)

<a id="term-pm"></a>
## `PM`

**Scope:** `general`  
**Rule:** See AM, PM.

[Official entry](https://developers.google.com/style/word-list#pm)

<a id="term-point-to"></a>
## `point to`

**Scope:** `general`  
**Rule:** Use to refer to the action of pointing the mouse pointer (focus). This action doesn't imply a length of time waiting for the UI to react to user action. This is similar to the action hold the pointer over (hover). In most cases, it's better to use the verb phrase hold the pointer over if you want the user to wait for the UI to react.

[Official entry](https://developers.google.com/style/word-list#point-to)

<a id="term-pojo"></a>
## `POJO`

**Scope:** `general`  
**Rule:** If you're not actually writing about a Plain Old Java Object for a Java audience, use simple object. You can write a simple object, similar to a POJO in Java if that helps your audience.

[Official entry](https://developers.google.com/style/word-list#pojo)
