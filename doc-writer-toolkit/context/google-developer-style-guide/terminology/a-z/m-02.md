# M terminology — 2 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-microservices"></a>
## `microservices`

**Scope:** `general`  
**Rule:** Use the heading form; do not use Microservices or micro-services.

[Official entry](https://developers.google.com/style/word-list#microservices)

<a id="term-might"></a>
## `might`

**Scope:** `general`  
**Rule:** Use to convey possibility or an uncertain outcome (for example, "You might be prompted to enter your credentials"). For information about clarifying who's performing an action, see Active voice.

[Official entry](https://developers.google.com/style/word-list#might)

<a id="term-mime-type"></a>
## `MIME type`

**Scope:** `use-with-caution`  
**Rule:** MIME stands for "Multipurpose Internet Mail Extensions," and was originally used to refer to email standards. Do not use MIME when you mean media type. If you feel that might be ambiguous to an audience familiar with the term MIME, then you can write media (MIME) type for clarity.

[Official entry](https://developers.google.com/style/word-list#mime-type)

<a id="term-mobile"></a>
## `mobile`

**Scope:** `do-not-use`  
**Rule:** Do not use mobile as a standalone noun. Instead, specify mobile phone, or if you're talking about more than phones, then use mobile device.

[Official entry](https://developers.google.com/style/word-list#mobile)

<a id="term-mobile-data"></a>
## `mobile data`

**Scope:** `general`  
**Rule:** Use instead of cellular data.

[Official entry](https://developers.google.com/style/word-list#mobile-data)

<a id="term-mobile-device"></a>
## `mobile device`

**Scope:** `general`  
**Rule:** Use mobile device when you're referring to more than phones (for example, tablets and phones). Acceptable to use phone (without mobile) when the context is clear.

[Official entry](https://developers.google.com/style/word-list#mobile-device)

<a id="term-mobile-network"></a>
## `mobile network`

**Scope:** `general`  
**Rule:** Use instead of cellular network.

[Official entry](https://developers.google.com/style/word-list#mobile-network)

<a id="term-mobile-phone"></a>
## `mobile phone`

**Scope:** `general`  
**Rule:** If you're talking about more than phones, then use mobile device. Acceptable to use phone (without mobile) when the context is clear.

[Official entry](https://developers.google.com/style/word-list#mobile-phone)

<a id="term-mom-test"></a>
## `mom test`

**Scope:** `do-not-use`  
**Rule:** Do not use mom test, grandmother test, grandma test, or girlfriend test. Prefer terms like beginner user test or novice user test.

[Official entry](https://developers.google.com/style/word-list#mom-test)

<a id="term-monkey"></a>
## `monkey, monkey test`

**Scope:** `do-not-use`  
**Rule:** Do not use monkey to refer to people. For tests, refer to the specific function. For example: automated, random tests.

[Official entry](https://developers.google.com/style/word-list#monkey)

[Official entry](https://developers.google.com/style/word-list#multi-cluster)

<a id="term-multi-region"></a>
## `multi-region, multi-regional`

**Scope:** `general`  
**Rule:** Hyphenate For a Google Cloud location that consists of more than one region. You can use multi-regional as an adjective in the context of multi-regions, but consider multi-region as an attributive noun instead, such as in "The dataset is in the EU multi-region location." Use multiregional in other contexts.

[Official entry](https://developers.google.com/style/word-list#multi-region)

<a id="term-must"></a>
## `must`

**Scope:** `general`  
**Rule:** Use to describe a required action or state (for example, "You must have the Editor role"). You can also write you need in order to convey a requirement. For information about clarifying who's performing an action, see Active voice.

[Official entry](https://developers.google.com/style/word-list#must)
