# SYMBOLS terminology — 1 of 1

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-plus"></a>
## `+`

**Scope:** `general`  
**Rule:** You may use `+` after a number in ordinary technical text. Avoid this compact
form in formal contexts.

[Official entry](https://developers.google.com/style/word-list#+)

<a id="term-ampersand"></a>
## `& (ampersand)`

**Scope:** `use-with-caution`  
**Rule:** Use **and**, not `&`, in prose, headings, navigation, and tables of contents.
Preserve `&` in literal UI text or code; it is also acceptable in space-constrained table
headings and diagram labels.

[Official entry](https://developers.google.com/style/word-list#ampersand)

<a id="term-aware"></a>
## `-aware`

**Scope:** `use-with-caution`  
**Rule:** Avoid forming a new compound modifier with **-aware**. Preserve it in an
official product name.

[Official entry](https://developers.google.com/style/word-list#aware)

<a id="term-touch-and-hold"></a>
## `"touch & hold"`

**Scope:** `general, android-only`  
**Rule:** Use the heading form; do not use touch and hold.

[Official entry](https://developers.google.com/style/word-list#touch-and-hold)
