# P terminology — 3 of 3

Scope labels are cumulative. `general` means no product-only marker was

## `primitive`

**Scope:** `use-with-caution`  
**Rule:** Use with caution. Do not use primitive in a disparaging sense.

[Official entry](https://developers.google.com/style/word-list#primitive)

<a id="term-project"></a>
## `project`

**Scope:** `general, google-cloud-only`  
**Rule:** In Google Cloud documentation, use Google Cloud project on first mention and in any context in which there might be ambiguity about what kind of project you're referring to.

[Official entry](https://developers.google.com/style/word-list#project)

## `pros`

**Scope:** `do-not-use`
