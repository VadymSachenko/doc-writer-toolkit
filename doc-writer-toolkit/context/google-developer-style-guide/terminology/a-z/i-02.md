# I terminology — 2 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-idn"></a>
## `Internationalized Domain Name (IDN)`

**Scope:** `general`  
**Rule:** Write out and capitalize each word on first use. Acceptable to abbreviate as IDN after first use.

[Official entry](https://developers.google.com/style/word-list#idn)

<a id="term-internet"></a>
## `internet`

**Scope:** `general`  
**Rule:** Lowercase except at the beginning of a sentence, heading, or list item.

[Official entry](https://developers.google.com/style/word-list#internet)

<a id="term-ike"></a>
## `Internet Key Exchange (IKE)`

**Scope:** `general`  
**Rule:** Write out and capitalize each word on first use. Acceptable to abbreviate IKE after first use.

[Official entry](https://developers.google.com/style/word-list#ike)

<a id="term-io"></a>
## `I/O (see also )`

**Scope:** `general`  
**Rule:** Use the heading form; do not use I-O or IO.

[Official entry](https://developers.google.com/style/word-list#io)

<a id="term-iot"></a>
## `IoT`

**Scope:** `general`  
**Rule:** Acceptable as an abbreviation for Internet of Things. Note the lowercase o.

[Official entry](https://developers.google.com/style/word-list#iot)

<a id="term-ipsec"></a>
## `IPsec`

**Scope:** `general`  
**Rule:** Use the heading form; do not use IPSec or IPSECShort. Short for Internet Protocol Security. No need to spell out on first mention.

[Official entry](https://developers.google.com/style/word-list#ipsec)
