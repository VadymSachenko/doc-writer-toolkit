# L terminology — 2 of 2

Scope labels are cumulative. `general` means no product-only marker was
present; a project-specific rule can still override this entry.

<a id="term-lro"></a>
## `long-running operation`

**Scope:** `general`  
**Rule:** Use the heading form; do not use long running operation. Acceptable to abbreviate as LRO after the first use.

[Official entry](https://developers.google.com/style/word-list#lro)

<a id="term-lower"></a>
## `lower`

**Scope:** `general`  
**Rule:** Do not use for a range of version numbers. Prefer earlier. Do not use to refer to a position in a document. Prefer later or following. Do not use to refer to a position in the UI. Instead, write instructions that avoid directional language. In Android documentation, use lower for a range of version numbers, not earlier.

[Official entry](https://developers.google.com/style/word-list#lower)
