# Links and cross-references

## GDSG-LINK-001 — Write descriptive link text

Make the link text identify the destination or action when read out of context. Include a
relevant abbreviation in the link if readers might search for it.

**Recommended:** For limits, see [API request quotas](…).  
**Not recommended:** For limits, click [here](…).

- Do not use a bare URL as link text when a descriptive phrase is possible.
- Avoid **click here**, **learn more**, **this page**, and other vague labels.
- Either sentence order works for a cross-reference — "For more information, see [X]" or
  "See [X] for more information." — but put the reason for the reference near the link
  itself.
- Do not instruct readers to open a link in a new tab. Keep the default browsing behavior
  unless there is a documented product reason to override it.

## GDSG-LINK-002 — Link selectively

- Give enough context on the current page before sending the reader elsewhere.
- Link the most relevant destination, not every possible background page.
- Do not repeat the same destination link throughout a short section.
- Prefer secure `https` destinations for external links.
- For sites that support it, use stable site-root-relative internal URLs.
- Do not link ordinary words merely because a related page exists.
