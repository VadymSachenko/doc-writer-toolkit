# Lists

## Choose the list type

- Use a numbered list for a sequence, ranking, or set whose order matters.
- Use a bulleted list for an unordered collection.
- Use a description list for term-definition or name-value pairs.
- Do not create a list with only one item.
- Use a table instead when readers must compare several properties across items.

## GDSG-LIST-001 — Make lists grammatical and parallel

- Introduce a list with a complete sentence. Use a colon when the list follows directly.
- Make items parallel in grammar, scope, and level of detail.
- Begin each item in sentence case.
- Use complete sentences when items contain actions, conditions, or substantial detail.
- End all complete-sentence items with periods. For fragments, omit end punctuation unless
  clarity requires it. Stay consistent within the list.
- Do not join list items with semicolons as a visual workaround.

For procedural lists and nesting, also load `../procedures/procedures.md`.
