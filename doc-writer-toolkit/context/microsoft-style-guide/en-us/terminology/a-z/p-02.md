# Microsoft terms: P (2)

Load this file only when checking one of the indexed terms below.

<a id="pin-unpin"></a>
## pin, unpin

- Prefer pin to refer to placing an item, such as a tile, an app, or a command, in a given area of the UI, so it's always accessible in that area.
- Prefer unpin to describe removing a pinned item.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/pin-unpin)

- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/pinch)

<a id="ping-ping"></a>
## ping, PING

- Avoid ping to refer generally to searching for a program.
- Acceptable: p ing to refer to using the PING protocol, which is used to determine the presence of a host on the internet.
- Don't spell out PING.
- If necessary, describe it as Packet Internet Groper.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/ping-ping)

<a id="pipe"></a>
## pipe

- Avoid this term as a verb in content for a general audience.
- Prefer a more specific term, such as send, move, copy, direct, redirect, or write.
- Acceptable: pipe as a verb in content for a technical audience to refer to routing data from the standard output of one process to the standard input of another.
- The symbol for a pipe in programming content is a vertical bar ( | ).
- Related guidance: Special characters term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/pipe)

<a id="plaintext-plain-text"></a>
## plaintext, plain text

- Prefer plaintext only to refer to nonencrypted or decrypted text in content about encryption.
- Prefer plain text to refer to ASCII files.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/plaintext-plain-text)

<a id="platform"></a>
## platform

- Avoid in content for a general audience.
- Acceptable: platform in content for a technical audience when you need to distinguish differing behaviors of a function or other API element in various operating systems.
- In content for a technical audience, use cross-platform to refer to an app or device that can run on more than one operating system.
- Prefer on as a preposition with platform in discussions about hardware platforms: on the Intel Atom platform, for example, but in Windows 10.
- Related guidance: operating environment, operating system.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/platform)

## please

- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/please)

<a id="plug-and-play-plug-and-play"></a>
## Plug and Play, plug and play

- Prefer Plug and Play as a noun or an adjective to refer to a set of specifications developed by Intel for the automatic configuration of a computer so that it works with various peripheral…
- Note capitalization.
- Don't hyphenate.
- Acceptable: all lowercase (plug and play) for all audiences to refer to the ability of a computer to automatically configure a device that's added to it.
- Avoid this term as a synonym for Universal Plug and Play (UPnP).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/plug-and-play)

<a id="plugin"></a>
## plugin

- Write plugin as one word. Do not use plug-in.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/plug-in)

<a id="plus-sign"></a>
## plus sign (+)

- Avoid the plus sign (+) to replace words like and, over, and plus.
- Exception Where space is limited, like in UI or a headline, it’s OK to use the plus sign to indicate a count that exceeds a certain number.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/plus-sign)

<a id="pointer"></a>
## pointer

- In a programming context, a pointer is a variable that contains a memory location.
- In the rare case where both types of pointers are discussed, use mouse pointer and pointer variable as necessary to avoid ambiguity.
- Related guidance: Mouse and mouse interaction term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/pointer)

<a id="pop-up"></a>
## pop-up

- Avoid this term as a noun.
- For example, don't use a pop-up; use a pop-up window instead.
- Avoid pop up or pops up as a verb to describe the appearance of a window.
- Prefer open or a similar verb instead.
- Acceptable: pop-up window to refer to windows that pop up in Help.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/pop-up)

<a id="port"></a>
## port

- Prefer the verb forms port to and port only in content for a technical audience in reference to portability.
- Avoid in content for a general audience.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/port)
