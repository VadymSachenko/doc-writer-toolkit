# Microsoft terms: R (2)

Load this file only when checking one of the indexed terms below.

<a id="restore"></a>
## restore

- Prefer this term as a verb instead of undelete to describe restoring an item that was deleted.
- Prefer this term as a verb to describe restoring an item or condition to its previous state, such as a window that was previously maximized or minimized.
- Avoid this term as an adjective or as a noun in content for a general audience unless you need to match the UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/restore)

<a id="reverse-video"></a>
## reverse video

- Prefer instead of inverse video, invert video, or reverse screen to describe the displaying of inverted background and text colors.
- Prefer highlighted to refer to the appearance.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/reverse-video)

<a id="right-align-right-aligned"></a>
## right align, right-aligned

- Prefer to refer to text that's aligned at the right margin.
- Write with a hyphen right-aligned.
- Avoid right-justified.
- Related guidance: justify, justified, left align, left-aligned.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/right-align-right-aligned)

<a id="right-rightmost-right-hand"></a>
## right, rightmost, right-hand

- Avoid right as a directional term by itself.
- Instead, use a term such as upper right, lower right, rightmost, or the right side of. Include a hyphen when you use right to modify a noun, as in upper-right corner.
- Avoid right-hand as a modifier.
- Accessibility tip Don't use directional terms (left, right, up, down) as the only clue to location.
- Individuals with cognitive disabilities might have difficulty interpreting them, as might people who are blind and use screen-reading software.
- Related guidance: a change in the interface as.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/right-rightmost-right-hand)

<a id="right-click"></a>
## right-click

- Prefer only when you need to talk specifically about mouse actions.
- Define in content that teaches beginning skills if you think it's necessary.
- Prefer select and hold (or right-click) when the instruction isn't specific to the mouse.
- Hyphenate.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/right-click)

<a id="rights"></a>
## rights

- Prefer rights only in a nonspecific way to refer to system actions that are authorized by the system administrator.
- For specific references, use user rights.
- Don't confuse rights, which apply to system operations, with permissions, which apply to specific system resources, such as files or printers.
- Avoid privileges as a synonym for rights.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/rights)

<a id="root-directory"></a>
## root directory

- In content for developers, use root directory, not home directory, to refer to the directory or folder from which all other directories or folders branch.
- In Windows, the root directory is indicated by a backslash (\\).
- Don’t shorten to root when you mean the directory.
- In other content, use top-level folder.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/root-directory)

<a id="run-vs-execute"></a>
## run vs. execute

- Avoid execute except to follow the UI.
- Prefer run instead.
- If the UI includes execute, the resulting action is still run.
- Always use run in the context of operating systems, macros, and queries.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/run-vs-execute)

<a id="running-foot-running-head"></a>
## running foot, running head

- Avoid.
- Prefer footer and header instead.
- If you think your audience might search for these terms, use also known as r unning foot and running head on the first mention.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/running-foot-running-head)

<a id="runs-vs-runs-on"></a>
## runs vs. runs on

- Avoid run for a general audience.
- For a technical audience, use run to refer to an operating system and run on to refer to a program.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/runs-vs-runs-on)

<a id="runtime"></a>
## runtime

- Prefer runtime:
- To indicate an environment required to run apps that aren't compiled to machine language. - To indicate the time during which an application is running. - As an adjective to describe a thing that's…
- Avoid runtime as a synonym for reader programs, such as Microsoft Office file viewers.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/r/runtime)
