# Microsoft terms: F (1)

Load this file only when checking one of the indexed terms below.

<a id="fail"></a>
## fail

- In content for a general audience, use only to refer to disks and other hardware.
- Prefer stop responding to refer to programs or the operating system.
- Acceptable: fail in content for a technical audience to describe an error condition.
- For example, E_FAIL is a common return value in COM programs.
- A function that returns E_FAIL has failed to do something.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/fail)

<a id="fail-over-fail-back-failover-failback"></a>
## fail over, fail back, failover, failback

- Two words as a verb, one word as an adjective or a noun.
- Avoid in content for a general audience.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/fail-over-fail-back-failover-failback)

<a id="false"></a>
## FALSE

- In content for developers, use all uppercase to refer to a return value, or follow the capitalization used in the specific programming language.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/FALSE)

<a id="family"></a>
## family

- Prefer instead of line to refer to a set of related Microsoft products or services.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/family)

<a id="far-east"></a>
## Far East

- Avoid to refer to the geographic region of East Asia.
- Prefer East Asia or Asia instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/far-east)

<a id="far-left-far-right"></a>
## far-left, far-right

- Avoid.
- Prefer leftmost or rightmost instead.
- Accessibility tip Don't use directional terms (left, right, up, down) as the only clue to location.
- Individuals with cognitive disabilities might have difficulty interpreting them, as might people who are blind and use screen-reading software.
- Acceptable: a directional term if another indication of location, such as in the Save As dialog box, on the Standard toolbar, or in the title bar, is also included.
- Related guidance: a change in the interface as.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/far-left-far-right)

<a id="favorite"></a>
## favorite

- Prefer to refer to a webpage or site the customer may want to return to later in Microsoft Edge or Internet Explorer.
- Customers save favorites to the Favorites menu.
- Prefer lowercase when referring to a favorite website, and capitalize the menu name.
- Avoid using as a verb.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/favorite)

<a id="fax"></a>
## fax

- Write in lowercase.
- Abbreviation for facsimile.
- Acceptable: fax as an adjective (fax machine, fax transmission), as a noun (your fax arrived), or as a verb (fax a copy of the order).
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/fax)

<a id="field"></a>
## field

- Avoid to refer to a text-entry box.
- Describe the box by its label.
- If you must use a descriptor, use box instead of field.
- Acceptable: field to refer to Word field codes, in a database context, and in other technical contexts.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/field)

<a id="file"></a>
## file

- Try to use a more specific term, such as document (Word), workbook (Excel), or presentation (PowerPoint).
- Acceptable: file to discuss units of storage or file management or to refer to files of mixed types.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/file)

<a id="file-attributes"></a>
## file attributes

- Prefer lowercase for file attributes such as hidden, system, read-only, and archive.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/file-attributes)

<a id="file-explorer"></a>
## File Explorer

- Prefer instead of Windows Explorer. Don't use an article, such as the, to precede File Explorer. Don't shorten to Explorer.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/file-explorer)

<a id="file-name"></a>
## file name

- Two words as an adjective or a noun when referring to the name of a file.
- Don't hyphenate.
- Usually one word when referring to a programming term, such as the FileName property.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/file-name)

<a id="file-name-extension-extension"></a>
## file name extension, extension

- Prefer instead of file extension.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/file-name-extension-extension)

<a id="finalize"></a>
## finalize

- Avoid.
- Prefer finish or complete instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/finalize)

<a id="find-and-replace"></a>
## find and replace

- Prefer find and replace as separate verbs, not as a single verb phrase.
- Avoid find and replace or find-and-replace as a noun or an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/find-replace)

<a id="first-line-first-line"></a>
## first line, first-line

- Two words as a noun.
- Hyphenate as an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/f/first-line)
