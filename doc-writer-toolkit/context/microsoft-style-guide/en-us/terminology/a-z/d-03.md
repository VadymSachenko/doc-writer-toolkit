# Microsoft terms: D (3)

Load this file only when checking one of the indexed terms below.

<a id="domain"></a>
## domain

- Domain has different meanings in database design, Windows, and internet addresses.
- Define the term on the first use, if necessary, to make sure the meaning is clear.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/domain)

<a id="dot-com"></a>
## dot-com

- Avoid.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dot-com)

<a id="dotted-rectangle"></a>
## dotted rectangle

- Prefer only if you need to describe the appearance of the element that a customer drags to select a region on the screen.
- Otherwise, use bounding outline (not marquee) instead.
- Related guidance: bounding outline.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dotted-rectangle)

<a id="double-buffering"></a>
## double buffering

- Two words as a noun.
- Hyphenate as an adjective.
- Avoid this term as a verb.
- Instead, use a phrase such as uses double buffering .
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/double-buffering)

<a id="downgrade"></a>
## downgrade

- Prefer only if necessary to express the concepts of downgrade rights, downgrading licenses, downgrading products, downgrading files, and similar subjects.
- Prefer only in content for an audience that will understand your use of the word in those contexts.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/downgrade)

<a id="download"></a>
## download

- Prefer download to describe the intentional transfer of data and files to a system or device.
- Prefer install to describe adding apps, hardware, and drivers to a device.
- When you use download as a verb, describe what the customer is transferring and where the customer is transferring it to. In grammatical terms, use both a subject (the thing to be downloaded) and…
- Avoid download to describe the process of opening, viewing, or switching to a webpage.
- Acceptable: download as a noun to describe data or a file that's available for downloading or that has been downloaded.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/download)

<a id="drag-drag-and-drop"></a>
## drag, drag and drop

- Avoid drag and drop except as an adjective to describe behavior that a programmer puts in a program, such as drag-and-drop editing or drag-and-drop feature.
- Prefer move or drag instead.
- Avoid click and drag. It's OK to use press and drag to teach mouse techniques in content that teaches beginning skills.
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/drag-and-drop)

<a id="drill-down-drill-up-drill-through"></a>
## drill down, drill up, drill through

- Acceptable: drill down, drill up, and drill through in content about data and the reports generated from them.
- Two words as a verb.
- Hyphenate drill-down and drill-up as adjectives.
- Note that drillthrough as a noun or an adjective is one word, no hyphen.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/drill-down-drill-up-drill-through)

<a id="dvd"></a>
## DVD

- Don't spell out DVD.
- If you refer to a DVD as a disc, use the correct spelling.
- Most of the time, use DVD by itself.
- If you need to be specific, it's OK to use video DVD, audio DVD, DVD-ROM, DVD-R, DVD-RAM, or DVD-RW.
- Describe the drive for a DVD as the DVD drive, not the DVD player.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dvd)

<a id="dynamic-link-library-dll"></a>
## dynamic-link library (DLL)

- Write in full on the first mention unless you're positive that your audience knows the term.
- On subsequent mentions, use the abbreviation DLL.
- Prefer .dll (lowercase with a period) to refer to the file name extension.
- Avoid dynalink.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dynamic-link-library-dll)
