# Microsoft terms: C (3)

Load this file only when checking one of the indexed terms below.

<a id="code-point"></a>
## code point

- Two words.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/code-point)

<a id="codec"></a>
## codec

- Don't spell out as compressor/decompressor or coder/decoder.
- Prefer only in content for a technical audience or when codec appears in the UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/codec)

<a id="color-map"></a>
## color map

- Two words when referring to the color lookup table in a video card.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/color-map)

<a id="column-format"></a>
## column format

- Prefer instead of columnar or columnlike.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/column-format)

<a id="combo-box"></a>
## combo box

- Two words.
- Prefer only in content for a technical audience to describe a box in which the user can enter or select a value.
- Avoid in content for a general audience.
- Instead, refer to it as a box, using the label provided in the UI.
- Prefer enter to indicate that the user can either type an item in the box or select an item in the list.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/combo-box)

<a id="command"></a>
## command

- In general, avoid talking about the UI.
- Instead, talk about what the customer needs to do.
- If you must refer to commands on menus in content for a general audience, use command instead of menu item, choice, or option.
- In content for developers about creating UI elements, it's OK to use menu item when appropriate.
- Describing interactions with UI Formatting text in instructions option, option button
- Related guidance: Describing interactions with UI.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/command)

<a id="command-button"></a>
## command button

- Avoid in content for a general audience.
- Most of the time, just refer to the button by its UI label.
- In content that teaches beginning skills, use the label followed by the word button.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/command-button)

<a id="command-line-command-line"></a>
## command line, command-line

- Two words as a noun.
- Hyphenate as an adjective.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/command-line)

<a id="command-prompt"></a>
## command prompt

- Prefer instead of C prompt, command-line prompt, or system prompt.
- Command prompt refers only to a prompt itself.
- For example, C:> is a command prompt.
- The window in which a command prompt appears is the Command Prompt window. Note the capitalization.
- Don't refer to the Command Prompt window as a console window except in content for a technical audience.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/command-prompt)

<a id="community-cloud"></a>
## community cloud

- Follow the referenced topic collection for this term.
- Related guidance: Cloud-computing term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/community-cloud)

<a id="company-vs-organization"></a>
## company vs. organization

- Prefer the term that makes the most sense for your audience.
- Company is appropriate for businesses, which don't think of themselves as organizations.
- Organization includes schools, nonprofits, and government customers in addition to companies.
- Related guidance: enterprise, org, organization.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/company-vs-organization)

<a id="compile"></a>
## compile

- Acceptable: compile as an adjective, as in compile time, or as a verb.
- Avoid this term as a noun.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/compile)

<a id="compute"></a>
## compute

- Acceptable: compute as a verb in content for all audiences.
- In content for a technical audience, it’s OK to use compute to refer to computation, such as in compute hours and compute-intensive.
- For a general audience, use terms such as computing time or processor-intensive.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/compute)

<a id="computer"></a>
## computer

- Follow the referenced topic collection for this term.
- Related guidance: Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/computer)

<a id="connect"></a>
## connect

- Prefer connect, make a connection, and similar phrases to describe attaching a computer to a network, whether intranet or internet.
- Avoid connect as a synonym for sign in or map, as in mapping a drive letter to a shared network folder.
- But use disconnect to describe removing a mapped network drive.
- Related guidance: sign in, sign out.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/connect)

<a id="console"></a>
## console

- Prefer console window and console application only in content for a technical audience.
- Prefer Command Prompt window and command-line program in content for a general audience.
- Avoid console as a synonym for snap-in.
- Command line, command-line command prompt snap-in
- Related guidance: command line, command-line.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/console)

<a id="context-menu"></a>
## context menu

- Prefer context menu only in content for developers.
- Make it clear that it refers to the shortcut menu.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/context-menu)

<a id="context-sensitive"></a>
## context-sensitive

- Write with a hyphen.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/context-sensitive)

<a id="contiguous-selection"></a>
## contiguous selection

- Avoid.
- Prefer multiple selection instead.
- If it's important to emphasize that all the selected items are adjacent to one another, use adjacent selection.
- Related guidance: multiple selection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/contiguous-selection)

<a id="control"></a>
## control

- In content for a general audience, don't use control to refer to a UI element such as a text box, check box, or list box.
- Acceptable: control to refer to adding a user-defined control in a program.
- In other contexts, it's OK to use control.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/c/control)
