# Microsoft terms: P (4)

Load this file only when checking one of the indexed terms below.

<a id="purge"></a>
## purge

- Prefer only in the context of a programming term, such as the Purge method.
- Otherwise, use delete, clear, or remove instead.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/purge)

<a id="push-button-push-button"></a>
## push button, push-button

- Two words.
- Hyphenate as an adjective.
- Avoid this term as a synonym for button or command button.
- In content for developers, it's OK to use push button parenthetically or to describe programming elements such as the PushButton class.
- Related guidance: command button.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/p/push-button)
