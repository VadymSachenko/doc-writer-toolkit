# Microsoft terms: D (2)

Load this file only when checking one of the indexed terms below.

<a id="destination-drive-destination-file"></a>
## destination drive, destination file

- Avoid.
- If you can, use more specific language, such as copy the file to OneDrive. Don't use target drive or target file.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/destination-drive-destination-file)

<a id="device-driver-driver"></a>
## device driver, driver

- Prefer device driver only in the context of a driver development kit (DDK) or in a general discussion about installing peripheral devices.
- If you're referring to a driver for a specific device, refer to the driver for that device, such as mouse driver or printer driver.
- In content for a general audience, define driver on the first mention.
- Related guidance: Computer and device term collection.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/device-driver-driver)

<a id="dial-up"></a>
## dial-up

- Prefer only as an adjective (as in dial-up connection), not as a noun or verb.
- Write with a hyphen.
- Prefer dial as the verb to refer to placing a call or using a dial-up device.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dial-up)

<a id="dialog-box-dialog-dialogue"></a>
## dialog box, dialog, dialogue

- Most of the time, avoid talking about UI elements.
- Talk about customer actions instead.
- When you need to refer to a dialog box, use dialog box—don't shorten to dialog. Don't use pop-up window or dialogue box.
- Don't hyphenate dialog box as a modifier.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dialog-box-dialog-dialogue)

<a id="different"></a>
## different

- Avoid different to mean many or various.
- In comparisons, use different from most of the time.
- Prefer different than only when than is followed by a clause.
- Avoid different to.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/different)

<a id="dimmed"></a>
## dimmed

- Most of the time, talk about the actions that customers should take rather than describing UI.
- Avoid to describe commands or options that are in an unusable state—use not available or isn’t available instead.
- Acceptable: appears dimmed if you must describe their appearance.
- Prefer shaded to describe the appearance of check boxes that represent a mixture of settings.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dimmed)

<a id="directory"></a>
## directory

- Most of the time, use folder instead.
- Prefer directory only in content for developers when you need to refer to the structure of the file system or to match the API.
- Avoid directory icon.
- Related guidance: folder.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/directory)

<a id="disable-disabled"></a>
## disable, disabled

- Avoid disabled to refer to people with disabilities.
- In content for a technical audience, it's OK to use disable to mean making a command or function inactive and disabled to describe such commands and functions.
- In other content, use turned off or isn’t available.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/disable-disabled)

<a id="dns"></a>
## DNS

- Write in full as Domain Name System, not Domain Name Server. When discussing the DNS networking protocol, spell out Domain Name System on the first mention.
- When discussing the Windows DNS feature, don't spell out DNS.
- The Windows feature is DNS, not DNS Server or Microsoft DNS Server. If you must emphasize that you're referring to the Windows feature and not to the networking protocol, mention Windows.
- Avoid dynamic DNS or DDNS.
- A DNS server (lowercase s) is a computer that's running DNS server software.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/dns)

<a id="document"></a>
## document

- Prefer for text files, such as files created in Word.
- To refer to any editable file located in a folder, use a more specific word, such as workbook, presentation, or database, if you can.
- Precede the descriptive word with a product name, such as PowerPoint presentation, when you need to distinguish a file created in a certain product from files created in other products.
- Prefer file for more general uses, such as file management or file structure, or references to files of mixed types.
- Source: [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/a-z-word-list-term-collections/d/document)
