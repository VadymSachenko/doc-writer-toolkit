# Date and time terms

- Spell the month name in English prose and use a numeral for the day.
- Use *noon* and *midnight* instead of `12:00 AM` or `12:00 PM`.
- Write `AM` and `PM` in capitals without periods when required by the selected format.
- Include a time zone for events interpreted across zones; do not add one to a timestamp
  already localized for the reader.
- Use *UTC* when a universal technical reference is required and state offsets clearly.
- Use *from … through …* for date ranges in prose and an en dash in compact displays.
- Use *24/7* only for continuous availability, not merely frequent service.
- Apply the target locale's calendar, week start, ordering, punctuation, and inflection.
