# Авторитетне джерело правил української мови

Ця бібліотека не дублює повний український правопис. Для орфографії,
морфології, синтаксису та пунктуації використовуйте:

`../../doc-rules/ua-grammar/INDEX.md`

## Порядок роботи

1. Знайдіть у `INDEX.md` потрібну тему та умови завантаження.
2. Відкрийте лише відповідний тематичний файл.
3. Для перевірки окремого слова спочатку шукайте його в `99-word-index.md`.
4. Не завантажуйте весь індекс слів у контекст моделі.

Проєктні назви та терміни з `00-cheatsheet.md` застосовуйте лише до
проєкту, для якого їх складено. Загальні правила правопису з тематичних файлів
мають вищий пріоритет за застарілі або суперечливі мовні рекомендації
Microsoft.
