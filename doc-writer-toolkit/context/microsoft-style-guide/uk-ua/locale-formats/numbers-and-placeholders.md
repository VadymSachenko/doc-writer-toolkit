# Числа, одиниці та підстановки

- У звичайному тексті числа від одного до дев’яти переважно пишіть словами, крім
  часу, дат, вимірів, таблиць і місць, де цифра полегшує сканування.
- У UI віддавайте перевагу цифрам: словесні числівники відмінюються й погано
  поєднуються зі змінними.
- Між числом і скороченням одиниці ставте нерозривний пробіл, якщо формат це
  підтримує: **100 МБ**, **20 К**.
- Не будуйте підстановний рядок як прямий переклад *%d users*. Перебудуйте його
  так, щоб форма була правильною для будь-якого числа: **Користувачів: %d**.
- Якщо перебудова неможлива, використайте нормативне скорочення або дужки:
  **через %d дн.**, **виявлено загрози (%1!d!)**.
- Не змінюйте синтаксис заповнювача. Визначте його тип і передбачте реальне
  значення: `%d/%u` — число, `%c` — символ, `%s` — рядок.
- Прагніть мінімуму зайвих слів: **Створено %1!d! дн. тому**.
